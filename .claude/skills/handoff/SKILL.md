# Передача дел

Цель — следующая сессия стартует с ~30k контекста и за один шаг понимает, где мы. Файл подложит хук `SessionStart` (`.claude/hooks/handoff_load.py`) сразу после `/clear`.

1. Собери факты одной командой: `git branch --show-current; git log --oneline -3; grep -o "t2d-v[0-9]*" sw.js; git status --short`. Чужие незакоммиченные правки (не из этой сессии) — отметь как чужие, не коммить.
2. Если задача закончена: строка в `docs/tokens.md` (ячейка «Токены» — вывод `python3 tools/tokens.py --line`, без «≈»), закоммить вместе с итоговыми доками.
3. Запиши `.claude/handoff.md` (не в git) — не больше ~40 строк, только то, чего нет в `CLAUDE.md` и доках:

```markdown
# Передача дел · <дата> · <ветка> · v<N>

**Задача:** <одна-две строки, как её поставил автор>
**Сделано:** <пункты; коммиты — коротким хешем>
**Дальше:** <следующий конкретный шаг первым пунктом>
**Где смотреть:** <файл:строка — только нужное для следующего шага>
**Решения автора:** <что автор выбрал и что отверг в этой сессии>
**Грабли:** <что не сработало и почему>
**Не закоммичено:** <файлы; чьи>
```

4. Скажи автору одной строкой: «Передача дел записана — делай `/clear`». Больше ничего не делай.
