# touch2decay

Эзотерический дрон / нойз-синт для пальцев. Работает в браузере (iPhone, Safari), без сборки и зависимостей: Web Audio + canvas.

## Как играть

На поле нет надписей — только кружки и их отклики. Подписи (на английском) появляются только в меню.

- **Коснись поля** — появляется кружок и звучит. Влево–вправо — высота (55–880 Гц, плавное скольжение). Вниз — тёмный и чистый, вверх — ярче, грязнее, с шумом.
- **Отпусти** — звук тянется хвостом и гаснет. Коснуться гаснущего кружка — оживить его.
- **Двойной тап** по кружку закрепляет его. Двойной тап по закреплённому — отпускает. Закреплённый кружок можно поймать и перетащить.
- **Второй палец на другой кружок** — мост: тот, кого коснулся первым, слушает второго (FM). Разведи пальцы — глубже, сведи почти в ноль — связь разорвана.
- **Второй палец на пустое место** — ещё один кружок.
- **Держи палец на кружке** (~0.4 с) — кольцо свойств. Веди палец по лучу: дальше от центра — больше; вернул в центр — отмена.
  - **wave** — triangle, sharp, saw, pulse, fold (свои циклы с аналоговым характером; закреплённый кружок показывает свою волну);
  - **cutoff** — срез фильтра, ±3 октавы поверх оси Y;
  - **res** — резонанс фильтра;
  - **detune** — от медленного фазирования до треска биений;
  - **fm** — модулятор кружка гнёт его же тон.
- **LFO.** Пока палец крутит параметр (луч кольца) или держит/тащит кружок, сверху появляется панель LFO: sine, tri, square, s&h. Второй палец на форму — LFO подключён к этому параметру (у кружка без кольца — к высоте). Тянешь второй палец вниз — глубина, вбок — скорость. Тап по уже включённой форме — выключить. Каждый LFO виден точкой на орбите вокруг кружка.
- До 8 кружков одновременно.

### Кнопки

- **Справа внизу — FX.** Держишь — веер: **hall** (посыл в зал, сухой звук не тише), **decay** (0.6–14 с), **delay**, **repeats**, **drive**.
- **Слева внизу — лад.** Держишь — список: major, minor, dorian, phrygian, lydian, mixolydian и **off**. Выбранный лад остаётся включённым: все кружки, и новые тоже, встают на его ноты (от ля). Короткий тап по кнопке — выключить/включить лад.
- **Справа вверху — убрать всё.** Все кружки, включая закреплённые, гаснут за секунду.

Лучше в наушниках.

## Деплой на Vercel

Статический сайт, сборка не нужна: Vercel → Add New → Project → импортировать этот репозиторий → Framework Preset: **Other**, Build Command пустой, Output Directory — корень. Каждый пуш в `main` выкатывается сам.

На айфоне: открыть адрес в Safari → «Поделиться» → «На экран Домой» — запускается на весь экран, как приложение.

## Устройство звука

Каждый кружок: пара осцилляторов со своими волнами (циклы посчитаны из аналоговых форм и превращены в спектр), разведённая по стерео и сдвинутая на detune, саб октавой ниже. Строй каждого осциллятора плавает медленно и дрожит быстро (отфильтрованный шум, ±3 цента) — аналоговая нестабильность. Дальше перегруз и фильтр, который сам гуляет, полоса шума на гармонике, тихая гребёнка, настроенная на высоту, и чуть дышащая громкость. Синус-модулятор даёт собственную FM и служит источником для мостов.

Общая шина: drive → сухой звук на выход как есть. Поверх — посылы: стерео-дилей крест-накрест с плавающим временем и зал из четырёх линий задержки с перекрёстной обратной связью (вход зала срезан снизу, чтобы бас не мутил хвост). Дальше компрессор и мягкий лимитер.

Все диапазоны и палитра — константы в начале `app.js`.
