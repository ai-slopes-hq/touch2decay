# touch2decay

Эзотерический дрон / нойз-синт для пальцев. Работает в браузере (iPhone, Safari), без сборки и зависимостей: Web Audio + canvas.

## Как играть

На поле нет надписей — только кружки и их отклики. Подписи появляются только в кольце свойств.

- **Коснись поля** — появляется кружок и звучит. Влево–вправо — высота (55–880 Гц, плавное скольжение). Вниз — тёмный и чистый, вверх — ярче, грязнее, с шумом.
- **Отпусти** — звук не обрывается, тянется хвостом и гаснет. Коснуться гаснущего кружка — оживить его.
- **Двойной тап** по кружку закрепляет его — звучит без рук. Двойной тап по закреплённому — отпускает, и он гаснет. Закреплённый кружок можно поймать и перетащить.
- **Второй палец на другой кружок** — мост. Между пальцами ДНК-спираль, кружки стоят на месте. Тот, кого коснулся первым, слушает второго (FM). Разведи пальцы — связь глубже, сведи почти в ноль — разорвана. Отпустил — связь осталась пунктиром.
- **Второй палец на пустое место** — просто ещё один кружок.
- **Держи палец на кружке** (~0.4 с) — кольцо свойств из пяти лучей. Веди палец по лучу: дальше от центра — больше. Вернуть палец в центр и отпустить — отмена.
  - вверх — **волна**: синус, треугольник, пила, меандр (метка в закреплённом кружке повторяет форму);
  - вправо — **хвост**: затухание от ~1 до ~24 с;
  - вправо-вниз — **детюн**: от медленного фазирования до треска биений;
  - влево-вниз — **FM**: саб кружка гнёт его же основной тон;
  - влево — **резонанс**: гребёнка, настроенная на высоту кружка.
- **Левый край — карман «дрожь»** (LFO). Затащи кружок к левому краю: он прилипает, звучит как раньше и дрожит по высоте и громкости. Выше по полосе — быстрее (от 0.06 до ~15 Гц). Вытащи на поле — дрожь снята.
- До 8 кружков одновременно.

Лучше в наушниках.

## Деплой на Vercel

Статический сайт, сборка не нужна: Vercel → Add New → Project → импортировать этот репозиторий → Framework Preset: **Other**, Build Command пустой, Output Directory — корень. Каждый пуш в `main` выкатывается сам.

На айфоне: открыть адрес в Safari → «Поделиться» → «На экран Домой» — запускается на весь экран, как приложение.

## Устройство звука

Каждый кружок: пара осцилляторов, разведённая по стерео и сдвинутая на детюн, саб октавой ниже, у каждого осциллятора свой медленный дрейф строя. Дальше перегруз и фильтр, который сам гуляет, полоса шума на гармонике, гребёнка-резонатор, настроенная на высоту, и чуть дышащая громкость. Синус-модулятор даёт собственную FM и служит источником для мостов.

Общая шина: мягкий перегруз → стерео-дилей крест-накрест с плавающим временем → зал → компрессор.

Все диапазоны и палитра — константы в начале `app.js`.
