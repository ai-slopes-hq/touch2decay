# touch2decay

Эзотерический дрон / нойз-синт для пальцев. Работает в браузере (iPhone, Safari), без сборки и зависимостей: Web Audio + canvas.

## Как играть

На поле нет надписей — только кружки и их отклики. Оси нарисованы фоном: ряды волн слева редкие, справа частые (высота); внизу гладкие, вверху рассыпаются в шум (характер). Риски внизу — ноты ля. Подписи (на английском) появляются только в меню.

- **Коснись поля** — появляется кружок и звучит. Влево–вправо — высота (55–1760 Гц, плавное скольжение; как у эквалайзера, нижним октавам больше места). Вниз — чистые тёмные колебания без перегруза, вверх — фильтр раскрывается, перегруз растёт, шум вытесняет тон.
- **Отпусти** — звук тянется хвостом и гаснет. Коснуться гаснущего кружка — оживить его.
- **Двойной тап** по кружку закрепляет его. Двойной тап по закреплённому — отпускает. Закреплённый кружок можно поймать и перетащить.
- **Второй палец на другой кружок** — мост: тот, кого коснулся первым, слушает второго. Разведи пальцы — глубже, сведи почти в ноль — связь разорвана.
- **Ручка на середине связи** (ромб) — кольцо связи: **fm** (экспоненциальная, до ±2 октав), **tzfm** (линейная, сквозь ноль, индекс до 5 от частоты источника), **am**, **rm**; расстояние по лучу — глубина. Луч **cut**: дотянуть и отпустить — связь удалена.
- **Второй палец на пустое место** — ещё один кружок.
- **Держи палец на кружке** (~0.4 с; вокруг дорисовывается дуга) — кольцо свойств. Веди палец по лучу: дальше от центра — больше; вернул в центр — отмена.
  - **wave** — плавный морфинг по таблицам triangle → sharp → saw → pulse → fold (свои циклы с аналоговым характером; закреплённый кружок показывает текущую форму);
  - **cutoff** — срез фильтра от 40 Гц до 18 кГц (ось Y ведёт его ещё на ±2.25 октавы; пока на кружке есть FM, фильтр приоткрывается, чтобы были слышны боковые полосы);
  - **res** — резонанс фильтра;
  - **detune** — от медленного фазирования до треска биений;
  - **fm** — модулятор кружка гнёт его же тон.
- **LFO.** Пока палец крутит параметр (луч кольца) или держит/тащит кружок, сверху появляется полоса LFO — те же таблицы с тем же морфингом. Второй палец на полосу: место касания — форма LFO, тянешь вниз — глубина, вбок — скорость. Подключается к тому, что крутишь (у кружка без кольца — к высоте; на луче wave — к морфингу волны). Увёл глубину в ноль — LFO снят. Каждый LFO виден точкой на орбите вокруг кружка; LFO на высоте качает сам кружок по полю.
- **Выделенная группа** (см. карандаш) правится целиком: кольцо свойств и LFO применяются ко всем выделенным кружкам.
- До 8 кружков одновременно. Молчащие кружки отключены от звукового графа; если устройство начинает тормозить, допустимое число кружков временно снижается.

### Кнопки

- **Справа внизу — FX.** Держишь — веер: **hall** (посыл в зал, сухой звук не тише), **decay** (0.6–14 с), **delay**, **chaos** (слабые случайные связи между звучащими кружками, которые сами меняются — как общий MOD у Лиры), **drive**.
- **Слева внизу — лад и карандаш.** Держишь — список: major, minor, dorian, phrygian, lydian, mixolydian и **off**. Справа от списка — тоники (A…G#). Лад выбирается задержкой пальца на строке, поэтому пролёт по списку ничего не меняет. Выбранный лад остаётся включённым: все кружки, и новые тоже, встают на его ноты. Короткий тап по кнопке — выключить/включить лад.
  Держишь и ведёшь палец **вправо** вдоль низа — карандаш: обведи кружки, они выделятся (бегущий пунктир). Тащишь любой выделенный — едут все вместе. Пустая обводка снимает выделение.
- **Справа вверху — убрать всё.** Все кружки, включая закреплённые, гаснут за секунду.

Лучше в наушниках.

## Деплой на Vercel

Статический сайт, сборка не нужна: Vercel → Add New → Project → импортировать этот репозиторий → Framework Preset: **Other**, Build Command пустой, Output Directory — корень. Каждый пуш в `main` выкатывается сам.

На айфоне: открыть адрес в Safari → «Поделиться» → «На экран Домой» — запускается на весь экран, как приложение, и работает без сети (сервис-воркер). Новая версия после деплоя подхватывается со следующего запуска.

## Устройство звука

Каждый кружок: пара генераторов с морфингом по таблицам (циклы посчитаны из аналоговых форм и превращены в спектры; на каждую таблицу свой осциллятор, веса — из позиции морфинга прямо в звуковом графе), разведённая по стерео и сдвинутая на detune, саб октавой ниже. Строй каждого осциллятора плавает медленно и дрожит быстро (отфильтрованный шум, ±3 цента) — аналоговая нестабильность. Дальше перегруз и фильтр, который сам гуляет, полоса шума на гармонике, тихая гребёнка, настроенная на высоту, и чуть дышащая громкость. Синус-модулятор даёт собственную FM и служит источником для мостов.

Общая шина: drive → сухой звук на выход как есть. Поверх — посылы: стерео-дилей крест-накрест с плавающим временем и зал из четырёх линий задержки с перекрёстной обратной связью (вход зала срезан снизу, чтобы бас не мутил хвост). Дальше компрессор и мягкий лимитер.

Все диапазоны и палитра — константы в начале `app.js`.
