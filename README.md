# touch2decay

Эзотерический дрон / нойз-синт для пальцев. Работает в браузере (iPhone, Safari), без сборки и зависимостей: Web Audio + canvas.

## Как играть

- **Коснись поля** — появляется кружок и звучит. Влево–вправо — высота (27.5–220 Гц, плавное скольжение). Вниз — чистый низкий тон, вверх — рассыпается в шум.
- **Отпусти** — звук не обрывается, тянется хвостом и гаснет.
- **Второй палец** присоединяется к кружку: расстояние между пальцами — расстройка и биения, наклон линии — резонанс (обратная связь гребёнки, настроенной на высоту). Середина между пальцами ведёт себя как один палец.
- **Холд** (кнопка внизу): держишь кружок пальцем и жмёшь — кружок закреплён и звучит без рук. Поймать закреплённый кружок снова и нажать холд — он отпускается и гаснет. Закреплённый кружок можно поймать и перетащить.
- До 8 кружков одновременно.

Лучше в наушниках. На динамике айфона низов почти нет — их вытягивает сатурация на общей шине.

## Деплой на Vercel

Статический сайт, сборка не нужна: Vercel → Add New → Project → импортировать этот репозиторий → Framework Preset: **Other**, Build Command пустой, Output Directory — корень. Каждый пуш в `main` выкатывается сам.

На айфоне: открыть адрес в Safari → «Поделиться» → «На экран Домой» — запускается на весь экран, как приложение.

## Устройство звука

На каждый голос: две группы осцилляторов (пила + синус-саб + квинта; вторая группа сдвинута на частоту биений), медленный дрейф строя, узкополосный шум, привязанный к высоте, гребёнчатый резонатор с tanh в петле, фильтр. Общая шина: сатурация → срез инфразвука → компрессор.

Все диапазоны и палитра — константы в начале `app.js`.
