# core — ядро звука на C++

Одно ядро на мир: собирается нативно (render-cli сейчас, iOS-приложение и AUv3 потом) и в WASM — его крутит AudioWorklet в вебе. План — `docs/native-plan.md`, фаза 0а — `docs/superpowers/specs/2026-10-22-native-0a-goetia-wasm-design.md`.

- `worlds/goetia/` — Goetia (bytebeat): звук (`goetia.cpp`, порт прежнего `goetia-worklet.js`), модель (`model.cpp`), мир SDK (`world.cpp`: эхо на `sdk::TapeEcho`, шина); в вебе — внутри `t2d.wasm` (слот 15); эталон звука — `tools/ref/goetia-worklet.js`, модели — `tools/ref/goetia-model.js`, шины и эха — `busRef` в `tools/goetia-scenarios.mjs`.
- `worlds/cymatica/` — Cymatica (этапы 1–3): модель — узор, луна, запись игрой, кубик, отзыв, закреплённые смычки (`model.cpp`; `Sink` в пластину), эхо (пары `sdk::PingPong`) и гул резонатора (`sdk::AD`) в `world.cpp`, пластина и часы секвенсера (`plate.cpp`), мир SDK (`world.cpp`: посыл в plate-ревербер); в вебе — внутри `t2d.wasm` (слот 2); эталон — `tools/ref/plate-worklet.js` (ГСЧ с зерном), сверка — `tools/test-cym-core.mjs`. `build-wasi.sh` — запасная сборка `t2d.wasm` через wasi-sdk (без emscripten).
- `worlds/portus/` — Portus (этапы 1–2: модель, звук и часы): модель (`model.cpp` — кораблики, луна, эхо, буй, туман, маяк, лад хоста), стабы на `sdk::Saw`, шина, эхо `sdk::PingPong`, туман, море, шаги `sdk::Steps` (`world.cpp`; действия фасада `worlds/portus/model.js`); в вебе — внутри `t2d.wasm` (слот 13); сверка — `tools/portus-bus.py` с прежним движком `tools/ref/portus-engine.js`, нативно — `core/build/portus-cli`.
- `worlds/natura/` — Natura (этапы 1–2: звук, часы и модель — кувшинки, fx, снимок JSON; фасад — `worlds/natura/model.js`): `model.cpp` (кувшинки и их правки, шаг, голос ноты, высота по ладу хоста, время задержки, snapshot / restore), `wave.hpp` (пять band-limited волн), `world.cpp` (ноты, кораблик, лазер, лягушка, шелест, шина: срез дерева → хор `sdk::Chorus` моно → лента `sdk::TapeEcho` → зал, шаги `sdk::Steps`); в вебе — внутри `t2d.wasm` (слот 4); сверка — `tools/natura-bus.py` с прежним движком `tools/ref/natura-engine.js`, нативно — `core/build/natura-cli`.
- `worlds/inferno/` — Inferno (шум сквозь банк резонаторов, девять кругов): модель (`model.cpp`), звук (`sound.cpp`), мир SDK (`world.cpp`, слот 5); в вебе — внутри `t2d.wasm`; эталон модели — `tools/ref/inferno-model.js`, эталон звука — прежний `engine.js` на Web Audio — `tools/ref/inferno-engine.js`: сверка — `tools/inferno-compare.py`, нативный рендер — `render-cli/inferno.cpp`.
- `worlds/firmamentum/` — Firmamentum (пульсарный синтез): модель (`model.cpp`), звук (`sound.cpp`), мир SDK (`world.cpp`); в вебе — внутри `t2d.wasm`; эталон звука — `tools/ref/pulsar-worklet.js` (тот же JS, но со своим генератором случайных чисел с зерном — иначе не с чем сверять), эталон модели — `tools/ref/firmamentum-model.js`.
- `worlds/monochord/` — Monochordum (Карплус — Стронг): звук (`sound.cpp`, порт прежнего `monochord-worklet.js`), модель (`model.cpp`), мир SDK (`world.cpp`: дека, хор, посыл, автострам на `sdk::Steps`); в вебе — внутри `t2d.wasm` (слот 7); эталоны — `tools/ref/monochord-worklet.js` (ГСЧ с зерном), `monochord-model.js`, `monochord-engine.js` (шина Web Audio).
- `worlds/horologium/` — Horologium (колесо и кольца): звук (`sound.cpp`, порт прежнего `horo-worklet.js`), модель (`model.cpp`: кольца, fx, ход часов), мир SDK (`world.cpp`: замок к такту по сетке хоста, шина); в вебе — внутри `t2d.wasm` (слот 9); маятник — в фасаде веба; эталоны — `tools/ref/horo-worklet.js` (ГСЧ с зерном), `horologium-model.js`; сверка — `tools/horo-scenarios.mjs`, `tools/test-horo-core.mjs` (1e-6, ход часов, замок).
- `worlds/arcadia/` — Arcadia (синтез по рельефу): страна (`land.cpp` — порт `genLand`, растёт по кускам: 59 блоков, `jsHypot` — `Math.hypot` V8), модель (`model.cpp`: странники, пути, нота, снимок), звук (`sound.cpp`, порт прежнего `terrain-worklet.js`), мир SDK (`world.cpp`: фейзер, хор, посыл); в вебе — внутри `t2d.wasm` (слот 12); эталоны — `tools/ref/terrain-worklet.js` (ГСЧ с зерном), `arcadia-model.js`, `arcadia-engine.js`; сверка — `tools/arcadia-scenarios.mjs`, `tools/test-arcadia-core.mjs`, шина — `tools/arcadia-bus.py`.
- `worlds/tria/` — Tria corpora (задача трёх тел), первый мир на узлах Web Audio: модель (`model.cpp`: порт прежней JS-модели, шаг — блок), мир SDK (`world.cpp`: дрон с FM по кругу, колокола, тимпан, шорох, шина — на `sdk::Param`); в вебе — внутри `t2d.wasm` (слот 11); эталоны — `tools/ref/tria-model.js`, `tria-engine.js`; сверка — `tools/tria-scenarios.mjs`, `tools/test-tria-core.mjs` (модель), `tools/tria-bus.py` (звук против прежней Web Audio).
- `sdk/` — блоки (фильтры, задержки, эхо `TapeEcho`, струна `KsLoop`, хор `Chorus`, фейзер `Phaser`, панорамы `panLin` / `panEq` / `PanStereo`, `Rng`, ревербы `room` / `plate` / `hall` / `cathedral`; для миров на узлах — `Param` (таймлайн AudioParam: set / lin / exp / target / cancel по сэмплу, семантика Chromium), `Osc` (синус, треугольник PolyBLAMP), `Shaper<N>` (кривая WaveShaperNode), `TanhShaper` (нормированный tanh, oversample 2×), `BpBank` (банк полос BP), `Noise` (шумы-цвета); числа как в V8 — `jsmath.hpp`: `jsHypot`, `jsRound`, `jsClamp`), транспорт (`transport.hpp`: разбор MIDI-часов `ClockParser`, сетка `Follower`, шагомер секвенсера `Steps`) и интерфейс мира `World` (`attach` — часы хоста); `host/` — хост ядра (миры, посылы после фейдера, четыре общих ревербера, лад, время блока, MIDI-часы — одна сетка на все миры, события часов для веба); `bridge/wasm.cpp` — вход `t2d.wasm`. Миры на Web Audio шлют в ревербы хоста через `T.send(rev)` (`host/audio.js`) — своего зала у них нет.
- `worlds/tenebrae/` — Tenebrae (мир I, только звук, слот 1): мир SDK (`world.cpp`: действия `VOICE/ON/OFF/LIVE/LINKS/LFO/FX/STRIKE/CLEAR`, шина `1/√Σenv`, эхо `PingPong`, удар солнца, зеркало контуров), голос (`voice.cpp`: генераторы, фильтры, гребёнка, связи, LFO, перегруз), таблицы волн по октавам (`waves.cpp`, формы — `sdk/waveforms.hpp`), Hilbert-сдвиг (`shifter.hpp`); модель и рисование — в вебе (`app.js`), клей — `worlds/tenebrae/engine.js`; эталон звука — `tools/ref/tenebrae-engine.js` (прежний Web Audio), нативный `core/build/tenebrae-cli`; что осталось другим — `docs/worlds/tenebrae.md`, «Ядро: отличия».
- `worlds/oceanus/` — Oceanus (сканирующий синтез): звук (`ocean.cpp`, порт прежнего `ocean-worklet.js`), модель (`model.cpp`), мир SDK (`world.cpp`); в вебе — внутри `t2d.wasm` (слот 8); эталон звука — `tools/ref/ocean-worklet.js` (тот же JS со своим генератором случайных чисел с зерном), модели — `tools/ref/oceanus-model.js`.
- LFO хоста (`host/`, `app/`): таблица LFO по правилам `host/sl.js` для строк плашек (FX мира — `obj` −1, объекты мира — по id); команды слота хоста в кольце действий `T2D_H_LFO_ADD=3`, `SPEC`, `BASE`, `OFF`, `DROP=7` (`T2D_H_LFO_*`, `core/app/t2d_app.h`), `ACT_LFO` — действие мира, куда хост передаёт значение строки (у Oceanus — `i == -1`, ключ FX в `NKEY..NKEY+NFX`); Monochordum: все LFO — строки мира (`obj` −1), код `ACT_LFO`: FX 0…6, ветер 7, strength 8, swing 9, строка k струны i — `10 + 4·i + k`; Horologium: FX 0…4, кольцо i — фаза `5 + 2·i`, уровень `6 + 2·i` (все строки мира, `obj` −1; строки без LFO — код −1); `DICE` (кубик) — действие ядра у Monochordum и Horologium (у Horologium — 8, на `sdk::Rng`: броски отличаются от веба); строки без LFO (tempo, rate, pattern земли) идут с кодом −1, потому что хост сопоставляет LFO строк по `code`, не сверяя `lfo.keys`, и совпавший код дал бы чужой LFO; `World.rowLfoOff` (Swift) снимает LFO строки мира; `t2d_restore` гасит LFO объектов мира (строки FX остаются), `t2d_app_lfo` — снимок таблицы (по 10 чисел), `t2d_app_scale_steps` — шаги лада хоста (7 ступеней, иначе пусто; их берёт `World.scale(pcs:root:)` у `Host`), `t2d_app_lfo_sample` — форма LFO по фазе (для рисования пада), `lfo_lost` в `t2d_app_stats` — LFO, не поместившиеся в таблицу хоста (64). Из-за слота LFO `Engine::RESTORE` стал 8 (был 3). Тесты — `core/tests/sdk_test.cpp` (`hostLfo`, `lfo*`).
- `bridge/` — вход ядра: `api.cpp` + `t2d.h` — общий C-ABI (миры, действия, мастер, `t2d_sum` / `t2d_master_run` / `t2d_mix`, MIDI), его берут и `wasm.cpp` (`t2d.wasm` для веба), и приложение iOS (статическая библиотека). Микс и мастер повторяют веб-цепочку (`host/audio.js`): сумма миров → highpass → lowpass 20 кГц → компрессор → колено → потолок; сверка — `tools/master-bus.py`; нативно — `core/build/mix-cli` (`core/tests/mix_cli.cpp`).
- `app/` — ядро нативного приложения (только iOS, в `t2d.wasm` не идёт): `engine` (кольцо действий `spsc.hpp` от UI-потока к аудиопотоку, рендер блоками ≤ 128, зеркало и буфер heard, статистика загрузки и задержки касание → блок), `t2d_app.h` — C API (`t2d_app_init` — только пока аудио остановлено, `t2d_app_render`, `t2d_app_action`, `t2d_app_mirror`, `t2d_app_heard`, `t2d_app_stats`). В аудиопотоке — без аллокаций, блокировок и `printf`. Нативный хост (`ios/app`): у `World` есть `enter()` (зовут `goWorld` / `go`) и `scale(pcs:root:)` (`Host.pushScale`); если лад не общий, первый вход в мир применяет лад его сцены. Правка только в `core/app/` не меняет wasm — коммит с `[no-wasm]`.
- `render-cli/` — офлайн-рендер по текстовому сценарию (stdin) в float32 (stdout), для сверки с JS.

## Сборка

```
core/build.sh
```

Собирает `core/build/render-cli`, `core/build/sdk-test`, `core/build/param-cli` (для `tools/param-check.py`), `core/build/tenebrae-cli` (для `tools/tenebrae-bus.py`) и `t2d.wasm` (в корень репозитория, рядом с `t2d-worklet.js`; он лежит в git — страница без сборщика). Нужны Apple clang (Xcode) или любой clang++ с C++17 и emscripten (`brew install emscripten`; на Mac с Rosetta-терминалом — `arch -arm64 brew install emscripten`; в облачной сессии свежий emsdk не скачивается — подходит emscripten 3.1.6 из apt: `build.sh` сам берёт `TOTAL_STACK` вместо `STACK_SIZE`, своя ловушка `_Exit` в мосте не даёт libc++ притянуть импорт WASI). WASM — standalone, без импортов и рантайма emscripten: обёртка зовёт `_initialize`, затем `t2d_*`. Флаг `-ffp-contract=off` обязателен: иначе `a*b+c` склеивается в FMA и звук расходится с JS и WASM.

## Сверка

```
core/build.sh && node --test tools/test-goetia-core.mjs tools/test-firm-core.mjs tools/test-ocean-core.mjs tools/test-mono-core.mjs tools/test-horo-core.mjs tools/test-arcadia-core.mjs tools/test-tria-core.mjs tools/test-transport.mjs
```

Сценарии — `tools/goetia-scenarios.mjs`: одни и те же сообщения в эталонный JS-worklet и в render-cli (звук), а ниже (`ACTS`) — действия модели в эталонный путь (JS-модель → сообщения прежнего engine → эталонный worklet → шина с эхом) и в `t2d.wasm` (слот 15): допуск 1e-6 на каждый сэмпл, на `t` и громкость духа, снимок — тот же JSON. Firmamentum — `tools/firm-scenarios.mjs`, `tools/test-firm-core.mjs` (эталон звука ↔ render-cli) и `tools/test-sdk.mjs` / `tools/test-t2d-worklet.mjs` (SDK и `t2d.wasm`), допуск 1e-6; случайность (jit, crepitus, fulgur, маска) идёт от зерна, его даёт engine (`processorOptions.seed`). Скорость (60 с, шесть звёзд, crepitus + fulgur): JS 1645 мс, WASM 107 мс — в ~15 раз (замер до переезда в `t2d.wasm`). Тест статистический, идёт около минуты. Oceanus — `tools/ocean-scenarios.mjs`, `tools/test-ocean-core.mjs`: то же, допуск 1e-6 на сэмплы, форму кольца `x` (64), `moon` и уровни голосов; зерно звука — зерно мира от хоста (`^ 0x85EBCA6B`). Скорость до переезда в `t2d.wasm` (60 с звука): JS 6819 мс, WASM 331 мс — в ~20 раз. Monochordum — `tools/mono-scenarios.mjs`, `tools/test-mono-core.mjs`: сухие струны (дека и хор ×0) против эталонного worklet — 1e-6 на сэмпл (на деле бит в бит), энергия струн и флажолетов каждый блок, снимок; автострам ядра — шаги по сэмплу, swing, деления, сетка MIDI. Шина (дека, хор) против прежнего Web Audio — `tools/mono-bus.py` в браузере (OfflineAudioContext): RMS ± 0.0004 дБ. Скорость (6 с): JS-worklet 1.4 с, `t2d.wasm` целиком (хост, 4 мира) 0.33 с. Транспорт — `tools/test-transport.mjs`: одни и те же байты MIDI-часов в прежний JS (`tools/ref/midi.js`) и в ядро — та же сетка (1e-9) после каждого блока и запуск миров на той же доле. Arcadia — `tools/arcadia-scenarios.mjs`, `tools/test-arcadia-core.mjs`: сухой выход (фейзер и хор 0) против эталонного worklet — 1e-6 на сэмпл, центры петель и уровни каждый блок, снимок; новая страна в эталоне приходит через те же 59 блоков, что растёт в ядре; страна ядра против `genLand` — бит в бит; блок с куском страны — ≤ 1/8 реального времени. Шина (фейзер, хор) против прежнего Web Audio — `tools/arcadia-bus.py`. Скорость (сценарий `all`, ~10 с): JS ≈ 4.5 с, `t2d.wasm` целиком ≈ 0.6 с. Tria — `tools/tria-scenarios.mjs`, `tools/test-tria-core.mjs`: модель ядра против прежней JS (шаг — блок 128) — тела, pairK, trem, флаги каждый блок до 1e-9 (на деле 2e-16), вспышки — те же в том же блоке, снимок; звук — `tools/tria-bus.py` в браузере: прежний engine с эталонной моделью (шаг по кванту через `suspend`) против ядра, эталон — 4 прогона (у браузера место разрыва петли FM — случайное на контекст), RMS ≤ 0.11 дБ, октавы ≤ 0.4 дБ от разброса. `sdk::Param` против AudioParam — `tools/param-check.py` (11 сценариев, 1e-6). Тесты моделей Goetia, Oceanus, Monochordum, Horologium, Arcadia и Tria (`tools/models/*.test.mjs`) идут дважды: против эталонной JS-модели и против ядра через фасад веба (`tools/models/sdk-facade.mjs`).
