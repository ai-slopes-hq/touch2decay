# Фаза 2b-1 (iOS): отложенное, решения, непроверенное

Выжимка из журнала ревью 2b-1 (28.10.2026; сам журнал не хранится). Спека — `docs/superpowers/specs/2026-10-28-ios-2b1-design.md`, план — `docs/superpowers/plans/2026-10-28-ios-2b1.md`, общий план — `docs/native-ios-plan.md`, прошлая фаза — `docs/ios-2a-deferred.md`. Всё ниже — мелочи, не блокирующие 2b-2, если не сказано иное.

## Не проверено на iPhone (условия «Готово» спеки)

- Верхняя строка выглядит как в вебе (в симуляторе — по парам снимков, на экране iPhone не смотрели).
- Громкость тянется без треска (сглаживание в ядре 0.03 с — на слух не проверено).
- Смена лада слышна; кубик и корзина работают.
- Undo откатывает и звёзды, и лад (звёзды — проверено в симуляторе на живом ядре, `-shot undo`; лад — только тестами).
- После выгрузки приложения из переключателя и запуска сцена и громкость на месте (восстановление из `Application Support/`).
- В панели замеров время снимка и загрузка рендера в норме (снимок мира аллоцирует на аудиопотоке — замер на устройстве).
- Принятое отклонение: restore идёт на аудиопотоке и аллоцирует (`t2d_restore` → `std::string` + разбор JSON мира, `core/app/engine.cpp:75-80`, `api.cpp:349`) — против ограничения «аллокация только внутри `t2d_snapshot`»; этого требует дизайн спеки; в замерах не учтено — померить на iPhone.
- Касание в симуляторе не вводилось жестом: тап и undo в `-shot undo` идут через `Host.down/up`, не через `Stage`.

## Расхождения со снимками веба (приняты)

- Верхняя полоса: плоская (paper 0.55 до top+44) вместо веб-затухания 0.85→0.55→0 до top+64 — градиенты запрещены. Подпись лада на top+46 за полосой, но читается (проверено на снимке `ios-topbar`); если на устройстве потеряется — ступенчатые полосы.
- ~~Кольцо FX без дуги громкости эффектов~~ — закрыто в 2b-2 (`fxArc`, `fxHeld`); undo без точек истории — по-прежнему не в `TopBar.State`.
- Вспышка кнопки undo при записи шага истории — не перенесена (нет в `TopBar.State`).
- Приглушение корзины, пока мир звучит («sounding»), — не перенесено.
- ~~Подсветка нажатия на стрелке назад и кубике~~ — закрыто: у FX, стрелки и кубика подсветка есть (`fxHeld`, `backHeld`, `diceHeld`).
- Хеш сборки в замерах не появляется (шаг сборки не пишет `T2DBuildHash`).
- Список ладов — тап-открыть / тап-выбрать, в вебе — зажать-вести-отпустить; короткий тап по включённому ладу в вебе его выключает.
- Пара снимков легенды: в вебе `firmtop-legend` с включённым dorian, в iOS сцена легенды с `Scl.off` (подпись отличается).
- ~~Стрелка назад и предмет в углу приглушены~~ — закрыто в 2b-3а (стрелка, угол и край ведут на карту). FX яркая и открывает веер (закрыто в 2b-2).
- В снимке `-shot` undo приглушён: сцена строится без жеста, история пуста.

## Ядро (core)

- `core/host/host.hpp:51`: `vol()` без `isfinite` / проверки отрицательных (NaN отравит `volNow_`); `host.cpp:146`: `volNow_` может уйти в денормалы после долгого нуля.
- Тест `hostVolSmooth` смотрит только состояние, не масштаб выхода на `volNow_`.
- `Host::prepare` сбрасывает громкость в 1.0 при повторном init — iOS применяет заново (`Host.reapply`); `t2d_app_init` не сбрасывает лад хоста.
- `core/app/engine.cpp`: ветка restore при полном кольце действий, но со свободной строкой, не покрыта; `RESTORE=3` достижим через публичный `t2d_app_action(T2D_HOST,3)` без парной строки; `Engine::STR == t2d_str_cap()` проверяется только в рантайме (можно `static_assert`).
- Тест `appHostVolScale`: мёртвые параметры лямбды `run`; отключение лада через кольцо (`a[0]=0`) не проверено.

## Swift: Host

- `Host.swift:84-87`: при мультитаче `.list` выбирает без проверки `sclOpen`, `.title` переключает по текущему `legendOpen`.
- `Host.swift:50,89`: один слот `volF` — второй палец на громкости перетирает первый.
- `Host.shotState` — только для `-shot`.

## Swift: TopBar / Legend

- `TopBar.State.hasFx` не читается (`rev` всегда приглушён) — нужен комментарий; нет приглушения кубика без `hasDice` (у Firmamentum кубик есть).
- Заголовок может превысить `tmax = 59` на минимуме 14 pt (заголовок выигрывает наложение; комментарий неверен); имя шрифта заголовка дублирует `Draw.font` без проверки; `CTLine` строится до ~15 раз за кадр для длинных названий.
- `testDrawSmoke` проверяет только `tw > 0`.
- `Legend.width` дублирует `TopBar.titleWidth` (кеш + `CTLine`, другой шрифт) — свести к `Draw.measure` с проверкой шрифта; нет PostScript-проверки.
- `Legend.draw(title:)` — фиксированный заголовок «L E G E N D A» (имя приглашает передать название мира); внутри к `top` добавляется +50.
- Тесты глифов и оверлея проверяют только чернила, не направление стрелок и вид скрутки.

## Swift: Undo / Store / Firmamentum

- После прерывания очередь запросов снимка переполняет `snaps_` (ёмкость 2), и новейший ответ теряется — база остаётся устаревшей до следующего жеста (`engine.cpp:58-71`, `Undo.swift:59`). Предложение: хук `Audio.onStart` → Host коммитит один раз; перед `t2d_snapshot` проверять `snaps_.reserve()`. Также `Engine::action` принимает `(T2D_HOST, RESTORE)` без строки — отсекать одной строкой в ядре позже.
- Rebase-снимок undo при работе через Host всегда вытесняется (`endGesture` коммитит сразу после `undoStep`) — лишний снимок на каждый undo.
- `Undo.poll` отдаёт одну базу, если за один проход изменились два слота.
- `Undo.pending` растёт с неотвеченными и вытесненными запросами; ответ с чужим слотом съедает запись; записи, потерянные из-за `t2d_app_init`, не удаляются.
- Коммит до прихода ответа на rebase-запрос делает этот жест базой, а не шагом (окно в один оборот, по решению; не покрыто тестом).
- `Store.swift:41`: версия 1 зашита дважды (проверка и значения по умолчанию) — нет общей константы; файл будущей версии с другой формой даёт ошибку разбора, а не «версия N не поддерживается».
- `HostCore.swift:67`: литерал 64 КБ без пометки «= STR ядра»; нет smoke-теста `AppHostCore` (многобайтный restore → `takeSnap` на живом ядре); `Scales` сверены с `host/scale.js` только по числу.
- `FirmamentumView.cornerHit` (солнце → карта) ≠ `inCorner` (угол 44×44 замеров, `Stage`); приглушённое солнце съедает роутер до `world.down` — держать.

## Тесты

- `UndoTests`: `testOtherSlotIsolated` не проверяет слот 1; нет теста commit при `snap` false и шага без смены лада; тест предела не проверяет, что старейший сброшен.
- `StoreTests`: проверяют число строк лога, не текст; нет тестов перезаписи и отказа записи.
- `FirmamentumTests`: нет границ `cornerHit` (y = hy у x солнца; сразу за `r+6`); `testRestoredDropsHolds` не покрывает move после restore и сброс вспышек.
- `HostTests`: нет тестов владения легендой / списком посреди жеста и «undo → 3 с → файл == `undo.last`»; проверка в `HostTests.swift:143` пустая.

# Фаза 2b-2 (iOS): плашки FX и LFO строк — отложенное

Спека — `docs/superpowers/specs/2026-10-30-ios-2b2-design.md`, план — `docs/superpowers/plans/2026-10-30-ios-2b2.md`. Не блокирует 2b-3.

## Не проверено на iPhone

- Плашки выглядят как в вебе (в симуляторе — по парам `sheet` / `starsheet` / `lfo` ↔ `firmsheet-fx` / `-star` / `-lfo`; жестом в симуляторе не вводилось: плашка открывается через `Host.shotSheet`, не касанием).
- LFO на слух: мерцание formant звезды, FX-строки; RMS в симуляторе гуляет, на устройстве не слушали.
- Удержание звезды открывает плашку, пад и полоса форм ведутся пальцем, закрытая звезда снимает свой LFO.

## Отложено

- Ветка формы `classic` на паде (у Firmamentum набор `random`, второй набор нужен мирам со своими плашками).
- Плашки других миров — только Firmamentum (миры 2b-3 и дальше).
- Двойной тап по строке — `reset` (решение 10 спеки): ни у одной плашки Firmamentum его нет, в `SheetSpec` поле есть, жеста нет.
- `-shot` плашек: `Host.shotSheet` / `shotLfo` и замер RMS (`Audio.probe`) нужны только снимкам.

# Фаза 2b-3а (iOS): карта Universum — отложенное

Спека — `docs/superpowers/specs/2026-10-30-ios-2b3a-map-design.md`, план — `docs/superpowers/plans/2026-10-30-ios-2b3a.md`. Сделано на Mac, ждёт iPhone.

## Не проверено на iPhone

## Отложено

- ~~Солнце и concordia на карте приглушены ×0.3~~ — закрыто в 2b-3б (солнце и подпись живые, тап открывает настройки).
- ~~Concordia рисуется и при открытых настройках~~ — закрыто в 2b-3б (`MapDraw.chrome(settings:)` прячет подпись).
- ~~Устаревший «услышанный» пакет (≤ 64 событий) при возврате в мир с карты~~ — закрыто: `World.idle()` сливает кольцо heard на карте и во время перехода.
- ~~Лучи-призраки при возврате на карту~~ — закрыто: `goMap` сбрасывает `Levels`; без свежего снимка дольше 0.3 с уровни считаются нулём (движок встал).
- `reapply` при первом запуске берёт масштаб (лад) из последнего слота — нужно правило до второго нативного мира.
- `Emblems`: статические кеши без синхронизации и вытеснения; ключ кеша не учитывает состояние шрифта.

- `setTheme` вызывается каждый кадр, хотя тема не менялась.
- `Host.goMap` не `private` (нужен тесту); `Undo.poll()` используется только тестами.
- Тесты эмблем проверяют non-nil и размер, а не содержимое.
- Кеш эмблем ищет по строковым ключам каждый кадр.

# Фаза 2b-3б (iOS): concordia, микшер, панель audio — отложенное

Спека — `docs/superpowers/specs/2026-10-30-ios-2b3b-concordia-design.md`. Сделано на Mac, ждёт iPhone.

## Не проверено на iPhone

- Concordia, микшер и панель audio выглядят как в вебе (в симуляторе — по парам `concordia` / `mixer` / `audio` ↔ `startmap` / `nav` / `audiopanel`; касания идут через `Host.down/move/up`, не через `Stage`).
- Фейдеры миров и мастер слышны без треска (сглаживание ядра 0.03 с — на слух не проверено).
- `stable audio` (буфер 1024 вместо 256) и `restart audio` — на USB-интерфейсе не пробовали.

## Отложено

- `shared tempo` в concordia без действия: у миров с часами (Cymatica, Natura) нативных видов ещё нет, переключатель только сохраняется.
- `tempo` в панели audio приглушён с «—» — по той же причине; `stop` работает.
- Строка `midi clock` скрыта (нативного MIDI нет — позже, вместе с Link / MIDI).
- `perScl` (свой лад у каждого мира) живёт в памяти, в `prefs.json` не пишется — как в вебе.
