# iOS 2b-1 — каркас хоста: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** вокруг Firmamentum в приложении — верхняя строка (громкость, лад, кубик, undo, корзина), легенда, undo по снимкам ядра и автосохранение сцены.

**Architecture:** команды хоста — действия слота −1 в общем кольце движка (`core/app/engine.cpp`); снимок — запрос действием и ответ обратным кольцом строк, restore — кольцом строк UI → аудио. В Swift — слой `Host` (`ios/app/T2D/Host/`) между `Stage` и миром: роутер касаний, верхняя строка, легенда, undo, файлы.

**Tech Stack:** C++17 (ядро, тесты `core/tests/sdk_test.cpp`), Swift 5 + UIKit + CoreGraphics, XCTest, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-28-ios-2b1-design.md` — читать целиком перед любой задачей.

## Global Constraints

- Ветка `native`; в `main` не идёт. Коммиты — по-английски, тело-список, `Co-Authored-By` из системной подсказки.
- Ядро: C++17, `-ffp-contract=off`, без блокировок в аудиопотоке; аллокация на аудиопотоке — только внутри `t2d_snapshot`. Комментарии — по-русски, плотность как в `core/app/`.
- Правка `core/host/` или `core/bridge/` → `core/build.sh` (пересобирает `t2d.wasm`) и в том же коммите `t2d.wasm`, новая версия: `CACHE` в `sw.js` = `?v=` в `index.html` (хук `guard.py` проверит). Веб по поведению тот же.
- Новые Swift-файлы — в `ios/app/project.yml`: в `T2D` (папка `T2D` уже целиком) и вручную в `sources` у `T2DTests` (нет TEST_HOST); после — `xcodegen` в `ios/app`.
- Тесты: ядро — `core/build.sh && core/build/sdk-test` → `0 failed`; Swift — `cd ios/app && xcodegen && xcodebuild test -project T2D.xcodeproj -scheme T2D -destination 'platform=iOS Simulator,name=iPhone 16'` (имя — по `xcrun simctl list devices available`) → `** TEST SUCCEEDED **`. Вывод xcodebuild огромный — фильтровать `grep -E "error:|failed|passed|SUCCEEDED|FAILED"`.
- Картинка — перенос `host/ui-top.js`, `host/legend.js` на `Draw.swift` без новых решений; без теней, жирного, градиентов в кадре; заголовок — IM Fell English, легенда и список ладов — EB Garamond, курсив только в подписях.
- Громкость: `VOL_TRAVEL = 220`, `VOL_LO = −48`, `VOL_HI = 6` дБ, ниже 0.005 — `off`, сглаживание в ядре — постоянная времени 0.03 с.
- Undo: 10 шагов на мир; автосохранение — через 3 с после последнего изменившего жеста и сразу при уходе в фон.
- Файлы — в `Application Support/`: `prefs.json` `{v: 1, vol}`, `scene-<слот>.json` `{v: 1, w, scl: {on, idx, root}}`.

## Review Focus

1. **Переинициализация ядра при смене частоты** (`Audio.reset(reinit:)` — наушники с другой частотой): `t2d_app_init` стирает миры и кольца; сцена, лад и громкость должны вернуться сами. Тест — в задаче 9 (`testReinitReappliesScene`).
2. **Undo во время прерывания** (движок стоит, кольцо не крутится): запросы снимков без ответа не должны ломать историю; нажатие undo ставит restore, он применится после старта. Тест — задача 4 (`testUnansweredSnapThenUndo`).
3. **Ответ снимка, выданный до undo, приходит после** — не должен стать шагом или базой. Тест — задача 4 (`testStaleResponseAfterUndoIgnored`).
4. **Палец на приглушённой кнопке / предмете в углу** не должен уйти миру (иначе тап по солнцу Firmamentum поставит звезду). Тест — задача 9 (`testDimmedEatsTouch`).
5. **Битый или чужой версии файл сцены** при запуске → пустой мир и строка в лог, без падения и без restore мусора в ядро. Тест — задача 5 (`testBadSceneIgnored`) и задача 2 (`appRestoreGarbage`).

  ```swift
    static let max = 10
    init(core: HostCore)
    func base(slot: Int, w: String?, scl: Scl)       // начало: w есть — база сразу; nil — следующий ответ снимка станет базой

    func last(slot: Int) -> (w: String, scl: Scl)?
  }
  ```
  Правила: ответ с `id` меньше последнего выданного — отброшен; ответ отличается от базы (`w` или `scl`) → в историю `{w: база.w, scl: база.scl, after: scl запроса}`, база = ответ; история > 10 — выкинуть старейший. `undo`: pop → `core.restore(slot, st.w)`; лад вернуть, если `st.scl != st.after && cur == st.after`; база = `(st.w, итоговый лад)`; все ответы на запросы, выданные до undo, отбрасываются, а ответ на следующий `commit` становится базой без шага.
