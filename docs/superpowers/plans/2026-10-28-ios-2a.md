# iOS-приложение, фаза 2a (вертикальный срез на Firmamentum) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Цель:** нативное `ios/app/` (Swift + CoreGraphics, без WebView) играет Firmamentum из ядра C++ — касание → ядро → звук и картинка — и пишет в лог задержку, загрузку и кадр.

**Архитектура:** мост `core/bridge/` делится на общий `api.cpp` (+ заголовок `t2d.h`) и emscripten-часть `wasm.cpp`; в `Host` появляются полный микс (dry × fader × trim + возвраты) и мастер по цепочке веба — только для приложения. Слой `core/app/` (только нативный) режет буфер устройства на куски по 128, принимает действия UI через SPSC-кольцо и отдаёт зеркало (тройной буфер) и heard (кольцо записей). Swift: `AVAudioSourceNode` зовёт `t2d_app_render`; `UIView` по `CADisplayLink` рисует Firmamentum по зеркалу слоем `Draw.swift` — порт вызовов `host/draw.js`.

**Стек:** C++17 (`-ffp-contract=off`), Swift 5, CoreGraphics, AVAudioEngine, XcodeGen, Xcode 16.2; сверка мастера — Python + Playwright + OfflineAudioContext.

**Спека:** `docs/superpowers/specs/2026-10-28-ios-2a-design.md`

## Review Focus

1. **Буфер устройства не кратен 128 и меняется** (iOS выдаёт 470, 1024 после смены маршрута): звук не должен щёлкать и сдвигаться — `render` с любыми `n` даёт тот же поток, что куски по 128, до бита. Тест `app_chunking` (задача 4).
2. **heard теряется между кадрами:** аудио публикует ~190 раз/с, UI читает 60 — каждая вспышка и искра должны дойти до картинки. Тест `app_heard_accumulates` (задача 4).
3. **Частота 44.1 кГц или смена частоты на ходу** (AirPods, проводные наушники): ядро переинициализируется фактической частотой, звук не меняет высоту. Тест `app_reinit_rate` (задача 4) и `testEngineRestartsOnRateChange` (задача 5).
4. **Звезда исчезла из зеркала, пока палец на ней** (`dice`, закрытие ядром): `move` / `up` по пропавшему id не падает и не шлёт закрытие чужой звезды. Тест `testTouchOnVanishedStar` (задача 7).
5. **Тап по небу при 6 звёздах** (`SMAX = 6`): действие не шлётся, палец не тянет чужую звезду. Тест `testSkyTapWhenFull` (задача 7).

## Общие имена

- C: `t2d_sum(float* L, float* R, int n)`, `t2d_master_run(float* L, float* R, int n)`, `t2d_mix(float* L, float* R, int n)` (= sum + master), `n ≤ 128`.
- `t2d_app.h`:
  ```c
  typedef struct {
    double load_avg, load_max;  // доля длительности буфера, за окно
    double lat_avg, lat_max;    // сек, блок − касание, без outputLatency, за окно
    int lat_n;                  // применённых действий с меткой за окно
    int frames;                 // последний размер буфера устройства
    unsigned dropped;           // действий не влезло в кольцо, всего
    unsigned heard_lost;        // записей heard не влезло, всего
  } t2d_app_stats_t;
  void t2d_app_init(double sr, unsigned seed, double ticks_per_sec, unsigned watch); // watch — маска слотов
  void t2d_app_render(float* L, float* R, int n, uint64_t host_time);
  int  t2d_app_action(int slot, int kind, int i, const double* a, int n, uint64_t touch_time); // 0 — отброшено; touch_time 0 — без замера
  int  t2d_app_mirror(int slot, double* buf, int cap);  // последний снимок, длина
  int  t2d_app_heard(int slot, double* buf, int cap);   // забрать накопленные записи подряд, длина
  void t2d_app_stats(t2d_app_stats_t* out);             // снять окно (avg/max обнуляются)
  ```
- Swift: `protocol World { var slot: Int { get }; var theme: Theme { get }; func tick(now: Double, dt: Double); func draw(_ d: Draw, now: Double); func down(_ f: Finger); func move(_ f: Finger); func up(_ f: Finger) }`; `struct Finger { id: ObjectIdentifier; x, y, x0, y0: CGFloat; t0: Double; moved: Bool; touchTime: Double }`; `struct Theme { ink, paper: (r, g, b); bg: UIColor }`.
