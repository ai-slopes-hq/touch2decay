# SDK A — ядро: блоки, ревербы, хост, мост, пилот Firmamentum — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** один `t2d.wasm` (хост + блоки SDK + Firmamentum как модель и звук на C++) в одном worklet; четыре общих ревербера-посыла вместо зала в каждом мире.

**Architecture:** `core/sdk` (блоки, `World`), `core/host` (миры, посылы после фейдера, ревербы, лад), `core/worlds/firmamentum` (модель + звук), `core/bridge/wasm.cpp` → `t2d.wasm`; в вебе — `t2d-worklet.js`, `T.send(rev)` вместо `T.hall()`, фасад `worlds/firmamentum/model.js` над ядром.

**Tech Stack:** C++17 (clang, emscripten standalone WASM), AudioWorklet, Node `node:test` + `vm`, Playwright (`tools/shot.py`), `tools/render.py`.

**Spec:** `docs/superpowers/specs/2026-10-23-sdk-a-core-design.md` (основание — `docs/sdk-inventory.md`, раздел 9).

## Global Constraints

- Ветка `native`; не пушить — пушит контроллер.
- C++17, без зависимостей, без аллокаций в `process`; `-ffp-contract=off` (натив и WASM); WASM — standalone, без импортов (`-sSTANDALONE_WASM --no-entry -fno-exceptions -sFILESYSTEM=0 -sALLOW_MEMORY_GROWTH=0`).
- Блоки — параметры, а не константы: звук миров не меняется (кроме ревербов — решено автором).
- `goetia.wasm` и `ocean.wasm` после правки путей `#include` — побайтно те же.
- `.wasm` лежат в git: изменил ядро — пересобери (`core/build.sh`) и закоммить вместе.
- Сверка звука — 1e-6 на сэмпл; модели — 1e-9; допуски не расширять, расхождение — искать причину.
- Комментарии и документы — по-русски, в духе соседнего кода (шапка-комментарий файла, короткие пояснения справа); коммиты — по-английски, тело — список, в конце `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Долгие статистические тесты (`old worklet`) — в цикле правок пропускать `--test-skip-pattern "old worklet"`, полный прогон — перед коммитом.
- Playwright: `/private/tmp/claude-501/-Users-noise-code-touch2decay/02916a52-f7e6-4e1a-b1bf-126ffe53c0eb/scratchpad/pw/bin/python tools/shot.py …`, сервер `python3 -m http.server 8765` в корне.
