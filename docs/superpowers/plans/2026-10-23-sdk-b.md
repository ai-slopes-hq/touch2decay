# План: SDK B — Goetia и Oceanus в `t2d.wasm`

Спека — `docs/superpowers/specs/2026-10-23-sdk-b-design.md`. Образец — Firmamentum в SDK A (`core/worlds/firmamentum`, `worlds/firmamentum/model.js` — фасад, `tools/models/firmamentum-core.mjs`, `tools/firm-scenarios.mjs` — `ACTS`, `refPath`, `corePath`). Ветка `native`. Каждая задача — отдельный коммит.

- [x] **1. Сборка на старом emscripten.** `core/build.sh` — `TOTAL_STACK` до emcc 3.1.25; в мосте своя ловушка `_Exit` (иначе 3.1.6 тянет импорт `proc_exit`). Все тесты ядра зелёные на сборке 3.1.6.
- [x] **2. `TapeEcho`** — `core/sdk/echo.hpp` (задержка, LP в петле, `send` / `fb` со сглаживанием 0.05 с). Тест в `core/tests/sdk_test.cpp`: импульс → повторы через `time`, каждый слабее, без NaN на тишине.
- [x] **3. Эталоны моделей.** `worlds/goetia/model.js` → `tools/ref/goetia-model.js`, `worlds/oceanus/model.js` → `tools/ref/oceanus-model.js` (как есть; дальше `model.js` станет фасадом).
- [x] **4. Oceanus в ядре.** `core/worlds/oceanus/model.hpp|.cpp` (порт эталона; у города ещё `id` — по нему фасад узнаёт город), `world.hpp|.cpp` (`sdk::World`, шина ×1.6, посыл `hall²·1.4·1.6`, сглаживание посыла 0.05 с; зерно звука = зерно мира ^ константа); мост — слот 8; `build.sh`. Сверка в `tools/ocean-scenarios.mjs`: `ACTS` действиями, `refPath` (эталонная модель → сообщения как `engine.js` → `tools/ref/ocean-worklet.js`, ×1.6) против `corePath` (сухой выход слота 8) — 1e-6, метры (форма, луна, gain) — тоже.
- [x] **5. Фасад Oceanus.** `worlds/oceanus/model.js` — прежний API над ядром (города по `id`, `dirty` / `gone` / `wipe` — как у Firmamentum); `tools/models/oceanus-core.mjs`; `tools/models/oceanus.test.mjs` — каждый тест против эталона и против ядра, плюс асинхронный порт (город под пальцем, гонка «отпустил — зеркало»).
- [x] **6. Goetia в ядре.** То же: `model`, `world` с эхом (`TapeEcho` 0.375 с, LP 2600, вход `echo·0.8`, обратная связь `echo·0.55`) и шиной (×1.6, посыл `hall²·1.5·1.6`); слот 15; `id` духа — `born`. Сверка 1e-6 — вместе с эхом: эталонный путь гонит звук через JS-копию шины прежнего engine (`busRef` в `tools/goetia-scenarios.mjs`); против настоящего Web Audio — по RMS и спектру в браузере (задача 9).
- [x] **7. Фасад Goetia** + `tools/models/goetia-core.mjs` + тесты против эталона и ядра.
- [x] **8. Веб.** `SDK_WORLDS = [10, 15, 8]`; `engine.js` обоих — тонкие (сухой выход в канал, `bind` / `sync`, метры из зеркала); `index.js`; удалить `goetia.wasm`, `ocean.wasm`, `goetia-worklet.js`, `ocean-worklet.js`, `core/worlds/*/wasm.cpp`, их тесты WASM (`test-goetia-engine.mjs` — гонка ленивого старта больше не нужна); `sw.js`, `CACHE` и `?v=` — v173.
- [x] **9. Проверка в браузере.** `shot.py goetia oceanus firmamentum midi audio worlds` и все сценарии миров; скриншоты глазами; `render.py`: прежний прод против ветки — RMS ± 1 дБ (Goetia с эхом, Oceanus), время рендера.
- [x] **10. Доки и выкладка.** `core/README.md`, `docs/worlds/goetia.md`, `docs/worlds/oceanus.md`, `docs/native-plan.md`, `docs/sdk-inventory.md`, `CLAUDE.md`, `docs/tokens.md`; пуш в `native`, превью — автору.
