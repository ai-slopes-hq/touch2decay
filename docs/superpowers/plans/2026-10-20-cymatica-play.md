# Cymatica: вращение, клавиши, смычок — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Мелодию в Cymatica можно сочинять руками: двумя пальцами (или Shift-мышью) крутишь кольца — узор сдвигается, крутишь пластину — мелодия транспонируется; под астролябией — 9 клавиш лада (игра, запись, пошаговый ввод с курсором); закреплённый смычок нарисован смычком.

**Architecture:** Чистые помощники (`rotateSteps`, `transposeMelody`, `keyNotes`, `twistOrPinch`) — в `cymatica.js`, открыты через `t2d.cym.core` и проверяются в Node. Жесты — в `cymatica.js` поверх существующей модели `seq` (узор по-прежнему уходит в worklet целиком через `sendSeq`). Хозяин отдаёт тонику лада через `T2D.scaleRoot`.

**Tech Stack:** ванильный JS, canvas 2D; `node --test tools/test-seq.mjs`, `tools/shot.py`.

**Spec:** `docs/superpowers/specs/2026-10-20-cymatica-play-design.md`

## Global Constraints

- Шаг поворота колец — 22.5° (одно гнездо, по часовой — вперёд); пластины — 20° на ступень (по часовой — вверх); допуск попадания в кольцо `|d − R| < 14`; пластина — `d < rMax`.
- Поворот или щипок — по первым ~10° / ~20 px, что сильнее; дальше жест не меняется.
- Клавиши: 9 штук (8 ступеней на октаву + «·»), ряд под ▶/●; без лада — минорная пентатоника от A (0, 3, 5, 7, 10); регистр — октава основного тона пластины; ноты > 48 полутонов — тусклые и не звучат.
- Запись клавишей: нота — в ближайший шаг мелодии, удар (`lastHit`) — в ближайший шаг ритма. Пошаговый ввод (часы стоят): нота в гнездо курсора, курсор +1 по кругу `melody.len`; «·» — `null` и +1; тап по гнезду мелодии — курсор туда.
- Щипок больше не пишет мелодию.
- Картинка — ч/б гравюра, `INK`, шрифт `MAP`; подписи — только во время жеста; версия 50 → 51 (`CACHE`, все `?v=`); комментарии — по-русски, коммиты — по-английски, тело-список, `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; `node --check` для всех `.js`.

## Review Focus

1. Второй палец ложится, когда первый уже начал удар или смычок на пластине, — смычок первого пальца гаснет, удар не повторяется, жест становится поворотом/щипком. Тест — Task 2 (`twist after a held finger`).
2. Поворот кольца, в котором меньше 16 активных гнёзд, — двигаются только первые `len`, неактивные не трогаются. Тест — Task 1.
3. Транспонирование на край (за 48 или ниже 0) — ноты упираются в край, не пропадают. Тест — Task 1.
4. Альбомная раскладка — клавиши на экране. Тест — Task 3.
5. Клавиша при записи чуть раньше доли — без двойного удара (через `rec` в `strike`, как у тапа). Тест — Task 3 (уровень worklet уже покрыт тестом `no double hit`; здесь — что клавиша шлёт `rec: true`).

### Task 1: Чистые помощники — поворот, транспонирование, клавиши, жест

**Files:** Modify `cymatica.js`, `tools/test-seq.mjs`

**Interfaces:**
- Produces (в `t2d.cym.core`):
  - `rotateSteps(steps: any[16], len: int, k: int) → any[16]` — первые `len` циклически сдвинуты: элемент `i` переходит в `(i + k) mod len`; гнёзда `≥ len` — как были; новый массив.
  - `transposeMelody(steps: (int|null)[16], k: int, scaleSemis: int[]) → (int|null)[16]` — каждая нота — на `k` позиций по `scaleSemis` от ближайшей, с упором в края списка; `null` остаётся.
  - `keyNotes(f0: number, pcs: int[], tonic: int) → int[8]` — `pcs` — классы высот лада (0–11, от A), `tonic` — класс тоники; старт — тоника в октаве основного тона (`tonic + 12·floor((semi(f0) − tonic) / 12)`, `semi(f0) = 12·log2(f0 / 55)`), дальше вверх по `pcs`, 8 нот.
  - `twistOrPinch(a0, a1, d0, d1) → 'twist' | 'pinch' | null` — углы в радианах, расстояния в px; `dA` = модуль разности углов в градусах (через ±180°), `dD = |d1 − d0|`; оба меньше порогов (10°, 20 px) — `null`; иначе больше `dA/10` или `dD/20`.
