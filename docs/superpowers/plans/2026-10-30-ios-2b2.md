# iOS 2b-2 — плашки FX и LFO строк: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** в Firmamentum на iPhone — плашка FX и плашка звезды (удержание), «~» ставит LFO на строку, LFO живёт в аудиопотоке ядра и слышен при закрытой плашке и в фоне.

**Architecture:** таблица LFO — в `Host` ядра, её пишет только аудиопоток: UI шлёт `T2D_H_LFO_*` слотом хоста в общее кольцо движка, снимок LFO публикуется рядом с зеркалами (`Triple`). Значение уходит миру раз в блок общим кодом `ACT_LFO` (0…1, перевод единиц — у мира). В Swift — `SheetSpec` / `Sheet` (перенос `host/sheet.js`) в слое `Host`, плашки Firmamentum — у его вида.

**Tech Stack:** C++17 (ядро, тесты `core/tests/sdk_test.cpp`), Swift 5 + UIKit + CoreGraphics, XCTest, XcodeGen; веб-пары снимков — `tools/shot.py` (Playwright).

**Spec:** `docs/superpowers/specs/2026-10-30-ios-2b2-design.md` — читать целиком перед любой задачей.
