# iOS 2b-3б — concordia, микшер, панель audio: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** солнце и `concordia` на карте открывают concordia (shared tempo, shared scale, stable audio, restart audio, mixer); микшер — фейдер и mute каждого мира с уровнем, мастер lpf / thr / ratio / ceil; в мире тап по громкости — панель audio; настройки — в `prefs.json`.

**Architecture:** ядро получает действия хоста `T2D_H_FADER` / `T2D_H_MASTER` и сглаживание 30 мс в движке приложения (`core/app/engine.cpp`, без wasm). Swift: модель `Host/Mix.swift`, экраны `Host/Concordia.swift`, `Host/Mixer.swift`, `Host/AudioPanel.swift` (геометрия, попадания, рисование — по вебу один в один), `Host` держит `settings` / `audioPanel` и роутит, `Audio` — `restart()` и `stable`.

**Tech Stack:** C++17 (`core/tests/sdk_test.cpp`), Swift 5 + UIKit + CoreGraphics, XCTest, XcodeGen; веб-пары снимков — `tools/shot.py startmap|nav|audiopanel`.

**Spec:** `docs/superpowers/specs/2026-10-30-ios-2b3b-concordia-design.md` — читать целиком перед любой задачей. Веб-источник истины — таблица в спеке (`host/concordia.js`, `host/mixer.js`, `host/audio-panel.js`, `host/audio.js:134-170`).

- Буфер звука: обычный `256/48000`, stable — `1024/48000`.

## Review Focus

1. **Палец фейдера уходит за коробку микшера** — фейдер ведётся до отпускания, микшер не закрывается (закрытие — только на касании мимо). Тест — задача 4 (`testMixerDragOutsideKeepsMixer`).
2. **Второй палец во время перетаскивания фейдера** — первый фейдер не прыгает, второй палец работает по своим правилам. Тест — задача 4 (`testMixerSecondFingerDoesNotMoveFirst`).
3. **Переинициализация ядра (прерывание, смена частоты) при сохранённом микшере** — после `reapply` ядро получает весь микшер. Тест — задача 4 (`testReapplySendsMix`).
4. **`stable audio` переключают, пока звучит мир** — звук перезапускается без переинициализации ядра (сцена жива), настройка сохранена. Тест — задача 3 (`testStableTogglesAudioAndSaves`) + `AudioPlanTests` (`.user` → `rebuild, !reinit`).
5. **Панель audio открыта, уход на карту** (стрелка / свайп) — панель закрыта. Тест — задача 5 (`testGoMapClosesAudioPanel`).
