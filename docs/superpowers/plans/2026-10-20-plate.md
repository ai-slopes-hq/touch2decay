# Пластина — план реализации (подпроект 2 из 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cymatica звучит: круглая пластина из 24 мод в AudioWorklet — тап = удар, держишь = смычок, двойной тап = закреплённый смычок (кольцо на удержание), щипок/колесо = размер = высота, песок собирается в фигуры Хладни, веер FX управляет пластиной.

**Architecture:** `plate-worklet.js` — звук: чистые функции (Бессель, строи, формы мод, затухания, выбор голоса) объявлены `function` на верхнем уровне (их видит тест через `vm`), класс `PlateProcessor` регистрируется, только если есть `AudioWorkletProcessor`. Основной поток (`cymatica.js`) шлёт сообщения и получает энергии мод и сетку форм мод для песка. Хозяин (`app.js`) даёт мирам общий вход мастера и помощники кольца/зала/лада через `T2D`.

**Tech Stack:** ванильный JS, AudioWorklet, canvas 2D; тесты — `node --test tools/test-plate.mjs` (Node 20+, без зависимостей), Playwright-сценарии `tools/shot.py`, офлайн-рендер `tools/render.py`.

**Spec:** `docs/superpowers/specs/2026-10-20-cymatica-design.md`, часть 2 «Пластина».

## Global Constraints

- Без сборки и зависимостей; новые файлы — в `SHELL` (`sw.js`); версия одна для `CACHE`, всех `?v=` в `index.html` и URL worklet'а (`cymatica.js` берёт `v` из своего `document.currentScript.src`): 46 → 47.
- На экране — английский/латынь; ч/б, `INK`; шрифт `MAP`; без `shadowBlur`; песок — без полноэкранных проходов.
- 24 моды круглой пластины, пары `(m 0–8, n 1–4)` по возрастанию `j(m,n)`; форма `J_m(j·r)·cos(mθ)`.
- Строи: 0 струна (1, 2, 3…), ⅓ мембрана `j_k/j01`, ⅔ пластина `(j_k/j01)²`, 1 колокол `0.5, 1, 1.2, 1.5, 2`, моды 6–24 — строй «пластина», умноженный так, чтобы 6-я была 2.5; между — интерполяция отношений в логарифме.
- Громкость моды при ударе `|φ_k(x,y)|`, нормированная по максимуму формы; моды выше 18 кГц или `0.45·fs` молчат.
- `T60_k = lerpLog(0.08, 12, damping) · (1/ratio_k)^(2·(1−brightness))`; резонатор `y = 2R·cos ω·y1 − R²·y2 + g·x`, `R = 10^(−3/(T60·fs))`.
- Высота 55–880 Гц, по умолчанию 110; в ладу — к ближайшей ноте лада; 4 голоса-пластины; смычки звучат на текущей высоте.
- Тап — удар сразу; держишь > 150 мс — смычок в этой точке; двойной тап — закрепить смычок (до 3); долгое касание метки (420 мс) — кольцо `exciter` (смычок ↔ шум), `pressure`, `amp`.
- Веер FX Cymatica: `structure`, `damping`, `brightness`, `hall`, `echo`; эхо — стерео, 0.375 с (до секвенсера).
- Из worklet ~30 раз/с `{ t: 'energy', e: Float32Array(24), voices: [{ hz, level }] }`; один раз после старта — `{ t: 'shapes', n: 96, grid: Float32Array(24·96·96) }`.
- Песок: 2500 крупинок; поле `A = sqrt(Σ E_k·φ_k²)` на сетке 96×96.
- Комментарии — по-русски, в стиле файла; коммиты — по-английски, тело-список, `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; `node --check` для всех `.js` перед коммитом.

**Сужение спеки (решение плана, сказать автору):** у закреплённого смычка в этом подпроекте нет панели LFO и полосы amp — громкость стала лучом кольца `amp`. LFO для смычков — позже: нужна модуляция внутри worklet.

## Review Focus

1. Шквал ударов (много пальцев, быстрые тапы) — worklet держит не больше 16 одновременных ударов, без NaN и перегруза. Тест — Task 2.
2. Первый тап раньше, чем загрузился worklet (`addModule` асинхронный) — сообщения копятся и доходят, когда узел готов; первый удар слышен. Тест — Task 3.
3. Щипок или колесо до упора — высота держится в 55–880 Гц, без NaN. Тест — Task 3.
4. Держишь смычок и вторым пальцем уходишь на карту — смычок замолкает, когда палец отпущен (касание принадлежит Cymatica). Тест — Task 3.
5. Отмена возвращает закреплённые смычки и они снова звучат (сообщения уходят в worklet). Тест — Task 3.
