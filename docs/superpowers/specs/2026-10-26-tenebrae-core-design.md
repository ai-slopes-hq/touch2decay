# Tenebrae в ядре — этап 1: звук

**Дата:** 2026-10-26 · **Статус:** согласовано с автором в чате, ждёт ревью файла · **Фаза:** нативный план, фаза 4 (ядро), этап 1 из 2

Заменяет прежнюю версию этой спеки: та писалась не по коду (морф, «дыра», шина, связи, LFO, мост — всё не так, как в `app.js`).

## Цель

Звук мира I (Tenebrae) играет из ядра C++ (`t2d.wasm`, слот 1). Модель, жесты, dice, chaos, снимок, undo и рисование остаются в `app.js`; модель шлёт в ядро свои поля, ядро считает формулы звука (`apply()`) само. Этап 2 (потом, отдельная спека) — модель в ядро, `app.js`/модель становится фасадом, как у Natura и Portus.

Готово, когда: на превью ветки `native` Tenebrae звучит из ядра, автор на iPhone не слышит разницы с продом и не ловит лагов; все проверки ниже зелёные.

## Ограничения

- Мир заморожен (с 22.10): это перенос, звучание не меняем. Причуды браузера не воспроизводим; заметные отличия — автору списком «что послушать» (`docs/native-plan.md:98`).
- Критерий звука: RMS ±1 dB, энергия по октавам ±1.5 dB (нижняя полоса ±2 dB, полосы ниже −60 dB от громкой не считаем) против эталона — старого движка в OfflineAudioContext. wasm = нативное — до 1e-5 на сэмпл.
- Случайность ядра — `sdk::Rng` от зерна мира (`seed ^ 0x54454eu`), не `Math.random` (решение 7 инвентаря). JS-модель (dice, chaos) на этапе 1 не трогаем.
- Ядро: C++17, `-fno-exceptions`, без аллокаций в `process`, память wasm фиксирована 16 МБ. Комментарии — по-русски, плотность как в `core/sdk/`.
- Правила SDK (`docs/sdk-rules.md`): блок есть в `core/sdk/` — берём его. Новое кладём в SDK, только если нужно 2+ мирам. Ревербер — только посыл `Out.sL/sR`.
- Работа — в ветке `native`, в `main` не идёт. Каждый пуш — новая версия (`CACHE` в `sw.js` = `?v=` в `index.html`), `t2d.wasm` вместе с правкой `core/`.

### Таблицы волн (`waves`)

- При `prepare` — 9 форм как `makeWave`: цикл N = 1024, минус среднее, деление на пик, ДПФ, гармоники h = 1…219 (`re = 2a/N`, `im = 2b/N`), `level = 0.24 / √(среднее квадрата)` исходного цикла. Формы — те же функции, что `WAVES` в `host/waves.js` (grain — LCG `s = 11`, `s·16807 mod 2147483647`, 40 точек). Функции форм уже есть в `core/sdk/lfo.cpp` (`WaveMorph`) — взять оттуда, не копировать.
- Два набора: **голосовой** — фазы выровнены по пиле (`alignWaves`: модуль своей гармоники, фаза — пилы); **LFO** — исходные фазы.
- Каждую таблицу хранить с обрезкой по октавам (мип-уровни, ~10 × 2048 точек, уровень выбирается по частоте: гармоники выше Найквиста — нет), всю — нормированной по пику полной таблицы (поведение `PeriodicWave` без `disableNormalization`). Чтение — линейная интерполяция. Память ≈ 0.8 МБ.
- Морф: позиция p ∈ [0, 1], вес формы i — `max(0, 1 − |p·8 − i|)`; голос: `Σ wᵢ^0.85 · levelᵢ · табл_i`, LFO: `Σ wᵢ · табл_i` (без level). Считаются только формы с весом > 0.

### Голос (`voice`)

Схема — `voiceNodes`/`apply` один в один, k = 1 + i·0.137, G = 0.14:

- c1 (панорама −0.5) и c2 (+0.5) — морф-генераторы голосового набора; саб — синус f/2 × 0.28 (моно).
- Частоты: c1 = f, c2 = f + beat (Гц), саб f/2, модулятор m = f. В частоту c1/c2 прибавляются self-FM (`f·1.4·fm`, Гц, сигнал m) и tzfm-связи; в detune — дрейф, джиттер, fm-связи, LFO pitch.
- Дрейф (синусы): c1.detune 0.071k Гц ±5 ц и 0.19k ±2.5; c2.detune 0.053k ±6 и 0.23k ±2; lp.detune 0.043k ±280 ц; дыхание 0.09k ±0.13. Джиттер — белый шум (`Rng`) → LP 23k Гц (Q −3 dB) × 140 → c1.detune и LP 31k (Q −3) × −140 → c2.detune.
- Цепь: tone → сдвиг (dry/wet) → drive `0.22 + 3.6y²` → `soft(3)` (TanhShaper, os 2×) → lowpass (`cutoff(v)`, Q = res·24 dB) → env. Шум (свой генератор `Rng`) → bandpass (×2.4) и highpass 3000 (hiss) → nz → env. env → сумма; env → delay 1/f (удваивать, пока < 6 мс) → LP 3000 (Q −3) → `soft(1.6)` без os → ×0.3 → назад в delay; delay → comb → сумма. Сумма → vca → дыхание → lvl → панорама `(x − 0.5)·0.6` → выход голоса. Кольцо контура — после vca.
- Значения `apply` с их τ (на `snap` все τ = 0.004): tone `(1 − 0.65y^1.5)(1 − h)`; nz `0.95y^1.8(1 − h) + 0.9h`; bp `min(3f·2^(2y), 9000)^(1−h) · 600^h`, Q `(9 − 6y)(1 − h) + 0.5h`; hiss `0.25y³(1 − h)`; comb `0.45(1 − h)`; lvl `0.55·amp·alive`, `alive = 1 − clamp((h − 0.5)/0.45)`; h = holeT (цель). Полный список с τ — `apply`, строки 1439-1500.
- `cutoff = clamp(lerpLog(40, 18000, cut) · 2^((y − 0.5)·4.5) · 2^(1.5·fmOpen), 20, 20000)`, `fmOpen = min(1, fm + Σ глубин fm/tzfm-связей)`.
- Частота f — из x по ладу хоста (`soundX`/`quantX`: `semi = 60·clamp(x)^1.45`, привязка к ладу, `f = 55·2^(semi/12)`), лад — `const Scale&` мира.
- Сглаживание — `sdk::Param` (setTargetAtTime). Коэффициенты фильтров — раз в 16 сэмплов (отличие от браузера — в «что послушать»).
- Огибающая: ON → 1 (τ 0.12), OFF → 0 с переданным τ (1.6 / 0.8 / 0.25 / 0.03 / 0.4). Сигнал m для связей — тоже через огибающую.
- `live = 0` — голос не считается вовсе (сейчас отцеплен от графа).

### Сдвиг частоты (`shifter`)

Два каскада по 4 allpass-IIR, коэффициенты Niemitalo:
`[[0.6923878, 0.9360654322959, 0.988229522686, 0.9987488452737], [0.4021921162426, 0.856171088242, 0.9722909545651, 0.9952884791278]]`; секция b = `[a², 0, −1]`, a = `[1, 0, −a²]`; у I-ветки — задержка на сэмпл. Выход `I·cos + Q·sin`, частота = `shiftHz(shift)` + LFO shift (d·300 Гц), dry/wet 1/0 с τ 0.02; включён, когда `shiftHz ≠ 0` или есть LFO shift. `shiftHz(t)`: u = 2t − 1, мёртвая зона |u| < 0.04, `sign(u)·(2^(((|u| − 0.04)/0.96)·11) − 1)·(1500/2047)`.

### Связи

Хранятся у приёмника (как `dst.mods`): [src, type, depth]. Источник — сигнал m источника (чистый синус f_src × огибающая), не выход голоса. fm → detune c1/c2, `depth·2400` ц; tzfm → частота c1/c2, `depth·5·f_src` Гц; am → vca, `depth`; rm → vca, `depth·1.6`; база vca = `max(0, 1 − Σ rm)` (τ 0.08). Изменение частоты источника меняет tzfm-глубину приёмника (как пометка `dirty` по tzfm в `solTick`). Циклов нет — m не модулируется.

### LFO планет

Ключи: pitch, wave, cut, res, beat, shift, amp, fm. Генератор — морф LFO-набора, позиция `morph`, частота `rate`. Глубины: pitch d·700 ц (c1/c2/саб detune), wave d·2 (позиция морфа), cut d·4800 ц (lp.detune), res d·20 (lp.Q), beat d·16 Гц (c2), shift d·300 Гц, amp d·0.55·amp·alive (lvl), fm d·f·1.4 (self-FM).

### Шина и эхо

Сумма голосов × `1/√max(1, Σ env)` (τ 0.3, огибающие ядра, пересчёт раз в блок) → pre `0.45 + dirt^1.4·14` → `asym(2.4, 0.35)` (Shaper os 4×) → post `2.2/(1 + 4·dirt^0.8)` (τ 0.05) → выход. Эхо: post × `dly·0.7` → `sdk::PingPong` 0.37 / 0.53 с, `setLp(2600, 2100, Q −3)`, fb 0.46, wow 0.13 Гц ±4 мс и 0.087 Гц ±5 мс → выход. Посыл: `rev²·1.4` от post и возвратов эха → `Out.sL/sR`.

### Удар по солнцу

Действие `STRIKE p`: шум (`Rng`) → bandpass 1800–4400 Гц (Q 1.2), два щелчка, + синус 140 → 45 Гц; уровень `0.05 + 0.1p`; в шину. Детали — `app.js:1172-1186`.

## Связь JS ↔ ядро

### Действия (`t2d_action(1, kind, i, a)`)

| kind | Когда (было в `app.js`) | i | a |
|---|---|---|---|
| `VOICE` | голос `dirty` (`apply`) | голос | x, y, cut, res, wave, beat, fm, shift, amp, holeT, snap |
| `ON` | `attack` | голос | — |
| `OFF` | `release` | голос | τ |
| `LIVE` | подключить / отцепить (`n.live`) | голос | 0 / 1 |
| `LINKS` | изменились `mods` | приёмник | [src, type, depth] × k (весь список; type: 0 fm, 1 tzfm, 2 am, 3 rm) |
| `LFO` | `setLfo` / снятие | голос | key, morph, rate, depth (depth 0 — снять) |
| `FX` | `applyFx` | — | rev, dly, dirt |
| `STRIKE` | удар по солнцу | — | p |
| `CLEAR` | корзина | — | — |

`kind = −1` (тик хоста) — пропускать. Коды — в `world.hpp` (комментарий с раскладкой, как у Natura) и те же числа в `worlds/tenebrae/engine.js`.

`snapshot()` ядра — пустой, `restore()` — ничего: снимок и undo на этапе 1 у JS. После смены аудиоконтекста `engine.bind()` шлёт заново всё: VOICE и ON/LIVE для активных, LINKS, LFO, FX. Особый случай мира 1 в `restartAudio` сохраняется.

### Зеркало

`[6, затем по голосу: live, env, 128 точек контура]` — 1 + 6·130 = 781 число. Контур: кольцо 1024 последних сэмплов после vca, первый переход через ноль снизу вверх в первых 480, `span = round(clamp(sr/f·2, 64, 520))`, точка j = `b[s0 + floor(j/128·span)]`. Масштаб (`pk`, `k`) и рисование — в JS, как сейчас. `heard` — пустой. Яркость солнца — с мастер-анализатора хоста, как сейчас.

## Проверка

- **`core/tests/sdk_test.cpp`:**
  - `tenebraeWaves` — `re`/`im`/`level` всех 9 форм обоих наборов против чисел из Node (`host/waves.js` + `makeWave`/`alignWaves`) до 1e-6; пик каждой мип-таблицы = 1 (±1e-6); у уровня выше Найквиста нет гармоник.
  - `tenebraeShifter` — `shiftHz` против JS на сетке t (1e-9); синус 1000 Гц, сдвиг +300 → пик 1300 Гц, 700 Гц ≤ −40 dB от пика; shift 0 → выход = вход (dry).
  - `tenebraeVoice` — `live = 0` → нули и не тратит время; fm/tzfm/rm = 1, `hole = 1` → выход конечный, пик < 4; шина: 6 голосов с env = 1 → множитель 1/√6.
  - `shaper` — os 4× против эталона Chromium (числа из браузера, 1e-6), прежние проверки 2× не меняются.
- **`tools/tenebrae-bus.py`** (по образцу `natura-bus.py`): старый движок `tools/ref/tenebrae-engine.js` в OfflineAudioContext против `core/build/tenebrae-cli` на тех же сценах, RMS ±1 dB, октавы ±1.5 dB, отдельно сухой и посыл. Сцены: 1) одна планета по умолчанию; 2) wave 0.5 и 0.9; 3) две планеты + tzfm 0.5, потом fm, am, rm; 4) shift +300 Гц; 5) hole 0.7; 6) LFO cut; 7) 6 голосов, dirt 0.6, dly 0.5, rev 0.5; 8) хвост после OFF τ 1.6. Эталону нужны формулы модели (`freq`, `cutoff`, `shiftHz`, `soundX`) — переносятся в `tools/ref/tenebrae-engine.js` вместе со звуком.
- **`tools/test-tenebrae-core.mjs`:** wasm против `tenebrae-cli` на тех же сценах, ≤ 1e-5 на сэмпл, зеркало (контур) совпадает.
- **Картинка:** агент `shots`, сценарии planets, ring, hole, audio — контуры рисуются и дышат, ошибок в консоли нет.
- **Производительность:** `tenebrae-cli` на сцене 7 — не медленнее 20× реального времени на ядро Mac. Окончательно — автор на iPhone (индикатор нагрузки).
- Прежние тесты (`node --test tools/test-models.mjs tools/models/*.test.mjs`, `core/build/sdk-test`, сверки других миров) — зелёные.
