# Paradisus — девять небесных сфер, ангельский хор

Рай Данте над Cymatica, координаты (−1, 2). Зеркало ада: там воронка вниз, здесь сферы вверх к свету. Звук — **vowel synth**: голосовой источник сквозь форманты гласных, хор, шиммер, грануляр. **Дрон без секвенсера.** Картинка — нарисованная линиями «Эмпирей» в духе Доре: кольца ангелов вокруг света.

Решено с автором: строй — натуральный ряд; дрон; рисовать линиями.

## Что что значит

| Где | Что | Звук |
|---|---|---|
| сферы | девять концентрических эллипсов вокруг Розы: Luna (внешняя), Mercurius, Venus, Sol, Mars, Iuppiter, Saturnus, Stellae, Primum Mobile (ближе всех к свету) — подписи только пока трогаешь | натуральный ряд: сфера n — n-я гармоника тоники лада (Luna — основной тон, Primum Mobile — 9-я) |
| ангел на сфере | силуэт крыльями, светлеет, когда поёт | голос хора |
| место на сфере | по кругу: a (сверху) → e → i → o → u → a; между — плавно | гласная |
| нимб ангела | форма: a — широкий, i — узкий, o — круглый, u — маленький | гласная (видна без подписи) |
| ангел закреплён | горит ровно, нимб двойной | поёт сам (до 4) |
| Небесная роза в центре | лепестки вспыхивают зёрнами | Gloria — грануляр, облако зёрен хора |
| лучи из центра | гуще и ярче | shimmer — зал с октавой вверх в петле |
| ангелы плывут вверх по сферам (фон) | скорость | бесконечно поднимающийся Шепард (ascensio) |
| божественный свет в нижнем правом углу (к центру карты) | четверть сияния — тонкие лучи, дышат общей громкостью; тап — карта | — |

## Жесты

- **Тап по сфере** — там появляется ангел и поёт, пока держишь (как планеты в Tenebrae).
- **Двойной тап** — ангел остаётся и поёт сам; ещё двойной тап — отпустить. До 4 закреплённых.
- **Ведёшь вдоль сферы** — гласная плывёт.
- **Переносишь поперёк** — на другую сферу (прилипает к ближайшей — к гармонике).
- Долгое касание ангела — кольцо, как в Tenebrae: размер хора (1–5 певчих), расстройка, вибрато, дыхание (шум в голосе), регистр (октава вниз / вверх).
- **Веер FX:** shimmer, gloria, aether (размер зала), vibrato, ascensio.
- **Кубик** — 3 ангела на сферах аккорда (например 4 · 5 · 6 — мажорное трезвучие в чистом строе), случайные гласные. **Корзина**, **отмена** — как везде.

## Звук

- **Голос:** пила (или импульс) с лёгким джиттером и вибрато → 4–5 полосовых формант параллельно (F1–F5 с ширинами и громкостями по таблице гласной; между гласными — плавная интерполяция) → сумма. Немного шума дыхания сквозь те же форманты.
- **Хор:** на ангела 3 певчих, расстроены на ±6–10 центов, вибрато не в фазе.
- **Строй:** f = тоника лада × n (натуральный ряд; без лада — от A2). Чистые интервалы — «как в соборе».
- **shimmer:** зал `T2D.hall`, в петле — шифтер на октаву вверх (взять из Tenebrae `shifter`, выставить в `T2D`).
- **gloria:** AudioWorklet-грануляр по кольцевому буферу хора (~2 с): зёрна 60–200 мс, случайное место, часть на октаву вверх; плотность — gloria.
- **ascensio:** Шепард вверх — 6–8 октавных голосов на гласной «а», колокол громкости по спектру.
- **Экономия:** молчащий ангел отцеплен, мир отцеплен через несколько секунд тишины; грануляр не считается при gloria = 0.

## Картинка

- Тема — свет: фон слоновая кость, чернила — бледное золото / сепия (обратное аду). Цвет без заливок.
- Сферы — эллипсы во весь экран (по вертикали шире: экран высокий), Роза — в центре чуть выше середины.
- Ангелы — штрихом: крылья, нимб; молчащие места на сферах — едва видные точки-звёзды.

## Хост

- `T2D.registerWorld`, тема `{ ink, bg, paper }` светлая (первый светлый мир с тёмными чернилами после Natura).
- Нужен `T2D.shifter` для shimmer.
- Карта должна вырасти — общая задача с Inferno.

## Открытые вопросы

- Расстояние между сферами на телефоне: 9 сфер в ~170 px по горизонтали — тесно; спасает прилипание к сфере и высокий эллипс. Проверить пальцем; если тесно — 7 сфер (без Stellae и Primum Mobile) или Роза меньше.
- Голос — пила или модель голосовой щели (импульс LF) — сравнить на слух.
