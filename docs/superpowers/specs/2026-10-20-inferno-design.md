# Inferno — воронка из девяти кругов, шум сквозь резонаторы

Ад Данте над Tenebrae, координаты (1, 2): продолжение шумной верхушки Tenebrae — выше начинается ад. Звук — **шум сквозь банк резонаторов** (spectral resonator / filter bank), как Mutable Rings, накормленный шумом. **Дрон без секвенсера**, как Tenebrae. Картинка — нарисованная линиями воронка в духе «Карты ада» Боттичелли, без гравюр-картинок.

Решено с автором: удары и тление по кругам; оба мира — дроны; рисовать линиями.

## Что что значит

| Где | Что | Звук |
|---|---|---|
| воронка | девять кругов-эллипсов один под другим, сужаются вниз (вид сверху в перспективе) | банк из девяти резонаторов |
| круг | Limbus, Luxuria, Gula, Avaritia, Ira, Haeresis, Violentia, Fraus, Proditio — подписи только пока трогаешь | резонатор (несколько полос) |
| глубина круга | ниже — уже и темнее | ниже тон (55–1760 Гц, у каждого круга своя зона ~½ октавы), грязнее: больше перегруза, меньше верха |
| место на круге | слева направо | высота внутри зоны круга (с ладом — по ступеням) |
| круг тлеет / горит | по кругу язычки пламени штрихом, высота — уровень; контур дрожит спектром | уровень резонатора |
| грешник на круге | крошечная фигурка, медленно бредёт по кругу | закреплённый голос: горит сам (до 4) |
| Коцит — ледяное озеро на дне | иней ползёт вверх по воронке с ice | заморозка: добротность → ∞, звук звенит сам |
| падающие тени по стенам воронки | скорость | бесконечно падающий тон Шепарда (fall) |
| дым над воронкой | гуще | тёмный зал (smoke) |
| надпись над входом LASCIATE OGNE SPERANZA | разгорается | общий уровень |
| вечная тьма в нижнем левом углу (к центру карты) | четверть чистой черноты — штрих фона в неё не заходит; тап — карта | — |

## Жесты

- **Тап по кругу** — удар: короткий всплеск шума, круг вспыхивает и звенит (длина звона — добротность и ice).
- **Держишь** — круг тлеет: шум идёт непрерывно, пока палец на круге.
- **Двойной тап** — грешник остаётся на круге, круг горит сам; ещё двойной тап по грешнику — отпустить. До 4 горящих.
- **Ведёшь вдоль круга** — высота внутри зоны круга.
- **Быстро провёл сквозь круги** — арфа: каждый пересечённый круг бьёт, вниз — каскад в преисподнюю.
- Долгое касание грешника — кольцо, как в Tenebrae: цвет шума (white · pink · brown · crackle · grain), ширина полос, перегруз своего голоса.
- **Веер FX:** structure, fire, smoke, fall, ice.
- **Кубик** — 2–3 грешника на случайных кругах, случайная structure. **Корзина**, **отмена** — как везде.

## Звук

- **Источник:** шумы в буферах, считаются один раз: белый, розовый, коричневый, треск (редкие импульсы), гранулы (обрывки шума с окном). Цвет — у каждого голоса свой.
- **Резонатор круга:** 3–4 полосовых фильтра (Biquad bandpass) параллельно, частоты — по лучу **structure**:
  - `harmonic` — f, 2f, 3f, 4f: шум поёт нотой;
  - `scale` — ступени лада вверх от f: шум поёт аккордом;
  - `inharmonic` — отношения колокола (как `TUNINGS` в Cymatica): металл.
- **Глубже — грязнее:** у круга k свой `tanh`-перегруз и lowpass, по глубине.
- **fire** — общий перегруз (drive). **smoke** — тёмный зал (`T2D.hall` с lowpass в петле). **fall** — Шепард: 6–8 октавных полос шума (или синусов) скользят вниз с колоколом громкости по спектру. **ice** — Q резонаторов растёт до 200–400, звон стоит сам; картинка покрывается инеем снизу.
- **Экономия:** молчащий круг отцеплен; мир отцеплен через несколько секунд тишины (`setLive`, как у Laboratorium и Natura). Шумы — один раз в буфер.

## Картинка

- Тема: чёрный фон, чернила — пепел (тёплый серый). Цвет — только у огня: горящий круг — тлеющий красно-оранжевый штрих. Без заливок.
- Воронка — главная часть экрана: внешний круг почти во всю ширину сверху, Коцит — маленький эллипс внизу по центру. Круги — полосы под палец (≈ 48 px по вертикали на телефоне).
- Подписи кругов и частоты — только пока тянешь.

## Хост

- Мир регистрируется через `T2D.registerWorld`, тема `{ ink, bg, paper }`.
- **Карта должна вырасти** (мир за пределами четырёх четвертей): отдельная задача — карта Universum листается и щиплется, новые миры бледные, пока их нет. До неё — вход через `t2d.go`.
