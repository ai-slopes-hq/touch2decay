# Horologium: пэды вместо маятника, фильтр на голос (05.11)

Решения автора (05.11): маятник и шкала tempus не нужны — убрать; ударные настраивать снизу рядом пэдов (тап — вкл/выкл, долгий — плашка); фильтр — на каждый голос (вариант 1), кубик его учитывает, но мягко.

## 1. Что убираем

Скорость колеса теперь только `bpm`: `Fnow = run ? bpm/240 : 0` (оборот = такт). Диапазона «тонус» (быстрее темпа) и замедления больше нет — это сознательно.

**Ядро** (`core/worlds/horologium`):
- действия `HELD`, `STEP`, `SPEED` убрать; `RUN` — один аргумент `on` (`u` не передаётся);
- `Clock` → `{run, bpm}`; из `Fnow`, `tick`, `sounding`, кубика, снимка и `restore` убрать `u`, `uT`, `held`, `strip`; `tick` (релаксация u) удалить; снимок без `u`/`uT` (старые снимки с ними открываются, лишнее игнорируется);
- `Sound::step` и `glide_` удалить;
- замок MIDI: условие `clk_ && grid.on && grid.p > 0 && run`.

**Зеркало** (сжимается, ключи в одном месте): голова = 5 fx + `run, bpm, P, F, strikes, locked` = 11; на кольцо 7 (`on, under, phi, lvl, inst, len, flt`); `MIRROR_N = 11 + 8·7 = 67`. Менять во всех слоях: `world.hpp/cpp`, `model.js` (`HEAD`, `M`), `tools/horo-scenarios.mjs`, `HoroMirror.swift`, буфер 64 → 72 в `HorologiumView.swift`, тесты, читающие индексы (`sdk_test.cpp ~4327/4346`, `HorologiumTests`, `HoroMathTests`).

**Нумерация действий** — оставить дыры или переименовать единообразно во всех слоях сразу (`ACT` в `model.js`, `Act` в Swift, `horo-scenarios.mjs`); решает план.

**Веб** (`worlds/horologium/`): только удаление, чтобы мир работал на новом ядре: `pend`, `grab/swing/tapPendulum/release`, `uOfE/eOfU`, шкала tempus, `drawPendulum`, строки легенды, `t2d.horo.bob/strip/pend`. Пэдов и фильтра в вебе нет (веб заморожен; ключ `flt` в снимке веб хранит и пропускает). Эталон `tools/ref/horologium-model.js` править синхронно.

## 2. Пэды (Swift)

Ряд из 8 пэдов по одному на кольцо (II…IX) в нижней части экрана (освободилась зона от строки отношения до низа). Кольца можно крупнее (формула `R` в `HoroGeo` пересчитывается под свободное место; финальные числа — в плане, проверка скриншотом).

- **Вид:** тонкий кружок (hairline) с римской цифрой кольца; включён — яркая цифра и точка; выключен — тускло. Под пэдом мелким курсивом (EB Garamond) имя инструмента (`Horo.instNames`). Зона касания ≥ 44 pt (шаг пэдов ≈ `Ws·0.8/8`, при необходимости кружок меньше зоны). Вспышка пэда на удар — только если сигнал удара кольца уже доступен в Swift (иначе не делаем).
- **Жесты:** тап — `on` кольца (то же `Act.ring [on]`); удержание (`Touch.holdMs`) — `ringSpec(i)`, та же плашка. Жесты на самом кольце не меняются (тап вкл/выкл, двойной — унтертон, вдоль — длина, удержание — плашка).
- **Ступица:** тап — пуск/стоп, удержание — темп (как есть).
- **Легенда:** убрать строки про маятник и tempus; добавить «tap a pad — sound on/off; hold — its settings».

## 3. Фильтр на голос

`flt` ∈ [0, 1], умолчание 0.5 = выкл. Влево — lowpass, вправо — highpass.

- **Отображение** (`Sound`, на блок): мёртвая зона 0.47…0.53 → байпас. Ниже — lowpass, срез экспоненциально от 20 кГц (при 0.47) к 200 Гц (при 0); выше — highpass от 20 Гц (при 0.53) к 8 кГц (при 1). Резонанс небольшой (Q ≈ 2 дБ в терминах `sdk::Biquad`). Частота ограничена `< sr/2`.
- **Место:** отдельный `sdk::Biquad` на кольцо в `Sound::O` (не `Drum::f_`), в цикле активных голосов `Sound::process` сразу после `d.step()·KIT`, до панорамы; `set()` раз в блок; `flt` сглаживается одним полюсом, чтобы не щёлкало при LFO и жесте. Хвост выключенного кольца идёт через тот же фильтр (`horoTailOff` остаётся зелёным); состояние фильтра сбрасывается вместе с `O{}`.
- **Параметр:** `RingKey::FLT = 6` (`NRK = 7`), `setRing` зажимает 0…1, мусор → 0.5; `clear` и кубик возвращают 0.5 (кубик — кроме выбранного ниже). Снимок: `flt` в `r[i]`, нет или мусор → 0.5.
- **LFO:** новые ключи `21 + i` (фильтр кольца i), существующие `5 + 2i` / `6 + 2i` не двигаются — миграции нет. `ACT_LFO` расширить до `key < NFX + 2·NR + NR`; тесты `horoLfo`, `horoLfoIgnores` обновить.
- **Плашка кольца (Swift):** шестая строка *filtrum* между *level* и *instrument*; `get = flt`, `set` шлёт `Act.ring [6, v]`; подпись: `off`, `low 1.2 k`, `high 180` (Гц/кГц, округлённо); LFO-код `21 + i`, `lfo.keys` дополнить.
- **Кубик (мягко):** новые вызовы `rng` — только в конце, после `materia`, чтобы порядок прежних бросков (и паритет ядро / фасад / эталон) не менялся: `pick = floor(R()·3)` — одно из трёх звучащих колец; `R() < 0.5` — фильтр применяется, иначе все `flt = 0.5`; `flt` = `0.30 + 0.17·R()` (lowpass, срез ≈ 0.9–12 кГц) или `0.53 + 0.12·R()` (highpass, срез ≈ 30–350 Гц), знак выбирает `R() < 0.5`. Максимум один фильтрованный голос на бросок; остальные кольца `flt = 0.5`.
