# Cymatica — модальный мир с секвенсером

Дата: 2026-10-20. Статус: дизайн согласован с автором по частям, спека на ревью.

## Зачем

Второй играющий мир touch2decay. Tenebrae — дрон и шум на планетах; Cymatica — **ударный модальный синтез**: одна звучащая пластина Хладни, по которой бьют и ведут смычком, и секвенсер-астролябия, который играет узоры ударов. Песок на пластине собирается в фигуры Хладни — картинка честно показывает, какие моды звучат.

Миры звучат одновременно: дрон из Tenebrae и узор из Cymatica — вместе.

Сначала звук и поведение, графика — строгая ч/б гравюра как в Tenebrae; цвет и настоящие гравюры Хладни — отдельно, потом.

## Что сказал автор (решения)

- Тема модального мира — **Cymatica** (фигуры Хладни), а не Cabbala: 10 сфирот не ложатся на модальный синтез.
- **Без планет**: экран — одна большая круглая пластина.
- Вместо солнца в углу — **резонатор Гельмгольца**.
- Высота — **щипок = размер пластины** (больше — ниже).
- Параметры пластины — **в веере FX этого мира**; закреплённый смычок — **кольцом**, как планета.
- Синтез рассчитан на удар — нужен **секвенсер, мелодический и пошаговый**: два слоя разной длины (полиметрия), запись **игрой**, на экране — **астролябия вокруг пластины**.
- **Все миры звучат одновременно.**
- Движок — **AudioWorklet** (звук и часы секвенсера в звуковом потоке).

Допущения (не обсуждались отдельно, приняты по умолчанию): картинка пока ч/б; III и IV на карте — бледные гравюры без входа; одна спека на три подпроекта, планы — по одному на подпроект.

## Порядок: три подпроекта, три выкладки

1. **Миры модулями** — карта снова включена, Tenebrae живой, Cymatica — пустая пластина с резонатором (без звука), III и IV — бледные *nondum*.
2. **Пластина** — звук, удар, смычок, закреплённые смычки с кольцом, щипок-высота, песок, веер FX.
3. **Секвенсер-астролябия** — кольца, запись, правка, пуск, темп, кубик, отмена.

Между выкладками автор проверяет на iPhone.

## 1. Миры модулями

### Карта

- `WORLDS_ON = true`. Тап по предмету в углу мира открывает карту Universum (в Tenebrae — солнце, в Cymatica — резонатор).
- Четверть **II (вверху слева) — Cymatica**: на карте `II · Cymatica`, подпись `figurae sonorae`. Cabbala уходит с карты; `art/kircher-tree.png` и код `artCabbala` остаются в репозитории, не используются.
- Четверти **I и II** на карте — **живые снимки** своих миров (как сейчас снимок Tenebrae, `snapC`): у каждого мира свой снимок, обновляется при уходе на карту.
- Четверти **III и IV** — их гравюры бледно (`globalAlpha` ≈ 0.35) с подписью *nondum*; тап по ним ничего не делает. Гравюры снова грузятся (`ART_SRC`), но без Кирхера; в `STATIC` (`sw.js`) возвращаются нужные файлы.
- Угол предмета в каждом мире — смежный с центром карты (как `sunCorner`): Tenebrae — нижний левый, Cymatica — **нижний правый**.

### Общее и своё

Общее для всех миров (хозяин, `app.js`): верхняя строка (громкость, лад, кнопка FX, кубик, отмена, корзина), мастер-выход (громкость `masterG`, компрессор, мягкий лимитер, анализатор уровня), лад `scl`, карта, служебные помощники рисования.

Своё у мира — объект с крючками:

```js
{
  n: 'II', title: 'Cymatica', sub: 'figurae sonorae',   // заголовок в верхней строке = title
  corner: { at() /* {x,y} */, hit(f), draw(now) },      // предмет в углу; тап — карта
  fx: { sectors, get(k), set(k, t), text(k) },          // лучи веера FX этого мира
  build(ctx, out),          // создать звук и подключить к общему мастеру (вызывается при создании AudioContext)
  enter(), leave(),         // вошли / ушли (звук не останавливается)
  down(f), move(f), up(f),  // касания по поверхности мира (после верхней строки и предмета в углу)
  wheel(e),                 // колесо / щипок тачпада на компьютере
  draw(now),                // кадр мира (под верхней строкой)
  dice(), clear(),          // кубик и корзина — только этот мир
  snapshot(), restore(s),   // для отмены; у каждого мира своя история (10 шагов)
}
```

- **Tenebrae** не переписывается: его существующие функции оборачиваются в такой объект (тонкий адаптер). Веер FX, кубик, отмена, корзина и рисование Tenebrae работают как сейчас.
- Верхняя строка рисует заголовок мира (`title`), кнопка FX открывает веер с лучами текущего мира. Отмена и корзина работают с текущим миром.
- Все миры звучат одновременно: каждый мир подключает свой выход (уже после своих FX) к общему входу мастера. Голоса Tenebrae продолжают звучать, пока ты в Cymatica, и наоборот.

### Хозяин отдаёт мирам

Маленький объект `T2D` (глобальный, создаётся в `app.js` до загрузки миров): `ctx` (геттер), `master` (вход мастера), `scl`, `freqOfSemi`/`snap` (лад), `W/H/DPR`, `topY` (низ верхней строки), помощники `ink`, `ring`, `dot`, `text`, `mapText`, `glowAt`, `hairBox`, фабрика зала `hall()`, `openRing(...)` (кольцо на весу и панель LFO), `goMap()`.

### Файлы

- `app.js` — хозяин и Tenebrae.
- `cymatica.js` — поверхность, песок, астролябия, связь с пластиной (обычный скрипт, подключается после `app.js`).
- `plate-worklet.js` — AudioWorklet: звук пластины и часы секвенсера.
- Сборки нет. Новые файлы — в `SHELL` (`sw.js`) и с тем же `?v=` в `index.html`.

### Готово, когда

Карта открывается из обоих миров, переход туда-обратно не прерывает звук Tenebrae, в Cymatica видна пустая пластина с резонатором и строка с заголовком «Cymatica», III и IV бледные и не открываются, Tenebrae работает как раньше (сценарии `tools/shot.py` проходят).

## 2. Пластина (`plate-worklet.js` + поверхность в `cymatica.js`)

### Моды

24 моды круглой пластины — первые 24 пары `(m, n)` (m — узловые диаметры 0–8, n — узловые окружности 1–4) в порядке возрастания нуля функции Бесселя `j(m,n)`: (0,1), (1,1), (2,1), (0,2), (3,1), (1,2), (4,1), (2,2), (0,3), (5,1) и так далее.

- **Форма моды** (для громкости по месту удара и для песка): `φ(m,n)(r,θ) = J_m(j(m,n)·r) · cos(mθ)`, `r ∈ [0,1]` — доля радиуса пластины.
- **Частота моды** `f_k = f0 · ratio_k(structure)`; `structure ∈ [0,1]` плавно перетекает между четырьмя строями:
  - 0 — **струна**: 1, 2, 3, … (гармонично);
  - ⅓ — **мембрана**: `j_k / j(0,1)`;
  - ⅔ — **пластина**: `(j_k / j(0,1))²` (сильно неровно);
  - 1 — **колокол**: hum 0.5, prime 1, tierce 1.2, quint 1.5, nominal 2; моды с 6-й по 24-ю — отношения строя «пластина» для тех же мод, умноженные так, чтобы 6-я была 2.5.
  Между соседними строями — интерполяция отношений в логарифме.
- **Громкость моды при ударе** `a_k = |φ_k(x, y)|`, нормированная по максимуму формы моды. В узле мода молчит.
- **Затухание** `T60_k = T(damping) · (f0 / f_k)^(brightness')`: damping — общая длина (≈ 0.08–12 с, логарифмически), brightness — насколько быстрее гаснут верхние моды (яркость ↑ — верх живёт дольше). Это и есть «материал»: дерево — коротко и глухо, латунь — звонко, стекло — долго и светло.
- Моды выше ~18 кГц не считаются.

Каждая мода — двухполюсный резонатор: `y[n] = 2R·cos(ω)·y[n-1] − R²·y[n-2] + g·x[n]`, `R = 10^(−3 / (T60·fs))`. Стерео — моды через одну чуть влево/вправо.

### Возбудители

В каждой точке касания (и каждом закреплённом смычке):

- **удар** — короткий импульс-полукосинус длиной 0.5–5 мс (твёрдость молоточка: короче — больше верха), сила — `vel`;
- **смычок** — непрерывное возбуждение, пока держишь: шум, пропущенный через фрикционную кривую от скорости пластины в точке (как bow в Elements); нажим — грубее и громче;
- **шум** («дыхание») — ровный полосовой шум через моды.

Живое касание выбирает тип само: короткий тап — удар, держишь дольше ~150 мс — смычок. У закреплённого смычка тип плавно морфится `exciter ∈ [0,1]`: смычок ↔ шум. Повторяющиеся удары даёт секвенсер (часть 3).

### Голоса и высота

- Высота — **размер пластины**: `f0` 55–880 Гц; при включённом ладе — к ближайшей ноте лада.
- **4 голоса-пластины** в worklet. Удар с новой нотой берёт голос с той же нотой или самый тихий; прошлые ноты дозванивают на своей высоте. Смычки звучат на текущем `f0`.
- Нагрузка: 4 × 24 резонатора + возбудители — порядка 10⁷ простых операций в секунду; сравнивается `tools/render.py`.

### Связь с основным потоком

Сообщения в worklet (`port.postMessage`):

- `{ t: 'params', structure, damping, brightness }`
- `{ t: 'f0', hz }`
- `{ t: 'strike', x, y, vel, hard, hz? }`
- `{ t: 'bow', id, x, y, on, exciter, pressure, amp }` — живые и закреплённые смычки
- `{ t: 'seq', ... }` — см. часть 3

Из worklet ~30 раз в секунду: `{ t: 'energy', e: Float32Array(24) /* сумма по голосам */, voices: [{ hz, level }] }`, и на каждом шаге секвенсера `{ t: 'step', r, m, time }`.

### Поверхность и жесты

- Раскладка (телефон 390×844): сверху общая строка; посередине пластина — круг радиусом до `W/2 − 44` (с кольцами астролябии вокруг); центр по высоте — середина места между строкой и низом. Резонатор Гельмгольца — **нижний правый угол**, выступает на четверть, тап — карта.
- **Тап** по пластине — удар в эту точку. **Держишь** — смычок, ведёшь палец — смычок едет (тембр меняется).
- **Двойной тап** — закрепить смычок: остаётся гравированной меткой и звучит. До 3 закреплённых. Метку можно тащить. **Долгое касание метки** — кольцо: лучи `exciter`, `pressure`, плюс полоса amp и панель LFO, как у планет (через `T2D.openRing`). Утащил метку за край пластины — смычок убран.
- **Щипок** — размер пластины (высота); пока щиплешь и секунду после — подпись ноты и герц рядом. Колесо / щипок тачпада на компьютере — то же.
- **Веер FX Cymatica**: `structure`, `damping`, `brightness`, `hall`, `echo`. Зал — `T2D.hall()`, эхо — стерео-задержка с обратной связью, время — восьмая с точкой по темпу секвенсера (без секвенсера — 0.375 с).

### Песок

- ~2500 крупинок внутри пластины (массивы `Float32Array`).
- Формы 24 мод посчитаны один раз сеткой 96×96 (на круг). В кадре — поле колебаний `A(x,y) = sqrt(Σ E_k · φ_k(x,y)²)` по энергиям из worklet (пересчитывается, только когда энергии изменились заметно).
- Каждая крупинка за кадр делает случайный шаг длиной `∝ A` в своей точке: где пластина колеблется — скачет, в узлах — оседает. Одна главная мода — чёткая фигура, сложный звук — размыто и неспокойно. В тишине песок лежит.
- Рисуется точками 1–1.5 px одним цветом; без полноэкранных проходов и `shadowBlur`.

### Картинка (пока)

Ч/б, как Tenebrae: край пластины — двойная гравированная линия с засечками, песок — светлые точки, резонатор — гравированный шар с горлышком; дышит общей громкостью (как солнце). Метки смычков — маленькие гравированные кружки с засечкой-смычком.

### Готово, когда

Тап звучит и затухает, центр и край пластины дают разные спектры (рендер), смычок тянется, закреплённый смычок звучит сам и правится кольцом, щипок меняет высоту и притягивается к ладу, песок собирается в фигуры, веер FX работает, Tenebrae при этом звучит, нагрузка — без отставания звуковых часов в `measureStrain`.

## 3. Секвенсер-астролябия

### Кольца

- Вокруг пластины — два неподвижных гравированных кольца: **внешнее — ритм** (по умолчанию 16 шагов), **внутреннее — мелодия** (по умолчанию 7). Шаг — засечка; по каждому кольцу идёт своя стрелка.
- Часы — шестнадцатые. На каждом тике обе стрелки сдвигаются на шаг. **Ритм** решает, будет ли удар и куда; **мелодия** — какой нотой. Длины независимы (1–16) — полиметрия: 16 и 7 повторяются через 112 шагов.

### Данные

```js
seq = {
  bpm: 96, playing: false, rec: false,
  rhythm: { len: 16, steps: [ { x, y, vel } | null, … ×16 ] },
  melody: { len: 7,  steps: [ semi | null, … ×16 ] },   // null — текущий размер пластины
}
```

Часы и узор живут в worklet (`{ t: 'seq', bpm, playing, rhythm, melody }` при каждом изменении); на каждом тике worklet сам бьёт удар нужной нотой и шлёт `{ t: 'step', r, m, time }`.

### Запись игрой

- Внизу у астролябии, под большой палец, два гравированных кружка: **▶/■** (пуск/стоп; зажал и ведёшь влево-вправо — темп 40–200, рядом подпись BPM) и **● запись** (на остановленном — пуск + запись).
- Пока идёт запись: **тап по пластине** ложится в ближайший по времени шаг ритма (с местом удара); **щипок** пишет ноту в текущий шаг мелодии (с ладом — ровно по нотам). Без записи тапы просто звучат поверх.
- Ближайший шаг считает основной поток по последнему событию `step` и темпу (`nearestStep`).

### Правка

- Записанные удары — маленькие метки на пластине, вспыхивают, когда их шаг играет. Тащишь метку — меняешь место удара (тембр); утащил за край пластины — удар удалён.
- Тап по засечке ритма — включить/выключить удар (новый — в место последнего удара).
- Засечку мелодии тянешь к центру/от центра — нота ниже/выше (по ладу, если включён).
- Длина кольца — перетащить выступ-засечку на его конце.

### Общие кнопки в Cymatica

- **Кубик** — генеративный узор: ритм — Евклид (k ударов на n шагов, k и n случайные в разумных пределах), места ударов случайные, мелодия — случайное блуждание по ладу (без лада — по пентатонике), случайные длины колец.
- **Корзина** — очищает узор и закреплённые смычки этого мира (часы идут дальше).
- **Отмена** — помнит узор, смычки, параметры пластины, размер, темп, длины колец.

Уходишь в другой мир — секвенсер играет дальше.

### Готово, когда

Узор из записи и из кубика играет ровно в доли (рендер: интервалы между ударами не дрожат), полиметрия слышна, правка на кольцах и метках работает, темп меняется без сбоя, отмена возвращает узор.
