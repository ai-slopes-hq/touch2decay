# Serpentes — змеиное царство, змеи-волноводы

Под Laboratorium, координаты (−1, −2). Звук — **физическое моделирование**: каждая змея — волновод (струна/труба). Змей **рисуешь пальцем**. Картинка — подземелье линиями: пласты земли штрихом, корни древа жизни, змеи с чешуёй.

Решено с автором: змеи рисуются пальцем.

## Что что значит

| Где | Что | Звук |
|---|---|---|
| змея | нарисована пальцем, тело идёт по штриху | голос: волновод (до 5 змей) |
| длина тела | длиннее — ниже (с ладом — по ступеням) | высота: длина линии задержки |
| голова, язык | язык щёлкает | щипок — возбуждение |
| тело под пальцем | змея шипит | шум продувает волновод (как труба, пока держишь) |
| изгибы тела | туже свернулась — звонче | яркость (lowpass в петле) и дисперсия |
| змея кусает свой хвост — уроборос | кольцо замкнулось | петля самовозбуждения: звучит сама, бесконечный дрон |
| две змеи кусают друг друга | укус — связь | связанные волноводы: симпатический резонанс |
| стоячая волна по телу | узлы гармоник бегут по чешуе, пока звучит | спектр голоса (картинка = информация) |
| сброшенная кожа | бледный след прежнего тела | затухание (decay) |
| корни древа жизни в правом верхнем углу | нижняя четверть медальона, у Laboratorium над нами — верхняя (крона); тап — карта | — |

## Жесты

- **Рисуешь пальцем по пустому месту** — новая змея по штриху; отпустил — змея готова и щёлкает языком (первый звук).
- **Тап по голове** — щипок. **Держишь на теле** — шипит, пока держишь.
- **Тянешь хвост** — длиннее/короче (глиссандо, змея ползёт).
- **Тащишь голову к своему хвосту** — уроборос (дрон); оттащить — разорвать.
- **Тащишь голову на другую змею** — укус, связь; оттащить — отпустить.
- **Долгое касание змеи** — кольцо, как в Tenebrae: тело (string — струна, tube — труба), яркость, затухание, шипение (сколько шума), яд (перегруз своего голоса).
- **Двойной тап по змее** — уползает (удалить).
- **Веер FX:** venenum (перегруз), fovea (зал-яма), sibilus (шипение во всём), exuviae (затухание).
- **Кубик** — 2–3 змеи случайной длины (по ладу), одна, может, уроборос. **Корзина**, **отмена** — как везде.

## Звук

- AudioWorklet: на змею — линия задержки (длина = частота дискретизации / f) + lowpass (яркость) + allpass (дисперсия, изгибы) в петле; `tube` — отражение с минусом и нелинейность «трости» (как кларнет), `string` — Карплус-Стронг.
- Возбуждение: щипок — короткий шумовой импульс с окном; шипение — непрерывный шум со своей громкостью.
- Уроборос — усиление петли чуть больше 1 с мягким ограничителем (`tanh`) — сама звучит, не взрывается.
- Связь змей — доля сигнала одной в петлю другой.
- Экономия: молчащая змея не считается (затухла ниже порога — пропуск), мир отцеплен в тишине.

## Картинка

- Тема: тёмная земля, чернила — зеленовато-костяные; чешуя — штрих по телу, гуще у головы.
- Тело змеи — сглаженная кривая по точкам штриха, ширина сужается к хвосту. Стоячая волна — поперечные «узлы» по телу, двигаются по уровню и высоте голоса.
- Подписи (нота, тело) — только пока тянешь.

## Открытые вопросы

- Как рисование змеи уживается с другими жестами на пустом месте — пустое место только для рисования, остальное — по змеям.
- Длина штриха и высота: линейно в пикселях (длиннее — ниже) или по ступеням лада с «прилипанием» длины.
