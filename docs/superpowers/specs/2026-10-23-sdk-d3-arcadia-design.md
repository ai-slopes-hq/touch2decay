# SDK, подпроект D3: Arcadia в `t2d.wasm`

23.10, автор: «D3 — Arcadia в ядро, как Monochordum и Horologium», ветка `native` поверх v175. Основание — спеки B, D1, D2; образец — Horologium (D2): мир SDK, фасад модели в вебе.

## Что куда

- **Ядро** (`core/worlds/arcadia`, слот 12):
  - **страна** (`land`) — порт `genLand(seed)`: тот же рельеф `z`, маска озёр `lake` (float32, как `Float32Array`), реки и озёра; `Math.hypot` — по алгоритму V8 (иначе последние биты расходятся и реки уходят в сторону); имена и вершины ядру не нужны — они для картинки;
  - **странники** (`model`): слоты 0…3 в порядке добавления, `{u, v, oct, r, fig, mode, sp, lvl}`, путь `routeOf` (вниз к воде / вверх к вершине по уклону), нота `hzOf` по ладу хоста, fx, снимок — тот же JSON;
  - **звук** (`sound`) — порт `terrain-worklet.js`: петли по рельефу, 2D Catmull — Rom 4 × 4 и отражение за краем, рябь озёр, цели (still / circuit / wander / river / summit), DC, АРУ, срез, tanh; `Math.random` → `Rng` от зерна (порядок вызовов прежний); Catmull — Rom и АРУ — внутри мира;
  - **шина** (как прежний `engine.js`): петли → pre → сухо + `sdk::Phaser` (6 allpass 320·1.7ⁱ, Q 0.6, LFO 0.11 Гц глубиной 150 + 650·phaser, мокрое phaser·0.95) → mix → сухо ×(1 − 0.3·chorus) + `sdk::Chorus` (13 / 19 мс, 0.27 / 0.19 Гц, глубины 3.5 / 4.5 мс, ∓0.8, мокрое chorus·0.75) → ×1.5; посыл в hall — от mix, hall²·1.4 ×1.5. Ручки — сглаживание 0.05 с; фейзер и хор при нуле не считаются (как отцеплены).
- **Страна считается по кускам.** `genLand` — ~20 мс (V8 на сервере, на iPhone дольше); в звуковом потоке это щелчок у всех миров. Ядро делает новую страну шагами — фиксированное число блоков (`LAND_BLOCKS`), долю работы на блок; пока считается, звучит прежняя; готова — перетекание 0.5 с, как раньше, и пути river / summit пересчитываются. Первая страна (`SEED0`) — в `prepare`, сразу.
- **Веб:** фасад `worlds/arcadia/model.js` с прежним API (`t2d.arc`, view, тесты): действия — сразу в state и в ядро (номер сообщения), зеркало ~60/с. **Картинке страна нужна сразу и без звука** (ядро живёт только после первого касания) — фасад держит ту же `genLand` для рисования, тест сверяет её с ядром; `routeOf`, `hzOf` — так же (чистые функции). След блуждания — картинка, в фасаде: центры петель — из зеркала (склейки `engine → model.track` больше нет). Кубик — в фасаде (`rng`), в ядро — сцена целиком (`restore`).
- `engine.js` — тонкий: сухой выход `T.core.dry[12]` в канал, `bind` / `sync`; метры `centers`, `gains` — из зеркала. `terrain-worklet.js` удаляется. `SDK_WORLDS` + 12, `sw.js`, v176.
- **SDK:** `sdk::Phaser<NS>` (`core/sdk/phaser.hpp`) — allpass как `BiquadFilterNode` (f ≤ 0 или ≥ Найквиста — фильтр пропускает как есть, как в Chromium), LFO на частотах; его возьмёт ещё кто-то. `sdk::Chorus` — у линии своя доля глубины (`k`, по умолчанию 1).

## Зеркало и действия

- `action`: `ADD` (i — слот, a = `[u, v, oct, r, fig, mode, sp, lvl]`), `DROP` (i), `MOVE` (i, a = `[u, v]`), `SET` (i, a = `[key, v, route]`), `FX` (i = key, a = `[v]`), `LAND` (a = `[seed]`), `CLEAR`; сцена — `restore`.
- Зеркало: fx[7], зерно звучащей страны, страна считается (0/1), затем на слот: есть, u, v, oct, r, fig, mode, sp, lvl, f, центр петли cx, cy, rs, уровень.

## Проверка

- Эталоны: `tools/ref/terrain-worklet.js` (ГСЧ с зерном), `tools/ref/arcadia-model.js` (прежняя модель), `tools/ref/arcadia-engine.js` (прежний engine).
- Звук ядра против эталона — 1e-6 на сэмпл (фейзер и хор 0; шина — ×1.5): действия прежней модели → сообщения прежнего engine → эталонный worklet; новая страна в эталоне — через `LAND_BLOCKS` блоков, как в ядре. Центры петель и уровни — те же. Страна ядра против `genLand` — z, lake.
- Шина против прежней Web Audio — в браузере (`tools/arcadia-bus.py`, как `mono-bus.py`): RMS и октавы.
- Тесты модели — на эталоне и на ядре (`tools/models/arcadia-core.mjs`); `shot.py arcadia` и все сценарии; ядро в тишине не дороже v175.

## Отличия

- Новая страна в звуке — на ~0.2 с позже картинки (куски); пока путь river / summit на новой стране не готов, петля стоит дома.
- Фейзер: коэффициенты allpass — раз в 16 сэмплов (в Web Audio — каждый сэмпл; LFO 0.11 Гц, разница не слышна).
- Мир всегда в ядре; молчит — не считается (было — отцеплялся через 8 с тишины). Звук с первого касания, без загрузки модуля.

**Вне D3:** остальные миры; LFO строк в ядре.
