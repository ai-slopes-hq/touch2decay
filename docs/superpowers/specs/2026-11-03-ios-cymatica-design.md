# iOS-приложение — фаза 3: Cymatica на Swift

**Дата:** 2026-11-03 · **Статус:** черновик, решено без автора (как Natura, Portus) · **Фаза:** `docs/native-ios-plan.md`, фаза 3 (миры по одному) · **Образец:** Portus — `ios/app/T2D/Portus/`, спека `2026-11-03-ios-portus-design.md`; разведка — `~/.claude/handoff/cymatica-map.md` (не в git)

## Цель

Десятый нативный мир — II · Cymatica: пластина-ханг (клетки — ноты лада по секторам и трём кольцам-октавам), удар по месту, метки мест мелодии, астролябия — два кольца секвенсера своей длины (ритм — удары, мелодия — места на пластине; полиритм), кнопки ▶ ● сетка луна под пластиной, щипок высоты, вращение колец и пластины двумя пальцами, луна (дрейф пластины), резонатор в углу (отзыв и карта), созвездия, веер FX и легенда — на Swift + CoreGraphics. Модель и звук уже в ядре (`core/worlds/cymatica/`, слот 2): Swift разбирает зеркало и «услышанное» и шлёт действия. **Ядро не меняется**: `DICE` с зерном есть, LFO в Cymatica нет и в вебе.

Готово, когда: Cymatica открывается с карты; удар по клетке (нота клетки, клетка горит по уровню голоса, звезда созвездия), клетка выше 1760 Гц молчит; щипок меняет высоту (с ладом — по ступеням); пуск / стоп и темп (▶), запись игрой и пошаговая запись (●, курсор, пропуск), сетка (тап — 16 → 8 → 4, удержание — причесать), луна (тап — вкл / выкл, удержание — плашка `luna`); на кольцах: тап по гнезду ритма — удар, тянуть удар — шанс, бусина мелодии — нота вверх / вниз, край заливки — длина кольца; метка места — тап звучит, тянуть — перенос, за край — снять; вращение колец и пластины двумя пальцами; резонатор отзывается и ведёт на карту; веер FX (`aether`), кубик, корзина, отмена работают как в вебе; пары снимков симулятор ↔ веб сходятся глазами; проверки ниже зелёные.

## Решения

1. **Всё как в вебе** (`worlds/cymatica/view.js`, `core.js`, из `model.js` — `DRIFT_RATES`, `effF0`, `fs`, `driftDepth`, `echoDiv`): геометрия `plateGeo / astro / slotAng / slotOf` (`view.js:71-89`), раскладка ханга `noteList / degPerOct / cellIdx / noteAt / cellOf / cellCenter / scaleSemis / twistOrPinch` (`core.js:49-109`), порядок попаданий `down()` (`view.js:201-233`), `move / up` (`:110-136, :254-287`), удержания (`:323-338`), два пальца (`:161-199`), плашка луны (`:309-321`), веер (`:341-363`), кадр (`:647-661`), легенда (`host/legend.js:15-19`, 9 строк). Новых решений в картинке нет. Тема — `.base` (`Worlds.info(2)`). Заголовок `Cymatica`, подзаголовок `figurae sonorae` (`index.js:22`). Время картинки — секунды Swift, в формулах веба (`performance.now()` в мс) — `now·1000`.
2. **Где код:** `ios/app/T2D/Cymatica/` — `CymMath.swift` (константы, раскладка ханга, геометрия пластины и астролябии, `noteName`, `effF0 / fs`, тексты веера и плашки луны), `CymMirror.swift` (разбор зеркала и `heard`), `CymState.swift` (чистый помощник без `Core`: собственные значения, `born` из диффа зеркала, `pulse`, созвездия, отзыв резонатора, `shownF0`, повороты `ringOrn / ringTurn`), `CymTouch.swift` (`extension CymaticaView`: касания → действия, пара пальцев), `CymSheets.swift` (веер, плашка луны), `CymaticaView.swift` (класс `World`: связка, тик, кубик, корзина, отмена, легенда), `CymScene.swift` (кеш волн), `CymDraw.swift` и при росте больше ~300 строк — `CymAstro.swift` (астролябия) / `CymFrame.swift` (кадр). Регистрация: `Worlds.swift` — `view: false → true`; `App.makeView` — ветка `CymaticaView.slotN` (2); сцены `-shot cym*` в `App.swift` (`shotCymatica`), `shot.sh` — список сцен; `project.yml` — источники теста `T2D/Cymatica`. С `view: true` слот 2 входит в маску `watch` — нативный тик зовёт `heard()`, и в нём оживает гул резонатора (`answerCheck`), как в вебе.
3. **Зеркало** (`core/worlds/cymatica/world.hpp:40-47`, `world.cpp:164-198`, `MIRROR_N 175`): `0–23` энергии мод, `24–31` голоса `(hz, level)×4`, `32` f0, `33–39` fx (structure, damping, brightness, hall, echo, time, chance — порядок `Fx` из `model.hpp:21`, `bridge.js:10`), `40–44` bpm, playing, rec, rlen, mlen, `45–108` ритм `16×(on, vel, chance, has)`, `109–156` мелодия `16×(on, x, y)`, `157–161` луна `on, depth, rate, shape, k`, `162–168` grid, lastHit x / y, cursor, stepRec on / r / m, `169–174` эхо (картинке не нужно). Короче 175 или не `isFinite` (кроме мест, где ядро законно кладёт NaN — план сверяет с `world.cpp`) — отказ, прежнее зеркало остаётся. Читатель внедряется (тесты — на фейке), буферы предвыделены (≥175 и ≥80).
4. **Услышанное** (`world.cpp:200-210`, записи по 5, `HEARD_MAX 80`): `[1, r, m, time, hit]` — сыгранный шаг: `pulse` гнёзд `r` и `m` (мигание 220 мс), `lastStep` для стрелок (шаг — `60000 / bpm / 4` мс, `view.js:462`), при `hit` — звезда созвездия в месте шага мелодии; `[2, semi, 0, 0, 0]` — резонатор отзывается (имя ноты 1.4 с). Время приёма — время тика. Читать до 4 раз за тик, пока полно; `idle()` сливает кольцо без событий.
5. **Действия** — через `Core.action(slot 2, …)` кодами `Act` ядра (`world.hpp:36`, 0…35); натив шлёт только уровня модели (`STRIKE_AT 7 … CLEAR 30`) плюс `STRIKE 2` для метки места. `STRIKE_AT [x, y]` и `STRIKE` — с `touchTime` пальца (запись игрой берёт фазу шага ядра); прочие — `touchTime: 0`. `LOCK`, `BOW*`, `HUM`, `LOAD`, `PARAMS / F0 / SEQ / FX` натив не шлёт.
6. **Метка места** (`model.js:139-142`): `STRIKE [x, y, hz, vel, hard, rec]`, `hz` — из Swift-`noteAt` по клетке места с ладом и `effF0`, остальное — как в вебе. Нового действия ядра не заводим.
7. **Кубик:** `DICE [seed]`, зерно — 32 бита из генератора, внедрённого в вид (тесты и сцены `-shot` — фиксированное; в работе — системный). Ядро само ставит `playing` («часы идут», `model.js:207`); натив `PLAY` не шлёт. Снимок отмены — хоста, до кубика. Числа кубика у натива и веба при одном зерне совпадают (ядро — то же).
8. **Собственные значения до зеркала** (правило Natura / Portus: своё значение после своего действия, пока не сошлось с зеркалом или 0.25 с после последнего своего действия по полю; всё — в `CymState`, каждое действие — через одну обёртку `send`): `bpm`, `playing`, `rec`, `rlen`, `mlen`, `f0`, `fx×7`, луна `on, depth, rate, shape`, `grid`, `cursor`, `stepRec`, шанс удара по гнезду, место метки мелодии под пальцем (`MOVE_MARK`). Правки узора, которые считает ядро (`STRIKE_AT` с записью, `BEAT`, `NUDGE`, `TURN`, `COMB`, `SKIP`, `DROP_MARK`, `DICE`, `CLEAR`), ждут зеркала (один блок звука). После `DICE` и `restored()` — сразу зеркало.
9. **`born`** (вспышка 500 мс у гнезда, `model.js:68-80`): дифф двух зеркал — гнездо ритма или мелодии, ставшее `on`; первое зеркало после входа, `restored()` и `scale()` — база без вспышек. `DICE` и `CLEAR` вспыхивают, как в вебе (план сверяет по `sendSeq`).
10. **Касания** (`view.js:201-287`; `TAP_MS 250`, сдвиг `TAP_MOVE 12`, «сдвинут» — от 10 px (`HOLD_MOVE` веб-хоста) — свои пороги от `x0 / y0`, не `Finger.moved` (14); `HOLD_MS 420`, удержание открывается в `tick`; пальцы независимы по `Finger.id`): порядок попаданий — кнопки ▶ ● сетка луна (r 22; ими жмут и вторым пальцем, в пару они не идут) → второй палец при живом первом → пара (`startTwo`) → `astroHit` (край длины, гнездо ритма, бусина мелодии) → мимо стола — `away` → метка места (r 11; не при записи и курсоре) → вне пластины — `away` → удар `STRIKE_AT` + звезда (клетка молчит — ничего). `move`: ▶ — темп 0.5 bpm / px (40…200), край — `LEN`, удар — шанс `CHANCE_AT` (Δr / 70, шаг 0.05, 0.05…1), бусина — `NUDGE` (Δr / 6 ступеней), метка — `MOVE_MARK`, за 1.05 r — `DROP_MARK`. `up`: сетка — `GRID` по кругу (если не было `COMB`), ▶ — `CURSOR −1` + `PLAY`, ● — `REC` или при стоящих часах `STEPREC`, гнездо ритма — `BEAT`, луна — `DRIFT_TOGGLE` (если тап не открыл плашку), бусина при стоящих часах — `CURSOR i`, `away` при пошаговой записи — тап < 12 px → `SKIP`, иначе курсор снят. Удержание: луна → плашка `luna`, сетка → `COMB`. Двойного тапа нет (он был у смычков). Общих часов и MIDI в iOS нет — `tempoFrom / transportFrom / syncLock` не переносим (как Portus).
11. **Два пальца** (`view.js:161-199`, `core.js:87-91`): цель — по средней дистанции пальцев от центра (< `rMax` пластина, < `RM` мелодия, иначе ритм); `twistOrPinch` — порог 10° / 20 px, побеждает большее из `dA/10` и `dD/20`; щипок — без лада 12 px на полутон → `SET_F0`, с ладом 18 px на ступень → `STEP_SCALE [fromSemi, steps]`; вращение — пластина 20° на ступень, кольца 22.5° на гнездо → `TURN i [k, исходный узор]` (исходный — из зеркала на начало жеста); `ringTurn` — картинка во время жеста, на отпускании `ringOrn += k·22.5°`. Хост уже даёт каждому пальцу свой `.world` — протокол `World` не меняется.
12. **Лад:** `noteList` (0…60 полутонов, с ладом — `scaleSnap(s) == s`, без — пентатоника `0, 3, 5, 7, 10`), `degPerOct` (`pcs.count` или 5), `scaleSemis` — из `World.scale(pcs:root:)`; `scaleSnap` — общий (`World.swift:64`). Смена лада — пересчёт раскладки, кеш волн не зависит от лада.
13. **Резонатор — предмет-угол** (`view.js:601-622`, центр `(W, H − safeBot)`, r 46): `cornerHit` → попадание в его круг → карта по маршруту хоста `.corner` (как солнца других миров; `goMap` мира не нужен). Угол Stage 44×44 (панель замеров) остаётся: резонатор досягаем выше и левее него. `drawShot` = `draw` (у веба нет `mapShot` для Cymatica).
14. **Плашки и веер** (как `view.js:309-363`):
    - **веер** `aether`: `structure 180°` (8 тел `STRUCT`), `damping 165°` (`0.08·150^v s`), `brightness 150°`, `hall 135°`, `echo 120°`, `chance 105°`, `time 90°` (`echoDiv`); `arc: fx.hall`; `SET_FX i [t]`; без LFO (коды −1);
    - **luna** — `depth` (`±N steps`), `rate` (`DRIFT_RATES`), `shape` (`sine | random`), hint `plate drift — tap outside to close`; `DRIFT_SET i [t]`; без LFO;
    - **легенда** — 9 строк (`host/legend.js:15-19`).
15. **Корзина и отмена.** `clear()` — `CLEAR`. `restored()`: пальцы, пара, удержания, свои значения, `ringTurn` сброшены; `born`-база — новое зеркало; созвездия, `pulse`, отзыв — только картинка, остаются. Снимок ядра не хранит `playing, rec, grid, cursor` — как в вебе.
16. **Рисование** (`view.js:45-661`):
    - **кеш волн** — `CGImage` `W × H × DPR` (DPR ≤ 2), ключ веба `W×H×DPR|round(fs)|topY|safeBot`, пересборка при сдвиге высоты на полутон, синхронно;
    - **в кадре** — порядок веба: волны, пластина (стол, край `r = rMax·(55/shownF0)^¼`, засечки 6°; `shownF0 → effF0`, τ 0.08 с), клетки (лучи, кольца, горят по `voices`: `glow = clamp((10·lg lv + 50)/40)`, имена нот — только при щипке), созвездия (до 24, жизнь 5 с), астролябия (лимбы с поворотом, заливка длины, удары — точки, шанс меньше и пунктир, бусины с подложкой, `blink` 220 мс, `born` 500 мс, стрелки, метки мест, 4 кнопки и подписи `bpm · per gradus | scribe · grid · luna ±k`, орбита луны, курсоры пошаговой записи, подписи шанса / темпа / ноты 1 с), курсор, подпись f0, метка вращения, резонатор (яркость `energy[0]`, отзыв 1.4 с с именем ноты); подписи `mapText` курсивом, только при касании;
    - производительность: без `shadowBlur`, ореолы — `glowAt`, градиентов в кадре нет, полноэкранный проход — только `drawImage` волн; буферы предвыделены; `dt` картинки ≤ 0.1 с.
17. **Не делаем:** смычки (`BOWS_ON = false` в вебе: удержание-смычок, двойной тап, кольцо смычка, `BOW*`), колесо и Shift-мышь (десктоп), сетку MIDI (`LOCK`), общий темп хоста, LFO (в вебе у Cymatica нет), правку ядра.

## Риски

- **Объём** (~1400 строк Swift и ~500 тестов) — два плана: (а) `CymMath`, `CymMirror`, `CymState`, `CymTouch`, `CymSheets`, `CymaticaView` без картинки (мир не включён на карте); (б) `CymScene`, `CymDraw` / `CymAstro` / `CymFrame`, сцены, включение на карте, доки.
- **Два пальца на iPhone** — порог вращения / щипка и цель по дистанции перенесены как есть; удобство одной рукой решает автор.
- **Резонатор у угла Stage** — часть круга под панелью замеров; если мешает — сдвиг решает автор.
- **Гул резонатора** включится в нативе впервые (раньше слот 2 не был в `watch`) — слушать на iPhone.
- Снимки — симулятор; звук, жесты на ощупь и производительность проверяет автор на iPhone.

## Решено без автора

Развилки решены «как в вебе»:

1. Смычки, колесо, Shift, MIDI-сетка не переносятся (в вебе выключены или десктопные).
2. Ядро не трогаем: метка места — `STRIKE` уровня пластины с `hz` от Swift; кубик — `DICE` с зерном.
3. Два пальца — внутри мира, протокол `World` не меняется.
4. Резонатор — `cornerHit` и маршрут `.corner`; угол панели замеров Stage остаётся.
5. Пороги касаний — веба (`TAP_MS 250`, `TAP_MOVE 12`), не хоста.
6. Темп — только ▶: общего темпа хоста в iOS нет.
