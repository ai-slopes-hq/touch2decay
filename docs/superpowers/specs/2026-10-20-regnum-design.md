# Regnum — королевство, шахматы короля

Справа от Natura, координаты (2, −1). Звук — **генеративный секвенсер-шахматы**: белые — клавесин, чёрные — орган. Партия **играет сама, но любую фигуру можно перетащить** — игра продолжается с новой позиции. Вместо солнца — **месяц**. Картинка — тронный зал линиями, доска на полу.

Решено с автором: партия сама, можно вмешаться.

## Что что значит

| Где | Что | Звук |
|---|---|---|
| доска 8 × 8 | столбец — шаг, ряд — ступень лада (снизу вверх) | секвенсер на 8 шагов |
| бегунок | свет из окна ползёт по столбцам | текущий шаг |
| фигура на столбце | звучит своим рядом | нота |
| белые | клавесин | щипковая струна (Карплус-Стронг) |
| чёрные | орган | регистры 16′, 8′, 4′, 2⅔′ |
| вид фигуры | пешка — короткая нота, ладья — длинная, ферзь — аккорд (тон + квинта), король — бас октавой ниже, конь — нота с форшлагом, слон — с глайдом | длина и украшение ноты |
| ход в конце такта | каждая сторона по очереди делает ход по правилам | мелодия меняется сама |
| взятие | фигура уходит с доски | голос замолкает |
| шах | вспышка на короле | акцент и каденция |
| мат / пат | партия кончилась, фигуры расставляются заново | начало новой формы |
| месяц в углу к центру карты | фаза — сколько тактов прошло в партии; тап — карта | — |
| залы замка | тронный зал, башня, склеп — в веере | реверб |

## Жесты

- **Тащишь фигуру** — переставить (на любую клетку, правила для тебя не обязательны); игра продолжается с этой позиции.
- **Тап по пустой клетке** — поставить последнюю выбранную фигуру; **тап по фигуре** — убрать.
- **Долгое касание фигуры** — выбор фигуры и цвета (как меню волн в Natura).
- **Тап по месяцу** — карта; пуск/стоп и темп — свеча на троне (тап — пуск, вбок — темп).
- **Веер FX:** aula (зал: тронный / башня / склеп), registra (тембр органа), ingenium (сила игры: случайные ходы ↔ лучший ход), tempo хода (каждый такт / каждые 2 / 4).
- **Кубик** — случайная позиция из середины партии. **Корзина** — начальная расстановка. **Отмена** — как везде.

## Звук

- Часы — по `ctx.currentTime` с запасом вперёд (как Natura). Ходы — по такту, между тактами.
- Клавесин — Карплус-Стронг (короткий шум в линию задержки с lowpass), щипок яркий, затухание по струне.
- Орган — сумма синусов-регистров, медленная атака, лёгкий воздух (шум) в начале.
- Шахматный «движок» — без библиотек: легальные ходы, простая оценка (материал + центр); `ingenium` — доля случайных ходов.
- Экономия: ноты — короткоживущие узлы, мир отцеплен в тишине.

## Картинка

- Тема: ночь — тёмно-синий фон, чернила — серебро лунного света. Без заливок.
- Доска в перспективе на полу тронного зала, клетки под палец (~44 px), фигуры — силуэты линиями (Стаунтон).
- Окно с месяцем, колонны, трон со свечой; ход — фигура скользит, взятие — падает.

## Открытые вопросы

- 8 шагов мало для мелодии — может, бегунок проходит доску дважды (по белым и чёрным отдельно)?
- Вид фигуры = длина/украшение ноты — проверить на слух.
