# iOS-приложение — фаза 2b-3б: concordia, микшер, панель audio

**Дата:** 2026-10-30 · **Статус:** черновик по вебу; варианты по умолчанию — рекомендованные (автор: «дальше 2b-3b»), ждёт ревью файла · **Фаза:** `docs/native-ios-plan.md`, фаза 2, часть b, срез 3б · **Предыдущий срез:** `2026-10-30-ios-2b3a-map-design.md` (карта, уровни слотов)

## Цель

Солнце и подпись `concordia` на карте оживают: тап открывает concordia — общие настройки (общий темп, общий лад, stable audio, restart audio, mixer). Из неё — микшер: громкость и mute каждого мира с уровнем на дорожке, мастер (low-pass, компрессор, ratio, потолок). В мире тап по кнопке громкости открывает панель audio (tempo, stop, restart audio, stable audio). Настройки переживают перезапуск.

Готово, когда: на iPhone автора солнце и `concordia` открывают concordia, строки переключаются, микшер слышно меняет громкость миров и мастер, уровни светятся на дорожках, mute глушит; панель audio открывается тапом по громкости, а потянуть громкость по-прежнему можно; stable / restart audio перезапускают звук без падения; после перезапуска приложения микшер, link и stable — прежние; пары снимков симулятор ↔ веб сходятся; проверки ниже зелёные.

## Решения

1. **Всё как в вебе** (`host/concordia.js`, `host/mixer.js`, `host/audio-panel.js`, `host/audio.js:134-170`): геометрия, подписи, числа, жесты. Новых решений в картинке нет; шрифт — как в вебе (`mapText` — IM Fell курсив, `text` — EB Garamond, панели в `reading`).
2. **Браузерные строки — с нативным смыслом** (вариант 1, рекомендованный):
   - `stable audio` — больший буфер: `setPreferredIOBufferDuration` 1024/48000 вместо 256/48000, затем перезапуск звука; подпись та же (`larger buffer — for USB interfaces`).
   - `restart audio` — пересборка аудиодвижка (новый повод `AudioTrigger.user` в AudioPlan: rebuild — да, reinit ядра — нет), ядро переинициализируется только при смене частоты дискретизации; сцена и микшер остаются живыми; вспышка `audio restarted` 900 мс, как в вебе (`restartAt`).
   - `midi clock` — не показывается (Web MIDI на iPhone нет и в вебе; CoreMIDI — фаза 5). В concordia подпись `shared tempo` всегда `one bpm in every sequencer`.
3. **Солнце и `concordia` на карте — без приглушения** (снимается ×0.3 решения 11 спеки 2b-3а). Попадание — как сейчас (`< 34` от солнца, `concordia` — `dx 26…120, |dy| < 20`), тап открывает concordia. Пока открыта concordia или микшер, подпись `concordia` не рисуется (`!nav.settings`, `map.js:346`).
4. **Состояние настроек — в `Host`**, как `nav.settings` веба: `settings: off / concordia / mixer`. Открываются только на карте без перехода; карта под ними тап не получает (съедается). Вход в мир (`goWorld`) сбрасывает `settings`. Порядок роутера на карте: настройки → карта.
5. **concordia** — коробка `settingsBox` (`concordia.js:17-21`): ширина `min(260, W − 40)`, высота 252, `y = min(H − safeBot − h − 10, sunY + 30)`, 5 строк через 44 начиная с `y + 46`. Тап по строке (`|y − row.y| < 20` внутри коробки): `shared tempo` / `shared scale` / `stable audio` — переключить; `restart audio` — перезапуск; `mixer` — открыть микшер. Мимо коробки — закрыть.
6. **Микшер** — `mixGeo` / `drawMixer` / `mixDown` / `mixMove` (`mixer.js`), один в один:
   - строки — 12 миров колоды `main` по возрастанию номера (реестр `Worlds.swift`), затем `master` и 4 фейдера (`lpf`, `thr`, `ratio`, `ceil`); высота строки `clamp(avail / (миры + 4), 24, 36)`; `top = scopeY + 40`, где `scopeY` — тот же аналог, что у поля карты в 2b-3а (`top` из `Host.layout`, верх строки кнопок по safe inset; `MapGeo.field(top:)`);
   - фейдер мира −36…+6 дБ, `FADER_DEF = 36/42` (0 дБ), `< 0.01` — `off`; тянуть — относительно (`v0 + dx / (tx1 − tx0)`); двойной тап (`DTAP_MS`) — по умолчанию; тап правее `tx1 + 28` — mute; левее `tx0 − 70` — ничего;
   - мастер: `lpf` 200·100^t Гц (> 0.99 — `open`, > 19 кГц → 22 кГц в ядро), `thr` −40…0 дБ, `ratio` 1…12, `ceil` −12…0 дБ; по умолчанию `MIX_DEF = {lpf 1, thr 0.75, ratio 0.136, ceil 1}`;
   - уровень мира — светлая полоса на дорожке `(20·log10(lvl) + 48) / 54`, кружок mute с точкой `2 + 2.5·clamp(lvl·6)` при `lvl > 0.003`; уровни — те же `Levels` 2b-3а (опрос на карте уже идёт); заглушённый мир — без полосы и точки;
   - назад — тап мимо коробки или по `‹ concordia` (`y < top + 34 && x < x + 110`) → concordia.
7. **Звук микшера — через кольцо хоста**, как громкость. Ядро: новые действия хоста `T2D_H_FADER` (`i` = слот, `a = [g]`) → `t2d_fader(slot, g)`; `T2D_H_MASTER` (`a = [lpfHz, thrDb, ratio, ceilDb]`) → `t2d_master_lpf`, `t2d_master_comp`, `t2d_master_ceil`. Код — только `core/app/` (в wasm не входит): коммит с `[no-wasm]`. **Сглаживание.** `Host::fader` и `masterLpf / Comp / Ceil` ставят значение сразу (ступенька — щелчки при перетаскивании), а веб сглаживает всё `setTargetAtTime(…, 0.03)`. Сглаживаем в движке приложения, не в `core/host` (тот в wasm, веб не трогаем): движок держит цель и текущее для 16 фейдеров и 4 величин мастера и раз в блок сдвигает текущее к цели однополюсным шагом `1 − exp(−n / (0.03·sr))`, передавая его в `t2d_fader` / `t2d_master_*` (фейдер — в линейном усилении, `lpf` — в логарифме частоты, `thr`, `ratio` и `ceil` — как есть, `ceil` в дБ: `t2d_master_ceil` принимает дБ); пока цель достигнута (разница < 1e-5) — не зовёт. Блок ≤ 128 сэмплов (≈ 2.7 мс) — ступеньки неслышны. Swift шлёт `chanGain(n)` = mute или `< 0.01` → 0, иначе `10^(faderDb/20)`.
8. **Когда шлём:** на каждое изменение (тап, двойной тап, движение фейдера) — `applyMix` целиком (12 фейдеров + мастер), как веб. При старте после `reapply` — тоже `applyMix`, чтобы ядро получило сохранённый микшер. Отброшенное действие (кольцо полно) не теряется навсегда: следующий `applyMix` пошлёт всё заново; на отпускании пальца — `applyMix` ещё раз.
9. **Общий лад (`perScl`)** — как веб (`map.js:43-50`): при `link.scale == false` вход в мир сохраняет текущий лад в `perScl[прошлый мир]` и ставит `perScl[новый]`, если есть. В памяти, не в файле (как веб). При одном нативном мире разница не видна; проверяется тестом с двумя мирами-фейками.
10. **Общий темп** — переключатель хранится и рисуется; `tempoFrom` ничего не делает, пока нет нативного мира с часами (у Firmamentum часов нет). Придёт с первым миром с часами (фаза 3).
11. **Панель audio** — `panelGeo` / `drawAudioPanel` / `panelDown` / `panelMove` (`audio-panel.js`):
    - тап по кнопке громкости в мире (`< TAP_MS`, сдвиг `< TAP_MOVE`, на отпускании) — открыть / закрыть; потянул — это громкость, как сейчас;
    - строки `tempo`, `stop`, `restart audio`, `stable audio` (без `midi clock`), шаг 44, ширина 230, под кнопкой громкости;
    - у Firmamentum часов нет: `tempo` приглушён с `—`; `stop` — «silence this world» = то же, что корзина (`clear` мира, undo вернёт); строка живая, пока мир звучит (`levels[слот] > 0.0025`, порог лучей);
    - мимо панели — закрыть; кнопка громкости при открытой панели — как всегда;
    - уход на карту закрывает панель (`closeOverlays()` из 2b-3а).
12. **Сохранение** — `prefs.json` (`Store`): к `PrefsFile` добавляются необязательные поля `mix` (`g: [слот: 0…1]`, `mute: [слот: Bool]`, `lpf`, `thr`, `ratio`, `ceil`), `link` (`clock`, `scale`), `audio` (`stable`). Версия остаётся 1: поля добавочные, старый файл читается (нет поля — по умолчанию). Пишем через существующее автосохранение (3 с и уход в фон); во время перетаскивания — после отпускания.
13. **Undo не трогают** ни микшер, ни concordia, ни панель audio (как в вебе); `stop` без часов — через корзину, она уже пишет undo.

## Ограничения

- Ветка `native`; в `main` не идёт. Миры заморожены: в вебе ничего не меняется.
- Ядро: C++17, `-ffp-contract=off`; в `render` / `block` — без блокировок и аллокаций; правка только `core/app/` — `[no-wasm]`.
- Картинка: без теней и градиентов, без аллокаций на кадр в путях рисования (геометрия — структуры, подписи — кеш ширин, где строка постоянна).
- Время в `Host` — секунды; константы веба в мс переводить на месте.

## Часть 1. Ядро

`core/app/t2d_app.h`: `T2D_H_FADER = 8`, `T2D_H_MASTER = 9`, комментарий к `t2d_app_action`. `core/app/engine.cpp`: два `case` рядом с `T2D_H_VOL`. Сглаживание (решение 7) — там же, в `Engine`: цели пишет разбор действия, шаг — в начале блока `render`. Тест (`core/tests/sdk_test.cpp`): фейдер 0 глушит слот на выходе, а уровень до фейдера остаётся; мастер `ceil` −12 дБ снижает пик выхода; фейдер 1 → 0 гаснет плавно (выход через 1 блок ещё > 0, через 0.3 с — ≈ 0), без скачка между соседними сэмплами больше, чем у исходного сигнала.

## Часть 2. Swift

- `Host/Mix.swift` — модель без UI: `Mix` (Codable), `Link`, `AudioPref`, `faderDb`, `chanGain`, `MIXM` (значение → величина и подпись), `MIX_DEF`, `FADER_DEF`.
- `Host/Concordia.swift` — геометрия, попадания, рисование concordia.
- `Host/Mixer.swift` — геометрия, попадания, перетаскивание, рисование микшера.
- `Host/AudioPanel.swift` — геометрия, попадания, рисование панели audio.
- `HostCore` — `fader(slot:g:)`, `master(lpf:thr:ratio:ceil:)`; `AppHostCore` — через `t2d_app_action(T2D_HOST, …)`.
- `Host` — `settings`, `audioPanel`, роутинг (на карте: настройки → карта; в мире: панель audio → плашка → легенда → лады → верхняя строка → мир), `applyMix`, `perScl`, сохранение.
- `Audio` — `stable` (буфер) и `restart()`; `Host` зовёт их через замыкание / протокол (тестируемо без звука).
- `MapDraw` — снять ×0.3 у солнца и `concordia`, не рисовать `concordia` при открытых настройках.
- `Store` — новые поля `PrefsFile`.

## Тесты

- Ядро: фейдер и мастер (часть 1).
- `Mix`: числа против веба — `faderDb(FADER_DEF) = 0`, `chanGain` при mute / `< 0.01`, подписи `MIXM` (`open`, `200 Hz`, `-30 dB`, `2.5 : 1`, `-12.0 dB`).
- `Store`: старый `prefs.json` без новых полей читается, новые поля — туда и обратно.
- `Host` (фейковое ядро): тап по солнцу и по `concordia` открывает; мимо — закрывает; `mixer` → микшер, `‹ concordia` и мимо → назад; фейдер тянется относительно и шлёт `fader` с `chanGain`; двойной тап — по умолчанию; mute; мастер шлёт `master`; вход в мир сбрасывает `settings`; `perScl` с двумя мирами; тап по громкости открывает панель, протяжка — нет; `stop` зовёт `clear`; `restart` и `stable` зовут `Audio`; настройки сохраняются и после перезапуска `Host` применяются в ядро.
- Снимки (агент `shots`): новые сцены `ios/app/shot.sh concordia`, `mixer`, `audio` против веба (`tools/shot.py` — сцены настроек и панели audio: найти или добавить в плане).

## Review Focus (крайние случаи)

1. Тянешь фейдер микшера, палец уходит за коробку — фейдер ведётся до отпускания, коробка не закрывается (закрытие — только на касании мимо).
2. Второй палец во время перетаскивания фейдера — своё касание по своим правилам, первый фейдер не прыгает.
3. Открыт микшер, приложение уходит в фон и возвращается (прерывание звука) — микшер заново отправлен в ядро (`applyMix` после `reset`).
4. `stable audio` переключают, пока звучит мир — звук перезапускается, сцена и микшер сохраняются.
5. Панель audio открыта, свайп от края / стрелка — уход на карту закрывает панель.
