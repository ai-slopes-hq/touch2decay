## Цель

Модель мира I становится чистым модулем `worlds/tenebrae/model.js` в форме будущего фасада ядра: методы модели = будущие действия ядра (шаг Б), пикселей модель не видит. **Веб ведёт себя так же**: тот же звук, те же жесты, та же картинка. Ядро (`core/`), клей `worlds/tenebrae/engine.js` и `t2d.wasm` не меняются.

Не входит: перенос view и жестов в `worlds/tenebrae/` (остаток шага 8 `docs/refactor-plan.md`), эталон `tools/ref/tenebrae-model.js` (делается в начале шага Б копией `model.js`), любые изменения поведения.

## Модель: состояние

`createModel({ rng, engine })` — `rng` — генератор с зерном, как у других миров; `engine()` — текущий клей (`null` до первого `build`).

- `state.voices[6]` — только модельные поля: `i, x (p), y (c), beat, wave, fm, cut, res, shift, amp, holeT, mods [{src, type, depth, auto, k, until}], lfo {key: {morph, rate, depth}}, pinned, active, live, env, envT, envTau, held, snap, dirty`, удары `strikeNext`, `sunT`.
- `state.fx = {rev, decay, dly, chaos, dirt}`; `state.kept` — голоса, которые держит открытая плашка.
- Константы модели (`VOICES 6`, `PIN_MAX 3`, `TEMP_MAX 3`, `TAIL`, `UNPIN_TAIL`, `LINK_NEW`, умолчания полей, `LINK_TYPES`, пределы `BEAT_*`, `LFO_RATE_*`) переезжают в `model.js` и экспортируются; `app.js` берёт их оттуда.
- Поля картинки — во view (`app.js`), отдельным массивом по номеру голоса: `dx, wob, wv, ox, oy, hole (сглаженная), strike, emit, t`, id пальцев, фазы LFO для рисования (`ph, vph`).

## Модель: методы (будущие действия ядра)

| Метод | Что делает (как сейчас в `app.js`) |
|---|---|
| `spawn(p, c, holeT)` → `i` или `−1` | выбор голоса: свободный при `temps < TEMP_MAX`, иначе самый тихий затухающий временный (не закреплён, не держат, не в плашке); сброс полей к умолчаниям, `unlink` всех связей и LFO, `attack`; `−1` — мест нет |
| `grab(i)` / `letGo(i)` | счётчик пальцев `held`. `grab` незакреплённого — `attack` (мост, :396). `letGo` последнего пальца: не закреплён и не в плашке — `release(TAIL)` |
| `keep(group)` / `unkeep()` | голоса открытой плашки; `unkeep` гасит (`TAIL`) активные незакреплённые, которых никто не держит (`closeEditor`) |
| `move(i, p, c, holeT, sunT)` | место, глубина дыры, глубина солнца (0 — не на солнце; view шлёт 0, пока палец не сдвинут, на мосту, в меню или «запаркован», как условия :1728); `dirty` |
| `pin(i)` → `'pinned' / 'unpinned' / 'full'` | двойной тап: открепить (`UNPIN_TAIL`, если не в плашке), закрепить или отказ при `PIN_MAX` (гаснет `TAIL`, если не держат и не в плашке) |
| `remove(i)` | `deleteVoice`: открепить, снять связи, `release(0.25)`, событие `burst` |
| `set(i, key, v)` | поле голоса (`wave, cut, res, beat, fm, shift, amp`) |
| `link(dst, src, depth, type)` / `linkDepth(dst, src, d)` / `unlink(dst, src)` | связи; мост на каждое движение пальца шлёт только `linkDepth`; на конце моста глубина < 0.06 — `unlink` (решает view) |
| `lfo(i, key, spec | null)` | поставить / снять LFO |
| `fx(key, v)` | общие FX; в клей уходят `rev, dly, dirt` (`applyFx`) |
| `dice()` → `bool` | случайный тембр живым голосам (`active && envT > 0`), связям (кроме авто) и LFO — формулы `rollDice`; `false` — живых нет. Пустое поле решает view: ставит планету в случайном месте видимой части (`place(zoom·…)`, `outOfHole`, `holeDepth`), `pin`, затем `dice()` |
| `clear()` | все голоса гаснут (`remove`), `engine.clear()` |
| `snapshot()` / `restore(js)` | тот же JSON, что сейчас (:742): закреплённые, поля `r4`, связи только между закреплёнными и без авто, LFO, все пять `fx`. `restore` — тот же порядок: лишние закреплённые `remove`, поля, `attack` погасшим, события `burst`, потом связи и LFO, `applyFx` |
| `load()` | нагрузка графа для индикатора (формула :739) |
| `build()` | первый `build` / `bind` клея — порядок `solBuild`: FX → LIVE → связи и LFO → VOICE → ON |

Сброс жестов при `remove` / `restore` / `clear` (пальцы, кольца, `lastTap`, `ghost`, `editor`) делает view после вызова.

## Тик

`tick(dt)` — время модели в секундах (накапливается из `dt`); тикает каждый кадр и тогда, когда на экране карта или другой мир.

- хаос — раз в 0.4 с (`chaosTick`, `until` в секундах: 3…10 с);
- удары солнца — у голосов с `held > 0` и `sunT > 0`: удар, когда время ≥ `strikeNext`; следующий — через `(0.44 − 0.32·t)·(0.6 + 0.8·rng())` с; `engine.strike(t)` и событие `strike`;
- `dirty` → `sync(v)` (связи и LFO до полей, как :1114-1123);
- `env` к `envT` с τ `envTau`;
- смерть в дыре: `holeT > 0.9`, никто не держит, `envT ≠ 0` → открепить, `release(0.4)`;
- затухание: активный, не закреплён, не держат, `envT = 0`, `env < 0.004` → не активен, связи и LFO сняты, `live 0`.

В тике `app.js` остаются картинные вещи: удержание → плашка, зум, съезд к ноте лада (`dx`), фазы LFO для качания (`wob`, `wv`), сглаженная `hole`, закрытие плашки умершего голоса или связи, рисование.

## События

Очередь `model.events()` → `[{t: 'strike', i, p}, {t: 'burst', i}]` и очистка. `burst` — при `remove`, `restore`, `dice`, `pin`; `strike` — удар солнца. View забирает очередь раз в кадр: кольца `rings`, молнии (`strike = {t0, p, a}`, угол — от солнца к планете). На шаге Б очередь ляжет на `heard` ядра.

## Случайность и время

- `Math.random` модели → `rng` (хаос, кубик, интервал ударов). Числа другие, распределения те же; кубик воспроизводим по зерну. `Math.random` картинки (фон, молнии) остаётся во view.
- Время модели — секунды тика (`chaos until`, `strikeNext`). Пороги жестов (`TAP_MS`, `DTAP_MS`, `HOLD_MS`, `GHOST_MS`, `lastTap`) — во view, на `performance.now`.
- Огибающая `env` остаётся у модели, как сейчас. Чья она каноническая на шаге Б (модели или ядра), решает спека Б.

## Тесты

`tools/models/tenebrae.test.mjs` (`node --test`), модель с зерном и поддельный клей, который записывает вызовы:

- `spawn`: свободный голос, предел временных 3, вытеснение самого тихого затухающего, никогда — закреплённого, удерживаемого, в плашке; `−1`, когда все заняты;
- `pin`: закрепление, открепление (`UNPIN_TAIL`), отказ при трёх закреплённых (`'full'`, `TAIL`);
- `grab / letGo / keep / unkeep`: затухание `TAIL` только у незакреплённых без пальцев и плашки;
- связи: `remove` снимает связи голоса у всех приёмников; `linkDepth`; `unlink`;
- хаос: по зерну — авто-связи только между активными при `chaos ≥ 0.02` и двух голосах, глубина `chaos·k`, истечение `until`, снятие при `chaos = 0`;
- `dice`: диапазоны полей, авто-связи не трогает, `false` на пустом поле, одно зерно → одинаковый результат;
- `snapshot / restore`: туда и обратно равны; незакреплённые и авто-связи не попадают; `restore` удаляет лишние закреплённые; порядок вызовов клея (`links / lfo` до `voice`);
- тик: смерть в дыре, затухание голоса (`live false`, связи и LFO сняты), удары солнца (интервалы в пределах формулы, `engine.strike`, событие);
- `clear`, `load`, `build` (порядок FX → LIVE → связи и LFO → VOICE → ON).
