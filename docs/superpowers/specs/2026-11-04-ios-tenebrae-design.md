# iOS-приложение — фаза 4, шаг В: Tenebrae на Swift

**Дата:** 2026-11-04 · **Статус:** черновик; развилки решены «как в вебе», умолчания объявлены автору 04.11 (возражений нет) · **Фаза:** `docs/native-ios-plan.md`, фаза 4, этап 3 · **Образец:** Cymatica — `ios/app/T2D/Cymatica/`, спека `2026-11-03-ios-cymatica-design.md`; модель в ядре — спека `2026-11-03-tenebrae-model-core-design.md`; разведка — `~/.claude/handoff/tenebrae-map.md`, `tenebrae-native-map.md` (не в git)

## Цель

Последний нативный мир — I · Tenebrae: поле планет в полярных координатах от солнца (радиус — высота, угол на дуге — характер: чисто справа внизу, шум слева вверху), касание звучит, пока держишь; двойной тап — закрепить; удержание — плашка планеты (волна, фильтр, beat, fm, shift, amp, LFO модели); второй палец на другой планете — мост-связь; ромб на нити — кольцо связи (тип, глубина, разрез); щипок по пустому — зум по октавам; солнце (тянуть в него — молнии, тап — карта), чёрная дыра (тянуть в неё — съедает шумом), волны, спутники-LFO, нити с частицами, веер FX `aether`, легенда — на Swift + CoreGraphics. Модель и звук уже в ядре (`core/worlds/tenebrae/`, слот 1, действия 16–36): Swift разбирает зеркало и «услышанное» и шлёт действия.

Готово, когда: Tenebrae открывается с карты (`view: true`); касание по пустому рождает планету, тяга ведёт её по дуге и меняет звук, отпустил — гаснет хвостом кометы; двойной тап закрепляет / открепляет (четвёртая — отказ «full»); удержание открывает плашку (строки, полоса 9 волн, «~» LFO с панелью форм и падом rate×depth, двойной тап строки — умолчание); мост вторым пальцем; кольцо связи на весу и закреплённое, разрез; щипок зумит; солнце дышит выходом и бьёт молниями; дыра тянет и съедает; кубик, корзина, отмена, лад, веер FX работают как в вебе; пары снимков симулятор ↔ веб сходятся глазами; проверки ниже зелёные.

## Решения

1. **Всё как в вебе** (`app.js`, Tenebrae-часть ≈1700 строк; номера строк — в карте `tenebrae-map.md` §1): константы `:31-93`, поле `:111-187`, нормы строк `:189-228`, пальцы `:230-299`, LFO `:301-323`, мост `:325-349`, плашка `:351-371, :542-581`, касания `solDown / solMove / solUp :393-502`, кубик `:513`, нити `:525-540`, FX `:830-840`, кольцо связи `:854-982`, кадр `solTick :1857`, `solDraw :1906`. Новых решений в картинке нет. Тема — `.base`, мир строго ч/б (`INK 237`). Заголовок `Tenebrae`, подзаголовок `orbes · strepitus`. Время картинки — секунды Swift, формулы веба в мс — `now·1000`. Мёртвый код веба не переносим (`openMenu`, `openFx`, `drawFx`, кольцо голоса в `drawEditor / drawHeld`, полоса amp, LFO-панель вне плашки), как и десктоп (Shift-нить, колесо, `gesturechange`).
2. **Где код:** `ios/app/T2D/Tenebrae/` — `TenMath.swift` (константы, поле `geo / arcSpan / rOfP / pOfR / place / unplace / holeDepth / outOfHole`, зум, `freq / cutoff / shiftHz / quantX`, нормы строк, `valueText`, полосы и имена нот), `Waves.swift` (9 таблиц и `morphFn / morphName` из `host/waves.js`; общий файл в `T2D/`, не в мире), `TenMirror.swift` (разбор 387 / 1161 и `heard`), `TenState.swift` (чистый, без `Core`: голоса, `pick()`, `pin` → pinned / unpinned / full, `dice` → есть ли живые, свои значения ttl 0.25 с, вид голоса `dx / wob / wv / hole / ph / vph`), `TenTouch.swift` (`extension TenebraeView`: палец, тяга, двойной тап, удержание, солнце), `TenLink.swift` (мост, ручка, кольцо связи), `TenSheet.swift` (плашка планеты: геометрия, попадания, правки; веер FX `SheetSpec`), `TenebraeView.swift` (класс `World`: связка, тик, кубик, корзина, отмена, лад, легенда), `TenScene.swift` (кеш фона и орбит), `TenDraw.swift` (солнце, дыра, планеты), `TenFrame.swift` (кадр, нити, мост, кольцо, волны, плашка) — файл больше ~350 строк делим дальше. Регистрация: `Worlds.swift` — `view: false → true`; `App.makeView` — ветка `TenebraeView.slotN` (1); сцены `-shot ten*` в `App.swift`, `shot.sh`; `project.yml` — источники теста `T2D/Tenebrae`.
3. **Ядро — задача 0** (открыто от шага Б): в `World::action` (`core/worlds/tenebrae/world.cpp:124`) для `kind ≥ 16` — все `a[0..n)` конечны, иначе действие отброшено (Swift зовёт действия без фасада-охранника); тест `Model::pick()` в `core/tests/sdk_test.cpp` (пусто → 0; 3 временных → самый тихий затухающий; held / kept / pinned не вытесняются; −1) и тест NaN-охраны; `core/build.sh`, `t2d.wasm` пересобран, `CACHE` = `?v=` новая версия (веб тот же). Больше ядро не меняется.
4. **Зеркало** (`world.cpp:307-347`): заголовок 15 (`[0]` 6, time, strikes, fx×5, nkept, kept×6), голос `15 + 62·i` (17 полей, число связей, 5×(src, type, depth, auto), 8×(morph, rate, depth; depth −1 — нет)); контуры с 387 по 129 (live + 128 точек) — только когда хоть один голос живой, иначе длина 387. Буфер 2048, `heard` — 256. Короче 387, `[0] ≠ 6` или не конечное — отказ, прежнее зеркало остаётся. Читатели внедряются (тесты — на фейке), буферы предвыделены.
5. **Услышанное:** `[1, i]` — вспышка-волна у планеты (две подряд у одного `i` за тик — одна), `[2, i, p]` — удар солнца (молния 110 мс, отдача 700 мс). Читать до 4 раз за тик, пока полно; `idle()` сливает кольцо без событий. Тик модели и удары солнца идут в ядре и при открытой карте (как в вебе).
6. **Действия** — `Core.action(slot 1, …)` кодами 16–36 (`world.hpp:15-26`), одна обёртка `send` → `core.action` + `state.own`. `SPAWN i` — голос выбирает Swift: `TenState.pick()` повторяет `model.cpp:86-99` по своему состоянию и `env` зеркала; `−1` → отказ на поле. Пальцевые действия (`SPAWN, MOVE, SUN, ATTACK`) — с `touchTime`, прочие — `0`. `REMOVE`, `RETUNE`, низкий уровень 0–8 натив не шлёт. `SUN i [t]` — только при изменении `t`; кеш последнего посланного `t` сбрасывается в `restored()` и `enter()` (ядро обнуляет `sunT` при `reset`, как `bind` веба `model.js:327-330`).
7. **Собственные значения до зеркала** (правило Natura / Portus / Cymatica): после своего действия — своё значение, пока не сошлось с зеркалом или 0.25 с после последнего своего действия по полю. Свои: `x, y, holeT` (тяга), строки `SET` 0–6, `pinned`, `held`, `kept`, LFO (morph, rate, depth), связи (depth, type), fx×5. `env / envT / live / active` — всегда из зеркала. Связи, рождённые ядром (`LINK`, авто-связи хаоса, `DICE`, `CLEAR`), — ждут зеркала.
8. **Поле и зум** (`app.js:111-187`, `:447-470`): начало (0, `bot = H − safeBot − 4`), `top = topY − 56` (хост даёт `topY = top + 44`, веб — `scopeY − 12`); `arcSpan`, площадь дуг `geo.a` шагом 2 px, `place / unplace`, `rAt` — ∞ за горизонтом. Зум `zoomT ∈ [0.35, 1]`, умолчание `zoomDef` по площади поля (`:175`), сглаживание τ 0.06 с, подпись `55 – N Hz` 1.2 с; ручной зум живёт до `layout` с другим размером. Пана нет.
9. **Касания** (пороги веба `TAP_MS 220, TAP_MOVE 14, DTAP_MS 320, HOLD_MS 420, HOLD_MOVE 10`; «сдвинут» — свой порог 10 px от `x0 / y0`, не `Finger.moved`; пальцы независимы по `Finger.id`). Порядок попаданий в мире (`uiHit :588-638`): призрак кольца (булавка в 31 px до `until` → закрепить) → булавка кольца на весу другого пальца → плашка планеты → закреплённое кольцо → ручка нити (24 px, не auto, источник активен) → поле (`solDown`): второй палец на другой планете при одном удерживаемом → мост; второй по пустому в 250 мс от несдвинутого первого → пара щипка; планета в 52 px → взять (не закреплена — `ATTACK`); пустое → `SPAWN`. Тяга → `MOVE` с `holeDepth`; солнце → `SUN` (t = clamp((124 − d)/70)). Отпустил: тап < 220 мс и < 14 px; двойной тап по той же планете в 320 мс → `LETGO` + `PIN` (`full` — отказ 600 мс); двойной по пустому — новая закреплённая; иначе `LETGO`. Удержание 420 мс без сдвига 10 px, один палец → плашка (`KEEP [i]`). Щипок: за 700 мс |Δd| > 26 → зум, оба пальца бросают планеты (`RELEASE i 0.03` временным), `zoomT = z1·d1 / max(20, d)`.
10. **Мост и кольцо связи** (`:325-349, :885-982`): мост — `LINK(A, B)` новой `tzfm 0.5`, глубина `clamp(depth0 + d/d0 − 1)`, `d0 = max(30, d)`; на отпускании глубина < 0.06 → `UNLINK`. Кольцо на весу от ромба: центр — целиком на экране, низ `H − safeBot − 24`; < 40 px — булавка, > 56 px — луч (fm −90°, tzfm −18°, am 54°, rm 126°, cut 198°), держится до возврата в центр; `t = clamp((d − 40)/MENU_SPAN)`, `MENU_SPAN = max(90, min(150, min(W, H)/2 − 74))`; тип → `LINKTYPE` + `LINKDEPTH`, cut > 0.35 — разрез; отпустил на булавке → закреплённое, иначе — применить и призрак 1.6 с. Тап по ромбу — сразу закреплённое. Закреплённое: луч по углу, на отпускании с разрезом → `UNLINK` и закрыть; чип close (`W − 80, H − safeBot − 320`, 64×26); закрывается, когда голос неактивен или связи нет.
11. **Плашка планеты — мир рисует и ведёт сам** (у хоста нет полосы волн, чипов, колбэка «закрыли» для `UNKEEP`, а классическая панель LFO — только random-формы): геометрия `sheetGeo :545` (строки 40, полоса волн 40, панель LFO 196, чипы `pitch` и `close`), касания `:600-613, :681-772, :797-819` — строка (`setNorm`: shift защёлка 0.5 ± 0.02, beat лог 0.05…24; amp лог 0.05…1.8, ≤ 0.005 → off, |дБ| < 0.6 → 1), двойной тап строки → умолчание, полоса волн, «~» → `SETLFO` с `LFO_DEF {0, 1.2, 0.35}`, повторный тап по той же «~» сворачивает панель, панель — формы `morph` и пад rate × depth по `host/sheet.js:10-15` (= `Sheet.swift:82-90`, функции пада берём оттуда), на отпускании depth < 0.03 → снять; мимо плашки → закрыть + `UNKEEP`. Пока плашка открыта, касание мимо неё (выше `top` или по полю) только закрывает её — планеты не рождаются (`void`, как в вебе), солнце — не карта. Панель LFO рисует формы `morphFn` (`Waves.swift`); раскладку панели берём из `SheetGeo.Panel`, если совпадает с вебом, иначе — своя.
12. **Веер FX** — `SheetSpec` хоста `aether` без LFO и reset: `hall` (rev), `decay` (`invLog 0.6…14`), `delay`, `chaos`, `drive`; `arc: fx.rev`; правка → `SETFX` пятью числами; hint `FX — tap outside to close`.
13. **Солнце — предмет-угол:** `cornerHit` — `d < 46` от (0, bot) при закрытой плашке → карта маршрутом хоста `.corner`. **Правка хоста:** в `Host.route` проверять `cornerHit` раньше левой полосы `x < 14` — порядок `headHit` веба (`host/ui-top.js:41-46`); иначе полоса съедает тап у края солнца. Прочим мирам это не меняет ничего, кроме того же порядка, что и в вебе. `drawShot` = `draw` (у веба `corner.draw` пуст, солнце — часть поля).
14. **Кубик, корзина, отмена, лад.** `dice()` — `DICE`; ядро ответило «живых нет» нельзя узнать синхронно, поэтому Swift решает по своему состоянию (`TenState.dice()` = есть голос `active && envT > 0`, как `model.js:221`): нет — `SPAWN` в `place(zoom·(0.08 + 0.75R), 0.1 + 0.6R)` + `PIN` + `DICE`; случайность места — свой генератор вида с зерном (тесты и сцены — фиксированное). Снимок отмены идёт по тому же кольцу после действий — `UndoCommitting` не нужен. `clear()` — `CLEAR`. `restored()`: пальцы, пара, плашка, кольца, призрак, свои значения, кеш `sunT` сброшены; `dx / hole` — из зеркала, фазы LFO заново. `scale()` — орбиты нот лада, `slideUntil = now + 0.5` (`dx → soundX` τ 0.07 с), `RETUNE` не шлём.
15. **Солнце дышит выходом:** `sunLevel` = √Σ `lv²` уровней слотов (`t2d_app_levels`, сухие до фейдера) ×2.2, сглаживание 0.08 / кадр — ближе всего к мастеру веба; читатель внедряется.
16. **Рисование** (`:1003-2024`, детали — карта §2):
    - **кеш** — фон (`BG`, звёзды `scan` LCG зерно 7, созвездия, меридианы, двойная рамка, засечки, край дыры) и орбиты полос / лада (`engraved`) — `CGImage` `W × H × DPR` (≤ 2), ключ `zoom.toFixed(4)|лад|W×H|DPR`; во время щипка пересборка не чаще 15 раз в секунду (риск веба: каждый кадр);
    - **в кадре** — порядок веба: фон → солнце (свечение `glowAt`, 28 лучей, молнии, диск, отдача) → дыра (диск 4 эллипса, тень, фотонные кольца, горизонт) → мерцание chaos → подсветка полосы → орбиты ярче → подписи (только при тяге / зуме) → волны (≤ 60, эхо delay) → призрак до первого касания → нити (пунктир по типу, частицы, ромб) → планеты (контур 128 точек scope, двойная звезда beat, Сатурн у закреплённой, хвост кометы у временной, туманность hall, спутники-LFO с орбитой и следом, деформация над дырой) → дуга удержания → отказ → мост → кольцо связи → плашка с панелью LFO;
    - производительность: без `shadowBlur` (свечение — широкие штрихи), градиенты — `glowAt`, полноэкранный проход — только блит кеша; случайность картинки — свой генератор вида; буферы контуров предвыделены; `dt ≤ 0.05 с`.
17. **Легенда** — 8 строк `host/legend.js:11-14` (tap / drag / double / hold / two / pinch / drag / tap).
18. **Не делаем:** десктоп (Shift, колесо), мёртвый код веба (решение 1), MIDI, общий темп, новые картинки или жесты.

## Риски

- **Объём** (≈2600 строк Swift и ≈600 тестов) — два плана: (а) задача 0 ядра, `TenMath`, `Waves`, `TenMirror`, `TenState`, `TenebraeView`, `TenTouch`, `TenLink`, `TenSheet` (логика), правка `Host.route` — без картинки, мир на карте не включён; (б) `TenScene`, `TenDraw`, `TenFrame`, рисование плашки и кольца, сцены, включение на карте, доки.
- **Производительность:** самый тяжёлый мир (6 контуров по 128 точек, нити с частицами, волны, лучи) — на iPhone проверяет автор; строка замеров Stage покажет нагрузку.
- **Щипок и мост на iPhone** — пороги веба как есть; удобство одной рукой решает автор.
- **Солнце у левого края** — после правки порядка хоста свайп от края в круге солнца ведёт на карту тапом, а не свайпом (как в вебе).
- Снимки — симулятор; звук, жесты на ощупь и производительность проверяет автор на iPhone.

## Решено без автора

1. Порт 1:1 с веба; мёртвый и десктопный код не переносим.
2. Плашку планеты мир рисует и ведёт сам; хост не расширяем (кроме порядка `cornerHit` / полосы).
3. Солнце дышит √Σ уровней слотов (≈ мастер веба).
4. Тик и удары солнца идут и при открытой карте (ядро).
5. Место кубика на пустом поле — свой генератор вида с зерном.
6. Щипок — внутри мира, протокол `World` не меняется.
