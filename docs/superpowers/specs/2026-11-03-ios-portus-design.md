# iOS-приложение — фаза 3: Portus на Swift

**Дата:** 2026-11-03 · **Статус:** черновик, решено без автора (как Natura, Inferno) · **Фаза:** `docs/native-ios-plan.md`, фаза 3 (миры по одному) · **Образец:** Natura — `ios/app/T2D/Natura/`, спека `2026-10-31-ios-natura-design.md`; LFO строк мира — Inferno (решение 6 спеки `2026-10-31-ios-inferno-design.md`); разведка — `~/.claude/handoff/portus-map.md` (не в git)

## Цель

Девятый нативный мир — XIII · Portus: ночная гавань-секвенсор — фарватер на 16 мест между двумя мысами, бумажные кораблики-стабы, вехи с фонарями (шаг), маяк (пуск, темп, аккорд), луна-угол (lowpass), буй (эхо: время и feedback), туман (ревербер), падающая звезда (KILL), плашки, веер FX с LFO и легенда на Swift + CoreGraphics. Модель и звук уже в ядре (`core/worlds/portus/`, слот 13) — Swift разбирает зеркало и «услышанное» и шлёт действия. Попутно — то, без чего натив не встанет: `ACT_LFO` и `DICE` в ядре Portus (в вебе LFO и кубик — в фасаде), вызовы хоста `goMap` и `lfoBase` для мира.

Готово, когда: Portus открывается с карты; поставить / утопить / перенести кораблик, нота поперёк, аудиция при стоящих часах, вехи (поставить / утопить), маяк (пуск тапом, темп вбок), луна (тап — карта, вверх — cutoff, вбок — res), буй, туман, звезда-KILL, удержание → плашки (luna, echo, nebula, pharos, navicula), веер FX, LFO строк, кровавая луна при LFO на cutoff, кубик, корзина, отмена работают как в вебе; пары снимков симулятор ↔ веб сходятся глазами; проверки ниже зелёные.

## Решения

1. **Всё как в вебе** (`worlds/portus/view.js`, из `model.js` — `CHORDS`, `DT / DT_NAME`, `NSTEP 16`, `PSPAN 12`, `edge`, ключи групп и значения по умолчанию, `hzOf / nameOf / fcOf / fbOf / buoyU`): геометрия `geo / P / unP / kOf / dOfF / fOf / laneC / laneHW / laneAt / slotPt / slotAt / markPt / cliffH` (`view.js:12-39`), порядок попаданий `down()` (`:59-106`), плашки (`:108-143`), кадр (`:338-360`), веер (`:364-369`), легенда (`:370-373`, 10 строк). Новых решений в картинке нет. Тема — `Worlds.info(13)`. Заголовок `Portus`, подзаголовок `pharos · echo · nebula`. Время картинки — секунды Swift, в формулах веба (`now` в мс) — `now·1000`.
2. **Где код:** `ios/app/T2D/Portus/` — `PorMath.swift` (константы, геометрия фарватера и предметов, `slotAt / slotPt / markPt / laneAt`, `hzOf / nameOf / fcOf / fbOf / buoyU` с ладом, тексты подписей, `get / set / text` плашек, тексты веера), `PorMirror.swift` (разбор зеркала и `heard`), `PorState.swift` (чистый помощник без `Core`: собственные значения, времена ударов, круги эха, звезда, порог аудиции), `PorTouch.swift` (`extension PortusView`: касания → действия), `PorScene.swift` (кеш стены), `PorDraw.swift` (предметы кадра: луна, вехи, кораблики, буй с кругами, туман, маяк, звезда, подписи), `PortusView.swift` (класс `World`: связка, плашки, веер, легенда, тик). Регистрация: `Worlds.swift:30` — `view: false → true`; `App.makeView` — ветка `PortusView.slotN` (13); сцены `-shot portus*` в `App.swift` (`shotPortus`), `shot.sh` — список сцен; `project.yml` — источники теста `T2D/Portus`. Если файл картинки вырастет больше ~300 строк — делить, как Natura (`Art / Frame`), решает план.
3. **Зеркало** (`core/worlds/portus/world.cpp:229-246`, `MIRROR_N 104`): `0` шаг (`−1` стоит), `1` играет, `2` голосов, `3` bpm, `4–6` luna `cut, res, env`, `7–9` echo `time, tone, mix`, `10–11` buoy `u, d`, `12–13` fog `amt, size`, `14–18` pharos `chord, oct, len, lvl, swing`, `19–23` fx `wow, mare, drive, spread, chance`, с `24 + 5j` — `on, p, oct, lvl, sd`. Короче 104 или не `isFinite` — отказ, прежнее зеркало остаётся. Читатель внедряется (тесты — на фейке), как у Natura. Шаг — целое, экстраполяции фазы нет (вехи и бегущий огонёк — от шага и времени удара, как в вебе).
4. **Услышанное** (`world.cpp:248-254`): пары `[1, шаг]` в момент звучания → `hitT[шаг] = now`, `lastHit = (шаг, now)` (луч маяка, вспышка), удар в кольцо кругов буя: `dt = DT[echo.time]·stepSec`, `fb = fbOf` на момент удара (до 6 кругов, k-й через `k·dt`, сила `fb^k`, живёт 1.4 с). Время приёма — время тика. До 32 записей за чтение; `idle()` сливает кольцо без событий.
5. **Действия** (`world.hpp:34`) — через `Core.action(slot 13, …)`, коды ядра `PLACE 0 … AUDITION 15` плюс новый `DICE 16`. Аудиция (`AUDITION i`) — как `engine.js:33-38`: только когда часы стоят, не чаще 140 мс (порог — в `PorState`).
6. **`ACT_LFO` в ядре Portus** (образцы `tria/world.cpp:149`, `inferno`): все LFO — строки мира, `obj −1`, `n ≥ 2`, ключ `a[0]` — код:
   - веер FX `0…4` (`wow, mare, drive, spread, chance`) → `model_.setFx(k, v)`;
   - луна `5…7` (`cut, res, env`) → `model_.setLuna(k − 5, v)`;
   - эхо `8…10` (`tone, mix, fb`) → `model_.setEcho(TONE / MIX / FB, v)` (тот же путь, что `ECHO`; `fb` — через `buoyD`, как в фасаде); строка `time` — код `−1` (как в вебе, LFO нет);
   - туман `11…12` (`amt, size`) → `model_.setFog(k − 11, v)`;
   - прочие коды, `obj ≥ 0`, `n < 2` — пропуск. Плашки `pharos` и `navicula` — без LFO (коды `−1`).
   Затем `pull(); applyState()`, как у прочих действий. Звук веба бит в бит прежний (веб `ACT_LFO` не шлёт; `node --test tools/models/portus.test.mjs tools/models/portus-engine.test.mjs` — зелёные до и после).
7. **`DICE` в ядре** (как Natura): `Model::dice(sdk::Rng&)` — алгоритм фасада (`model.js:107-121`: `roots = [0, pick(3,5,7,10), pick(0,5,7,12)]`, `chord = pick(2,2,3,3,1,4)`, порядок `[2,6,10,14,3,11,7,15,0,9,13,5]` с p 0.62, не больше 7, меньше 3 — добавить `2, 10`, без повторов; нота — `roots[0]` в первой половине, иначе `roots[1]` с p 0.7, иначе `roots[2]`; `oct 0, lvl 1, sd = R·1000`; `echo.time = ⌊R·5⌋`, `buoy.d = 0.25 + R·0.55`, `buoyFromEcho()`, `pharos.oct = R < 0.6 ? −1 : 0`, `luna.cut = 0.25 + R·0.45`, `luna.res = R·0.6`, `fog.amt = 0.25 + R·0.55`) на `rng_` мира, тот же порядок вызовов `R`; `World` по `DICE` — `model_.dice(rng_)`, `pull(); applyState()`. Веб не трогаем. Swift: `DICE`, затем `PLAY [1]`, если не играет (как веб). Снимок отмены — хоста, до кубика.
8. **Луна — угол, который отдаёт тап** (у хоста `cornerHit` забирает касание целиком на `down`, `Host.swift:254,289`; у луны — ещё тяга и удержание): Portus `cornerHit` → `false`, луну ведёт сам мир; в протокол `World` — `var goMap: (() -> Void)? { get set }` (ставит хост, как `openSheet`; в расширении — заглушка, прочие миры не меняются); тап по луне (< 300 мс без сдвига, как `view.js:104`) → `goMap()`. Левая полоса хоста (`edge`) и прочие миры — как есть. `drawShot` — кадр без луны (снимок для карты, как у прочих углов).
9. **Кровавая луна** (`view.js:17, :230`): при LFO на `cut` луна стоит на базе, качание — цвет (ниже базы — кровавая). Базу знает только хост: в протокол `World` — `var lfoBase: ((Int, Int) -> Double?)? { get set }` (`obj, code` → база LFO строки этого слота или `nil`; ставит хост, читает `core.lfoSnap()` — свежий, не снимок плашки; заглушка в расширении). Мир зовёт его раз за кадр для `(−1, 5)`.
10. **Собственные значения до зеркала** (правило Natura / Inferno — своё значение после своего действия, пока не сошлось с зеркалом или 0.25 с после последнего своего действия по полю; всё — в `PorState`, каждое действие идёт через одну обёртку `send`): кораблик целиком (`on, p, oct, lvl, sd`) — по месту (`PLACE / SINK / NOTE / ISLE`, `MOVE i→j` — пусто в `i`, копия в `j`, только если `j` свободно); `luna×3`, `echo×4` (`fb` — через `buoy.d`), `buoy u, d` (`u` — `buoyU` от своих `time, d`), `fog×2`, `pharos×5`, `fx×5`, `bpm`, `playing` — по полю; `CLEAR` — свои пустые 16 мест; после `DICE` и `restored()` — сразу зеркало.
11. **Касания** (`view.js:59-106`; `HOLD_MS 420`, тап < 300 мс, сдвиг 8 px, пальцы независимы по `Finger.id`, двойного тапа и щипка нет; удержание открывается в `tick`, как `view.js:144-146`): порядок попаданий — маяк (тап → `PLAY`, вбок `BPM = bpm0 + dx/2`, 60…180), луна (тап → карта, вверх `LUNA cut`, вбок `LUNA res` от `dx/(Ws·0.5)`), веха (`markAt`: есть кораблик — `SINK`, нет — `PLACE (i, lastP)` + аудиция), буй (`BUOY [u, d]` от `unP`), кораблик (вдоль — `MOVE` только на свободное, поперёк — `NOTE` + аудиция, тап — `SINK`), верх тумана ±16 (вверх `FOG amt`), небо над туманом (`KILL` + звезда 0.9 с), вода (`PLACE` + аудиция, новый кораблик сразу тянется — `fresh`, без тапа и плашки). Удержание без сдвига → плашка у луны, буя, тумана, маяка, кораблика. Общего темпа хоста в iOS нет — маяк шлёт только `BPM` (как Natura).
12. **Лад:** подписи считают `semi = p + root`, с ладом — `snap(a + 24) − 24`, плюс `12·(pharos.oct + oct)` (`model.js:49-54`). `snap` — общий: `infSnap` (`Inferno/InfMath.swift:71`) переезжает в общий файл как `scaleSnap`, Inferno и его тесты — на него. `pcs, root` — из `World.scale(pcs:root:)`.
13. **Плашки и веер** (как `view.js:108-143, 364-369`):
    - **luna** — `cutoff` (Hz), `resonance`, `envelope`; LFO на всех трёх (коды 5–7), `shape 0` (classic);
    - **echo** — `time` (`DT_NAME`, код −1), `feedback` (`> 0.95` — `endless`), `dark` (tone), `send` (mix); LFO `fb, tone, mix` (коды 10, 8, 9), `shape 1`;
    - **nebula** — `amount`, `size` (`1.2 + 8·size с`); LFO обе (11, 12), `shape 1`;
    - **pharos** — `chord` (хранится `v·4`), `octave` (−2…+2, `v·4 − 2`), `length` (ms / `endless`), `swing`, `level`; без LFO;
    - **navicula** — `octave` (`as lighthouse · нота` / `±N · нота`), `level`; без LFO; `obj` = место — кораблик пропал (своё `SINK`, `MOVE` прочь, `CLEAR`, отмена, кубик) → `objGone`;
    - **веер** `aether`: `wow 180°, mare 150° (< 0.01 — calm), drive 130°, chance 110°, spread 90°`, `arc: fx.drive`, LFO на всех пяти (коды 0–4), `shape 1`;
    - **легенда** — 10 строк `view.js:370-373`.
14. **Корзина и отмена.** `clear()` — `CLEAR`, свои места пусты, `objGone` занятым. `restored()`: пальцы, звезда, свои значения сброшены; круги буя и времена ударов остаются (только картинка); кораблики, пропавшие по снимку, — `objGone`. LFO строк переживают отмену (строки мира, `obj −1`).
15. **Рисование** (`view.js:151-360`):
    - **кеш стены** — `CGImage` `W × H × DPR` (DPR ≤ 2), ключ веба `W×H×DPR|hor|qy|Ws|pcs|root`: 110 звёзд (LCG зерно 13, точно и в том же порядке), 700 штрихов волн, фарватер (края пунктиром, квинта бледнее), 16 поперечных черт мест (4-я ярче), 13 засечек полутонов (ступени лада длиннее и ярче), два мыса (штриховка, скалы, кромка, урез, прибой, кипарисы), горизонт, набережная кладкой; рисуется синхронно при смене ключа (смена лада — пересборка);
    - **в кадре** — порядок веба: стена, луна (высота = cut, дорожка — яркость cut и ширина res, ореол `glowAt`, пунктирные кольца = res, лицо, кратеры, кровавая при LFO), падающая звезда, туман (3 пелены, `10 + 22·amt` строк), вехи (16 шестов, фонарь = кораблик, бегущий огонёк + полоса света = шаг), кораблики от дальних к ближним (бумажная лодочка, качание от `sd`, 3 штриха отражения, текущий — золотой + `glowAt`, `hit = 1 − Δt/0.5 с`), буй (качка от `fx.wow`, круги повторов), маяк (горит, луч к последнему удару < 0.6 с, вспышка 0.26 с; стоит — знак пуска), веер-дуга; подписи `mapText` курсивом только при касании: кораблик `нота·аккорд · Hz` и `step N`, луна `Hz · res`, буй `echo 1/4 · %|endless`, туман `reverb %`, маяк `bpm`;
    - **случайность вида** — нет своей: качание от `sd`, всё от `now`; звёзды — LCG;
    - производительность: никакого `shadowBlur`, градиентов в кадре нет (ореолы — `glowAt`), полноэкранных проходов нет, кроме `drawImage` стены; буферы предвыделены; `dt` картинки ≤ 0.1 с.
16. **Не делаем:** совпадение кубика с вебом; общий темп хоста; LFO на `time` эха, на плашках маяка и кораблика (их нет в вебе); переделку `cornerHit` прочих миров.

## Риски

- **Объём** — как Natura: два плана — (а) ядро `ACT_LFO` и `DICE`, `goMap / lfoBase` в протоколе и хосте, `scaleSnap`, `PorMath`, `PorMirror`, `PorState`, `PorTouch`, `PortusView` без картинки (мир не включён на карте); (б) `PorScene`, `PorDraw`, сцены, включение на карте, доки.
- **Стена** — 700 штрихов и 110 звёзд в одном слое; пересборка только при смене ключа (лад, размер), в кадре — один `drawImage`.
- **`lfoSnap` каждый кадр** — один вызов C и до 64 записей; если заметно — хост отдаёт базу из снимка, обновляемого раз в N кадров.
- Снимки — симулятор; звук, жесты на ощупь и производительность проверяет автор на iPhone.

## Решено без автора

Развилки решены «как в вебе»:

1. Луна — тап на карту, тяга — фильтр, удержание — плашка (как в вебе); механизм — `World.goMap` от хоста, `cornerHit` Portus — `false`.
2. Кровавая луна — как в вебе; база LFO — `World.lfoBase` от хоста.
3. Кубик — действие ядра `DICE` (как Natura), веб не трогаем.
4. LFO — все строки мира (`obj −1`), коды 0–12 по группам; LFO переживают отмену.
5. `snap` лада — общий `scaleSnap` (был `infSnap`).
6. Темп — только маяк: общего темпа хоста в iOS нет.
7. Стена — тот же LCG и порядок, что в вебе, чтобы пары снимков сходились.
