# iOS-приложение — фаза 2b-1: каркас хоста (верхняя строка, легенда, undo, сохранение)

**Дата:** 2026-10-28 · **Статус:** согласовано с автором в чате, ждёт ревью файла · **Фаза:** `docs/native-ios-plan.md`, фаза 2, часть b, срез 1 из 3

Фаза 2b (хост-экраны) разделена на три среза, у каждого своя спека, план и приёмка на iPhone:
- **2b-1** (эта) — роутер хоста, расширенный `World`, верхняя строка, легенда, кубик и корзина, громкость, undo, автосохранение сцены;
- **2b-2** — оболочка плашек (`sheet`), плашка FX, LFO строк;
- **2b-3** — карта Universum, микшер и мастер, concordia, панель audio, уровни каналов в ядре, настройки микшера / audio / link в файле.

## Цель

Вокруг Firmamentum в приложении — хост как в вебе: верхняя строка с громкостью, ладом, кубиком, undo и корзиной, легенда по тапу на заголовок; сцена переживает выгрузку приложения. Перенос, не переделка.

Готово, когда: на iPhone автора верхняя строка выглядит как в вебе; громкость тянется без треска; смена лада слышна; кубик и корзина работают; undo откатывает и звёзды, и лад; после выгрузки приложения из переключателя и запуска сцена и громкость на месте; в панели замеров время снимка и загрузка рендера в норме. Все проверки ниже зелёные.

## Решения (с автором, 28.10)

1. 2b — три среза (2b-1, 2b-2, 2b-3), каждый со своей спекой и приёмкой.
2. Кнопки без экрана в 2b-1 (стрелка назад, предмет в углу, FX) рисуются приглушёнными и не отвечают; тап по громкости (панель audio) — ничего, перетаскивание работает. Свайп от левого края (на карту) — тоже ничего.
3. Сцена каждого мира сохраняется автоматически и восстанавливается при запуске (iOS выгружает приложение из фона). Слоты сцен по имени — после натива, отдельно.
4. Хост ↔ ядро — через одно кольцо действий: команды хоста — действия слота −1 в той же очереди, что касания (порядок undo и касаний гарантирован). Снимок — запрос действием, ответ — обратным кольцом строк. Фасад состояния в Swift (как `model.js`) не делаем (решение 7 спеки 2a).
5. Автосохранение пишет последний снимок, уже взятый для undo, — отдельного запроса к ядру нет; работает и когда звук стоит (прерывание).

## Ограничения

- Миры заморожены. Картинка верхней строки и легенды — по `host/ui-top.js` и `host/legend.js`; принципы «не шумно», гравюра, без теней и жирного (`CLAUDE.md`, «Дизайн-принципы»).
- Ядро: C++17, `-ffp-contract=off`, без блокировок в аудиопотоке; аллокация на аудиопотоке допускается только в снимке мира (`t2d_snapshot`, раз за жест) — с замером. Комментарии — по-русски.
- Правка `core/host/` входит в `t2d.wasm` → пересборка `core/build.sh`, новая версия при пуше (хук `guard.py`). Веб по поведению тот же: `host.vol` по умолчанию 1.0, слот хоста есть только у движка приложения.
- Ветка `native`, в `main` не идёт. Новые Swift-файлы — руками в `project.yml` (у `T2DTests` нет TEST_HOST, `docs/ios-2a-deferred.md`).
- `t2d_app_init` — только при остановленном движке (`docs/ios-2a-deferred.md`).

## Часть 1. Ядро и мост (C++)

**Слот хоста.** Действия со `slot = -1` разбирает сам `Engine` на аудиопотоке, в мир не идут:
- `vol(gain)` → новый `host.vol(g)` вместо константы `VOL_GAIN`; сглаживание ~30 мс (как `setTargetAtTime(…, 0.03)` в вебе), чтобы громкость не трещала. Положение 0…1 → дБ → усиление считает Swift по формулам `audio.js`;
- `scale(on, idx, root)` → `host.scale` (уже есть);
- `snap(slot, id)` → `t2d_snapshot(slot)`; строка с `id` и слотом — в новое обратное кольцо снимков (аудио → UI), 2 ячейки по `STR_CAP`, выделены заранее. Не влезла — счётчик потерь;
- `restore(slot)` → строка снимка едет рядом в кольце строк UI → аудио (2 ячейки по `STR_CAP`); аудиопоток забирает её, когда дошла очередь действия, и зовёт `t2d_restore`. Кольцо строк полно — действие не ставится, вызов возвращает 0.

**C API** (`t2d_app.h`, новое):
- `int t2d_app_restore(int slot, const char* s, int len, uint64_t touch)` — строка + действие; 0 — отброшено;
- `int t2d_app_snap_take(int* id, int* slot, char* buf, int cap)` — забрать готовый снимок (UI, из кадра); длина или 0.

Громкость, лад, кубик / корзина мира и запрос снимка — через существующий `t2d_app_action` (хост — слот −1, кинды хоста — константы в `t2d_app.h`).

**Статистика.** `t2d_app_stats_t` + время снимка на аудиопотоке (среднее, максимум за окно) и потерянные снимки; в панели замеров — одна строка. Порог внимания — снимок дольше 10 % буфера.

**Тесты ядра** (рядом с тестами `core/app/`): порядок «касание → restore → касание»; снимок → restore даёт тот же мир (снимок после совпадает); переполнение колец действий / строк / снимков не роняет и считается; громкость сглаживается без скачка; restore мусорной строки не роняет.

## Часть 2. `World` и роутер хоста (Swift)

**Протокол `World`** дополняется по интерфейсу мира веба:
- `title`, `sub` (Firmamentum: «stellae · pulsar»), `legend` — строки (глиф, жест, что делает);
- `hasFx` — приглушить кнопку FX (плашка — 2b-2);
- `dice()`, `clear()` — у Firmamentum действия ядра 5 и 6;
- `corner` — рисуется приглушённым, не отвечает (ведёт на карту — 2b-3);
- `restored()` — после restore мир сбрасывает свои временные состояния (подсветки, пальцы); рисует он всё равно по зеркалу.

Снимок и restore — не методы мира, а хост через ядро по слоту мира.

**Реестр** — список миров (пока один Firmamentum); карта в 2b-3 возьмёт его отсюда.

**`Host`** — слой между `Stage` и миром, файлы в `ios/app/T2D/Host/`:
- `Host` — роутер касаний и порядок рисования;
- `TopBar` — кнопки и список ладов;
- `Legend` — оверлей;
- `Undo` — история и снимки;
- `Prefs` — файлы настроек и сцен;
- `CoreLink` — обёртки нового C API (протокол, чтобы подменять в тестах, как `Core` в `Touch.swift`).

**Роутер касаний** (часть `uiHit/uiDown/uiMove/uiUp` из `app.js`):
- открыта легенда — забирает все касания, тап закрывает;
- открыт список ладов — тап по строке / тонике выбирает (`rootAt`), мимо — закрывает;
- палец лёг на кнопку верхней строки — касание её: громкость тянется по вертикали (`VOL_TRAVEL = 220` pt на весь ход), остальные срабатывают по отпусканию; приглушённые — съедают касание без действия;
- иначе — миру, как сейчас.

Угол 44×44 с панелью замеров остаётся у `Stage`.

**Конец жеста.** Отпущены все пальцы (`up` и `cancel`) → `Undo.commit()`.

## Часть 3. Верхняя строка и легенда (картинка)

Перенос `host/ui-top.js` и `host/legend.js` на `Draw.swift`, новых решений по виду нет.

- Раскладка — по `btnPos` от правого края: корзина, undo, кубик, FX, лад, громкость; слева стрелка назад, правее — заголовок (тап — легенда). Тонкие кружки на тёмной подложке, `BTN_R = 20`, `CLR_R = 17`; высота строки — от safe area (как `topY`).
- Стрелка назад, FX и предмет в углу — приглушены.
- Как в вебе: громкость показывает дБ, пока тянешь (`drawVol`); кубик крутится после броска; undo тускнеет при пустой истории; список ладов — `off` и `SCALES`, справа тоники в две колонки (`NOTES`).
- Легенда — оверлей «глиф · жест · что делает» из `world.legend`, глифы по `legGlyph`, курсив ужимается (`fitText`).
- Шрифты: заголовок — IM Fell English; легенда и список ладов — EB Garamond (`reading`); курсив — только в подписях; без жирного и теней.
- Подпись сборки (`drawBuild`) не переносим: версия и хеш — в панели замеров.

## Часть 4. Undo и сохранение

**Undo** — как `host/undo.js`, но снимок асинхронный:
- шаг — законченный жест, после которого снимок изменился: `{w: снимок до, scl: лад до, after: лад после}`; на мир 10 шагов;
- конец жеста → запрос `snap` с новым `id`; ответ (через ~буфер) сравнивается с последним снимком; отличается — прежний в историю. Ответы с устаревшим `id` отбрасываются;
- undo: `restore(w)`; лад откатывается по правилу веба (менялся в этом шаге и с тех пор не трогали — вернуть); `world.restored()`. Следующий ответ снимка — новая база, не шаг (текст снимка после restore может отличаться от сохранённого);
- база при запуске — первый снимок после восстановления сцены;
- история — только в памяти.

**Сохранение** — `Application Support/`:
- `prefs.json` — `{v: 1, vol}`; в 2b-3 добавятся микшер, audio, link;
- `scene-<слот>.json` — `{v: 1, w: снимок, scl: {on, idx, root}}`; лад — со сценой (в вебе он свой у мира, `perScl`);
- запись атомарная (`Data.write(.atomic)`): через 3 с после последнего изменившего жеста и сразу при уходе в фон — последний уже взятый снимок, ядро не трогается;
- запуск: прочитать файлы → `t2d_app_init` → первым в кольце `restore` сцены, затем лад и громкость;
- файл битый или чужой версии → строка в лог, пустой мир, без падения.
