# iOS-приложение — фаза 3: Horologium на Swift

**Дата:** 2026-10-30 · **Статус:** черновик, ждёт ревью автора · **Фаза:** `docs/native-ios-plan.md`, фаза 3 (миры по одному) · **Образец:** `ios/app/T2D/Monochord/`, спека `2026-10-30-ios-monochordum-design.md`

## Цель

Четвёртый нативный мир — IX · Horologium (Nova): картинка, касания, маятник, шкала tempus, плашки кольца и ступицы, веер FX с LFO и легенда на Swift + CoreGraphics. Колесо, кольца, ход и звук уже в ядре (`core/worlds/horologium/`), Swift разбирает зеркало и шлёт действия. Попутно — то, без чего мир не встаёт в нативе: LFO и кубик в ядре Horologium.

Готово, когда: на iPhone автора Horologium открывается с карты; кольца (тап, двойной тап, фаза), ступица, маятник (рукой, бросок, через верх, поймал) и шкала tempus работают как в вебе; LFO на плашках и веере слышно и видно; пары снимков симулятор ↔ веб (`sc_horologium`) сходятся; проверки ниже зелёные.

## Решения

1. **Всё как в вебе** (`worlds/horologium/view.js`; из `model.js` — константы `NR`, `Z`, `ROMAN`, `NAMES`, `ET`, `OM0`, `uOfE`, `eOfU`, `noteName`, физика маятника `grab / swing / tapPendulum / release / tickPendulum`, шкала `holdStrip / dragStrip / freeStrip / resetSpeed`, подпись `ratio`): геометрия, подписи, числа, жесты, пороги. Новых решений в картинке нет. Шрифты как в вебе: `mapText` — IM Fell курсив, `text` — EB Garamond, плашки в `reading`. Тема — слот 9 из `Worlds.swift` (`ink 214,180,110`, фон `12,10,7`).
2. **Где код:** `ios/app/T2D/Horologium/` — `HoroMirror.swift` (разбор зеркала), `HoroGeo.swift` (`geo`, `ringR`, `bobXY`, `stripX` / `stripU`, `ringAt`), `HoroPendulum.swift` (состояние маятника `th, ph, spin, held` и его физика; чистый код без `Core`, на вход — `u`, `F`, выход — действия списком), `HoroMath.swift` (константы, `uOfE`, `eOfU`, `noteName`, `ratio`), `HorologiumView.swift` (класс `World`: легенда, касания, тик), `HoroDraw.swift` (рисование), `HoroSheets.swift` (плашки и веер). Регистрация: `Worlds.swift`, слот 9 `view: true`; `App.makeView` — ветка `9`.
3. **Зеркало** (`core/worlds/horologium/world.hpp`, 47 чисел): `fx[5]` (`AEQUALIS, MATERIA, CONCURSUS, CHANCE, HALL`), `run`, `u`, `uT`, `bpm`, `strip`, `held`, `P`, `F`, `strikes`, `locked`, затем 8 колец (II…IX) по 4 числа: `on, under, phi, lvl`. Кольцо heard: `[удары, P, номера колец…]` или 0 чисел — по нему вспыхивают кольца (`ringHit`, 260 мс) и луч concursus (больше одного кольца в пачке и `fx.concursus > 0.05`, 350 мс); разбор — в `idle()`, как у Monochordum. Читатель зеркала внедряется (тесты — на фейке).
4. **Действия** (`world.hpp:19`) — через `Core.action(slot 9, …)`: `RING 0 (i, [key, v])` (`key`: `on 0, under 1, phi 2, lvl 3`), `FX 1 (i=key, [v])`, `RUN 2 ([on, u?])`, `HELD 3 ([on])`, `STEP 4 ([d])`, `BPM 5 ([bpm])`, `SPEED 6 ([u, uT, strip])`, `CLEAR 7`, новый `DICE 8` (решение 8).
5. **Своего значения до зеркала не держим** — кольца, FX, ход, темп читаются из зеркала, как у Monochordum. Исключение — то, чего в ядре нет: маятник (`th, ph, spin, held` — только картинка и жест, как `pend` в вебе) и счётчик `handSteps` (для тестов). Стрелку и колесо досчитываем между кадрами: `Pvis = P + F·min(0.1, now − t_зеркала)`, как `Pvis` в вебе.
6. **Касания** (`view.js:40-96`; общие `Touch.dtapMs 320`, `Touch.holdMs 420`, пороги мира — как в вебе), порядок проверки в `down`:
   - **маятник**: груз ближе `bob + 24` или (при `spin`) |расстояние от оси − L| < 30 — схватил (`HELD 1`, колесо стоит); ведёшь — `swing`: проход через низ — `STEP 1/4`; тап (< 300 мс, без сдвига) — пуск / стоп; отпустил — бросок по `release` (скорость сглажена 0.6 / 0.4; держал неподвижно > 120 мс — ω = 0, поймал → стоп; `e ≥ 1.95` — крутится через верх);
   - **шкала tempus** (|y − S.y| < 24, x в `[x0 − 14, x1 + 14]`): палец на шкале — `holdStrip` (запускает ход, если стоял), ведёшь — `dragStrip`, `u ∈ [−8, 8.5]` по логарифмической шкале `0.05…120 об/с`; подъём — `freeStrip`; двойной тап — `resetSpeed` (назад к темпу);
   - **ступица** (`r < r0 − 6`): тап — пуск / стоп (`RUN`); удержание — плашка `tempus`;
   - **кольцо** (|d − Rᵢ| < 0.62·dr): тап — вкл / выкл; двойной тап по тому же кольцу — унтертон (и включает); сдвиг вдоль > 8 px — фаза (`RING i [2, phi]`); удержание без сдвига — его плашка;
   - пальцы независимы (по `Finger.id`); `lastTap` для двойного тапа — один на мир, как в вебе;
   - угол — солнце четвертью справа сверху (`y > sun.y` и `hypot < sun.r + 6`) ведёт на карту.
7. **Плашки и веер** (`view.js:97-115, 251-256`):
   - **кольцо** `circulus II…IX`: `sounds` (`yes / no`), `undertone` (`n a turn` / `1/n · 12/n a turn`), `phase` (`N°`), `level` (`N%`); LFO только на `phase` и `level`, форма `classic`;
   - **ступица** `tempus`: одна строка `tempo` 40–200 bpm (`BPM`), без LFO. `T.tempoFrom` (темп другим мирам) в нативе не делаем — у натива нет общих часов;
   - **веер FX** `aether` (у веба веер берёт заголовок `fxSpec()`): секторы `aequalis 190°, materia 160°, concursus 130°, chance 105°, hall 80°`, `arc: fx.hall`; тексты `pure / equal / N% equal`, `lignum / metallum N%`, `N%`; LFO на всех пяти, форма `random`.
8. **Ядро Horologium** (`core/worlds/horologium/world.cpp`), веб не меняется (там LFO и кубик идут через JS), правка `core/` → пересобрать `t2d.wasm`:
   - **`case sdk::ACT_LFO`** — все строки LFO — строки мира (`obj = −1`), как у Monochordum: FX `0…4` → `setFx`; кольцо `i`: `phase` — `5 + 2·i`, `level` — `6 + 2·i` (`5…20`) → `setRing`. Строки без LFO (`sounds`, `undertone`, `tempo`) — код `−1`. Прочие obj и ключи — пропуск;
   - **`DICE 8`** — как веб `model.dice()` (`model.js:106-114`), тот же порядок вызовов rng: набор из `MAGIC` (12 наборов), унтертоны с вероятностью 0.25, у всех колец `phi 0, lvl 0.8`, с вероятностью 0.4 — фаза `0.25 / 0.5 / 0.75` у одного из звучащих колец; `materia = R`; ход пущен на `u = uT = 0`. Случайность — `sdk::Rng`. Swift после кубика ставит фазу маятника под новый ход (как веб).
9. **Корзина** — как веб `clear()` (`model.js:115`): `CLEAR` гасит кольца и ход. LFO не снимает (веб не снимает) — `rowLfoOff` не нужен.
10. **Undo и пальцы.** Снимок ядра не хранит `held` и `strip` (`model.cpp:71-89`): если во время undo палец на маятнике или шкале, ядро осталось бы «в руке» навсегда. `restored()` отпускает их явно — `HELD 0` и `SPEED [u, uT, 0]` — и бросает все пальцы (урок Monochordum: смычок после undo).
11. **Лад** нужен только подписи нот в `ratio` (тоника `55·2^(root/12)`, если лад есть): мир берёт `root` из `World.scale(pcs:root:)`. `enter()` не нужен.
12. **Рисование** (`view.js:120-250`):
    - стена — `CGImage`, ключ `W×H×scale|cy|R|strip.y`: обод, 96 делений, цифры I…XII, подпись «раз», шкала tempus с делениями, ось маятника;
    - в кадре: кольца (вспышка 260 мс по heard, номер кольца в просвете между метками, при `F > 4` — ровный круг), часовая стрелка (`P/12`, цифра такта, диск при `F/12 > 4`), стрелка-солнце (диск при `F > 4`, луч concursus 350 мс), подпись отношения (`ratio`), метка `limen` (`stripX(20/m_ср)`), бегунок `F` на шкале, маятник (веер при частоте > 2.5, расплыв при `spin` и > 3), подпись фазы, пока тянут вдоль кольца;
    - свечение — `glowAt`; никакого `shadowBlur`, градиентов на кадр, полноэкранных проходов, аллокаций в горячих циклах; `dt` для картинки — не больше 0.1 с.
13. **Не делаем:** `T.tempoFrom` и общие часы; темп и пуск из панели audio (`tempo.play / playing / armed` веба — в нативе темп в панели приглушён); замок к MIDI-такту (`locked` в нативе всегда 0 — CoreMIDI в фазе 5); сброс двойным тапом на строке плашки.

## Проверка

- **Ядро:** C++ тесты в `core/tests/sdk_test.cpp` — `ACT_LFO` Horologium (FX, фаза и уровень колец по кодам; obj ≥ 0, чужой ключ, `n < 2` — без изменений); `DICE` (звучащие кольца — набор из `MAGIC`, `lvl 0.8`, фаза ≠ 0 не больше чем у одного, ход пущен на `u = 0`, детерминированно при одном зерне); `core/build.sh && core/build/sdk-test` → `0 failed`. Веб не меняется: `node --test tools/models/horologium.test.mjs`, `core/build.sh && node --test tools/test-horo-core.mjs` — зелёные до и после.
- **Swift** (`ios/app/T2DTests/HorologiumTests.swift` на фейковом зеркале): разбор зеркала и heard; физика маятника (`swing` → `STEP`, `release`: поймал → стоп, бросок → `RUN` с `u = uOfE(e)`, через верх → `spin`); касания → действия (кольцо — тап / двойной тап / фаза, ступица, шкала — удержание / сдвиг / подъём / двойной тап, маятник — тап / бросок); удержания → плашки; коды строк LFO по решению 8; `ratio` (имена `NAMES`, rhythmus / tonus); `restored()` с пальцем на маятнике и шкале → `HELD 0` и `SPEED … 0`.
- **Снимки:** сцены `-shot horologium` (поле, кольца звучат, ход идёт), `horologium-ring-sheet`, `horologium-hub-sheet`, `horologium-fan`, `horologium-spin` (маятник через верх, тон за limen) против веба `sc_horologium` (`tools/shot.py:1317`) — агент `shots`.
- **iPhone:** автор ставит `ios/app/install.sh`.

## Ограничения

- Снимки — симулятор; звук, маятник на ощупь и производительность проверяет только автор на iPhone.
- Кубик натива — `sdk::Rng`, веба — `Math.random`: распределение то же, конкретные броски разные.
- LFO колец в вебе — LFO объекта (`horo-r${i}`), в нативе — строки мира: при undo нативные не гаснут.
