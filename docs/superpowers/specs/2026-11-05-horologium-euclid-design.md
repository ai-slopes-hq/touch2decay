# Horologium — Евклид на сетке 16 и длина кольца (полиметр)

Дата: 05.11.2026. Статус: спека, ждёт ревью автора. Мир IX, ветка `native`.

## Зачем

Автор (05.11): звук glitch-кита нравится, но «рисунки ударных прям хаос». Причина: кольцо n бьёт n раз за оборот ровно,
II…IX дают 2, 3, 5, 7, 9-оли поверх друг друга — общей сетки нет. Нужен порядок, но с полиритмом и полиметром,
как в Cymatica (у колец своя длина), и регулировка руками, а не надежда на кубик.

Опора: в Grids (MI, GPL v3 — таблицы не берём, только вывод) 25 грувов стоят на ровной сетке (49 из 907 ненулевых —
на нечётных 32-х), ударов за такт бочка : малый : хэт ≈ 2 : 2 : 3–4 на средней плотности, ≈ 3.5 : 4 : 5 на высокой —
лесенка 2-3-4 → 3-4-5, которую предложил автор.

## Что сказал автор

- Евклид на сетке 16 — да. Ратио 2-3-4, 3-4-5, 4-5-6 — включёнными кольцами («круто»).
- Длина кольца меньше 16 — как в Cymatica: полиритм и полиметр.
- Длина — жестом вдоль кольца (вариант 1); фаза уходит в плашку.

## Звук: когда кольцо бьёт

- Шаг кольца — шестнадцатая такта (оборот колеса = такт, как сейчас), у унтертона — восьмая (вдвое медленнее).
- Глобальный номер шага кольца `q = floor(P·16)` (унтертон — `floor(P·8)`), 64-битный, как счётчик сэмплов потолка.
  Удар — когда `q` сменился (в любую сторону, как сейчас `floor(P·m + phi)`) и шаг `j = (q + rot) mod L` — удар рисунка.
- Рисунок — Евклид без таблиц: `hit(j) = (j·k) mod L < k`, k = min(n, L), n — номер кольца (II = 2 … IX = 9).
  Удар на шаге 0 есть всегда. При k = L — каждый шаг.
- `rot = round(phi·L) mod L`: фаза остаётся числом 0…1 в модели (снимок и веб не ломаются), звук видит её целым сдвигом.
- Длина `len` — целое 1…16, умолчание 16. Кольцо с L ≠ 16 сходится с «раз» раз в lcm(L, 16)/16 тактов — полиметр.
- Всё прочее как было: `chance`, `concursus` (совпадения теперь точные — на одной шестнадцатой), потолок 24 удара/с,
  `heard()`, MIDI-замок (оборот = такт), маятник и tempus, хвост выключенного кольца.
- `aequalis` и `m` дальше влияют только на высоту (`pitch(i)` через `mOf`), не на ритм.

## Модель и снимок

- У кольца новое поле `len` (1…16, мусор — в диапазон, NaN — без изменений, как у `inst`). Ключ снимка `len`;
  старый снимок без `len` — 16. `clear` — 16.
- Зеркало ядра: на кольцо 6 чисел (`on, under, phi, lvl, inst, len`), всего 63 (было 55). Свифт и веб-фасад читают `len`.
- Умолчание колец: звучат II, III, IV (2-3-4: kick, blip, click), остальные выключены; `len` 16, фаза 0.
- Кубик (`dice`): тройка соседних колец k, k+1, k+2 (k — 2…7, по `rng`) включена, остальные выключены;
  `len` — из набора {16, 16, 12, 8, 6} у каждого из трёх, фаза — случайный сдвиг `rot / len`; `inst` не трогает (как сейчас).

## Натив (iOS): жесты и рисунок

- Вдоль кольца тянешь — **длина**: по часовой длиннее, против — короче, шаг — одно гнездо (угол 2π/16 на гнездо,
  от точки касания); пока тянешь — подпись `12 / 16` у кольца (EB Garamond, курсив, как подписи поля). Тап, двойной тап,
  долгое касание — как были.
- Фаза — строка плашки кольца (уже есть: *phase*), отображение — сдвиг в шестнадцатых: `3 / 12` вместо градусов.
- Рисунок кольца: L гнёзд равномерно по всему кругу; гнездо с ударом — точка, пустое — едва видная засечка;
  свой бегунок — текущее гнездо `(q + rot) mod L` светится; удар — вспышка гнезда (как сейчас вспышка метки).
  Кольца с разной длиной видимо крутятся с разной скоростью. Метки `marksOf` (n за оборот) уходят.
- «Не шумно»: засечки пустых гнёзд — едва заметны; подпись длины — только пока тянешь.

## Веб

Веб — сайт, ядро общее: фасад читает и хранит `len`, вид рисует гнёзда по `len`, жест «вдоль — фаза» в вебе остаётся
(длины в вебе нет — как строки *instrument*), README говорит, что длина — в приложении.

## Вне объёма

Своя карта грувов в духе Grids, отдельная ручка ратио, число ударов у кольца независимо от номера, свинг и акценты.

## Риски

- Зеркало 55 → 63: все читатели (Swift, веб, тесты) — одной правкой, иначе сдвиг полей.
- Смена смысла `phi` (непрерывная фаза → сдвиг в шагах): старые сцены зазвучат по-другому — ожидаемо, мир меняет механику.
- Жест длины на восьми узких кольцах одной рукой — проверить на iPhone; запасной путь — строка *length* в плашке.
