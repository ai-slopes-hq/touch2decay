# III · Laboratorium (`laboratorium.js`) — перегонный куб (v157)

Переписан заново 22.10 (старая «квадратура круга» с 4 операторами, solve/coagula и металлами — в истории git до v156). Тема — `INK 232,220,200`, `BGC #0d0a08`, цвета колб `COL` (киноварь, купорос, ярь-медянка), медь змеевиков `BRASS`.

- **Звук:** 3 `OscillatorNode` (синусы) — колбы A, B, C; FM: A → `ab` → частота B, B → `bc` → частота C, кольцо C → задержка 11 мс → `ca` → частота A (только когда `st.ring`); индекс = 0.55 · витки, девиация = индекс × частота приёмника. Сумма → `WaveShaper` (athanor: tanh, `1 + 9k²`) → `fireG` (огонь: 0.25 + 0.75·heat, гаснет за ~0.8 с) → pre → hall. Голоса — `f.lvl · 0.12`, панорама A/B/C — лево/центр/право × spread. Генераторы создаются, когда огонь, и останавливаются через 9 с тишины (`stopOps`, `setLive`).
- **Высота:** `BASE = 12, 24, 19` полутонов от 55 Гц у пустой колбы, полная — на 12 ниже (`semiOf`, с ладом — `snapSemi`). Кипение `wob` (центы): `bulla · heat · 14 ·` (две синусоиды, у каждой колбы свои).
- **Жизнь (`tick`):** перегонка A → B → C и C → A (с кольцом — полностью, без кольца — вполовину, «конденсат», без FM): `rate = 0.006 + 0.03·heat` доли уровня в секунду × `gush(k)` — толчки, у каждой трубки свой период (≈ 30, 18, 11 с), поэтому уровни бродят без конца; цвет смеси `mix` перетекает с жидкостью. Капли: раз в `1000 / (0.6 + 4.5·heat)` мс (× 0.4…1.6, × (1 + 0.12·витки B→C)) в C (с кольцом 40 % — в A), долетела за 380 мс — `plink`: вспышка голоса колбы + тихий синус ×4. `update()` ~16 раз в секунду.
- **Геометрия `geo()`:** портретная сцена `Ws`; атанор `furn … bot` (кладка, топка, решётка — в `wall()`), колбы `F[3]` (A, C — над огнём, B — выше в центре, радиус `r` до 62), кольцо `ringY` под колбами, лампа `lamp` — карта. `tubes()` — ломаные змеевиков AB, BC, CA; `along`, `nearPoly`.
- **Жесты:** огонь (топка) — тап: `ignite`, вверх-вниз — heat; колба — вверх-вниз: уровень `L` (LMIN … LMAX), держишь — `flaskSheet` (liquor, level; «~» random); змеевик — тап: виток (0…6); кольцо — тап: `st.ring`.
- **Картинка:** витки — петли посередине змеевика, течёт — по нему бегут капли цвета источника (`flowVis`); жидкость — цвет смеси, поверхность — волна, чем больше входящий индекс, тем чаще и выше; пузыри — heat × bulla; брызги от капель; пламя — высота от жара; подпись ноты — пока тянешь колбу, `ignis N%` — пока тянешь огонь.
- **FX:** athanor, bulla, spread, hall. Кубик — уровни, витки 0–3, кольцо (35 %), жар, огонь. Корзина — огонь гаснет. Снимок старого Laboratorium (без `L`) при отмене игнорируется.
