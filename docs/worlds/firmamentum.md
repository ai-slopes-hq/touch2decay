# X · Firmamentum

**Firmamentum (мир X, `worlds/firmamentum/` + `pulsar-worklet.js` (тонкая обёртка над ядром `pulsar.wasm`); образец раскладки model / engine / view — см. `CLAUDE.md`):** `model.js` — звёзды, fx, комета, drift, кубик, снимок (`fpOf` → `model.fp`, `ffOf` → `model.ff`, `cometTick`, время — секунды); `engine.js` — шина, зал, worklet, `setLive`; `view.js` — `geo`, `toSky`/`fromSky`, касания, `starSheet`, `wall`, `drawStar`, `drawDust`, `drawComet`; `index.js` — склейка и `t2d.firm` (+ `model`). Тесты модели — `node --test tools/test-models.mjs`. пульсарный синтез. **DSP — ядро C++** (`core/worlds/firmamentum` → `pulsar.wasm`, 23.10): `pulsar-worklet.js` только берёт байты из `processorOptions.wasm` и зерно `seed`, гонит сообщения в ядро и шлёт метры; engine качает `pulsar.wasm` один раз (на каждый контекст — `slice(0)`), `t2d.firm.core` становится `'wasm'` после `{t:'ready'}`, ошибка ядра — `console.error`. Эталон — `tools/ref/pulsar-worklet.js` (прежний JS с генератором от зерна); сверка эталон ↔ render-cli ↔ WASM по сэмплам — `node --test tools/test-firm-core.mjs` (1e-6). Скорость — в ~15 раз быстрее JS. Звук прежний, ниже описан алгоритм. Worklet / ядро: до 6 голосов `{fp, ff, cyc, win, mask, lvl, pan}`; каждый период 1/fp — пульсарет длиной min(cyc/ff, 1/fp), синус ff в окне (win: 0 Ханн → 0.5 удар с хвостом → 1 прямоугольник), mask и fx `jit` (scintilla) — пропуск и сбой фазы; DC-блок, tanh; обратно `p {c: счётчики пульсаретов, g}` ~30/с — звезда вспыхивает, когда счётчик вырос. Модуль — при входе (`start`). Мир: `geo()` — горизонт `hy`, свод — эллипс `RX × RY` (высокий), над ним Эмпирей (лучи, колёса), солнце под землёй слева снизу (sunGlyph с клипом); звезда `{slot, h, u, cyc, win, mask, lvl}`: `h` — высота (fp = 0.7·(520/0.7)^h, выше 27.5 Гц с ладом — ступени), `u` — по своду (−1…1, формант 140…4800 Гц, ± `dr` от drift); `toSky`/`fromSky`; `LIMEN` — где 20 Гц. Жесты: тап по небу — `addStar` (прокол), тап по звезде — `closeStar`, тянешь — h и u, держишь — `starSheet`. Рисование: `wall()` (Эмпирей, свод с делениями, звёзды, limen, rhythmus/tonus, земля), `drawStar` (вспышка по `flash` при fp < 18, луч — форма пульсарета). FX: scintilla, drift, cometa, crepitus, fulgur, spread, hall. **crepitus** (worklet `dust`): треск — пуассоновские щелчки (2 + 90·c^2.2 в секунду × стайки `burst`), сила в основном мала (r^5), короткий всплеск шума через дифференциатор, панорама случайно; шипение c²; всё × `act` (звучит, пока есть звёзды); события `k [pan, a]` → пылинки `specks` на своде (~260 мс). **fulgur**: на пульсарете с вероятностью fulgur·min(0.25, 4/fp) — `flash`: 25% одиночный щелчок, иначе синус 10.5/12.8/14/15.6/17.2 кГц 6–60 мс с фронтами 0.4 мс, жёстко в L или R; события `f [slot]` → белый луч `bolts` от звезды вверх до свода (~110 мс). Тест — `t2d.firm.specks`, `bolts` (счётчики). Комета (`fx.cometa`, 0 — нет): `cometTick` — раз в 4…24 с пролёт от края свода вниз (`comet {a, b, t0, dur}`), звезда ближе 90 px — множитель пульсации `s.cm` до 2^(2·cometa) (в `fpOf`), `drawComet`. Плашка звезды: pulse (h), formant (u), cycles, window, mask, level, «~» — random. `t2d.firm` (stars, fx, geo, fp, ff, LIMEN, at(h, u), counts, gains, ready). Сценарий `shot.py firmamentum`.
