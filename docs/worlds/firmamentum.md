# X · Firmamentum

**Firmamentum (мир X, `firmamentum.js` + `pulsar-worklet.js`):** пульсарный синтез. Worklet: до 6 голосов `{fp, ff, cyc, win, mask, lvl, pan}`; каждый период 1/fp — пульсарет длиной min(cyc/ff, 1/fp), синус ff в окне (win: 0 Ханн → 0.5 удар с хвостом → 1 прямоугольник), mask и fx `jit` (scintilla) — пропуск и сбой фазы; DC-блок, tanh; обратно `p {c: счётчики пульсаретов, g}` ~30/с — звезда вспыхивает, когда счётчик вырос. Модуль — при входе (`start`). Мир: `geo()` — горизонт `hy`, свод — эллипс `RX × RY` (высокий), над ним Эмпирей (лучи, колёса), солнце под землёй слева снизу (sunGlyph с клипом); звезда `{slot, h, u, cyc, win, mask, lvl}`: `h` — высота (fp = 0.7·(520/0.7)^h, выше 27.5 Гц с ладом — ступени), `u` — по своду (−1…1, формант 140…4800 Гц, ± `dr` от drift); `toSky`/`fromSky`; `LIMEN` — где 20 Гц. Жесты: тап по небу — `addStar` (прокол), тап по звезде — `closeStar`, тянешь — h и u, держишь — `starSheet`. Рисование: `wall()` (Эмпирей, свод с делениями, звёзды, limen, rhythmus/tonus, земля), `drawStar` (вспышка по `flash` при fp < 18, луч — форма пульсарета). FX: scintilla, drift, cometa, spread, hall. Комета (`fx.cometa`, 0 — нет): `cometTick` — раз в 4…24 с пролёт от края свода вниз (`comet {a, b, t0, dur}`), звезда ближе 90 px — множитель пульсации `s.cm` до 2^(2·cometa) (в `fpOf`), `drawComet`. Плашка звезды: pulse (h), formant (u), cycles, window, mask, level, «~» — random. `t2d.firm` (stars, fx, geo, fp, ff, LIMEN, at(h, u), counts, gains, ready). Сценарий `shot.py firmamentum`.
