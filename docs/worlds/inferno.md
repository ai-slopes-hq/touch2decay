# V · Inferno

**Inferno (мир V, `worlds/inferno/`: `model.js`, `engine.js`, `view.js`, `index.js`; worklet нет — обычные узлы Web Audio).**

- **`model.js`** — `createModel({ scale {on, snap, pcs}, rng })`. Состояние `state {circ, fx, iceE, stormSemi, stormPh, time}`: круг `circ[k] {pos, sinner, held, color, width, drive, level, lvl}` (узлов в нём нет — они в engine). Высота: `semiOf(k, pos)` = (8−k)·60/9 + pos·60/9 полутонов от 55 Гц (с ладом — `scale.snap`), `hzOf(k)` (у k = 1 плюс буря `stormSemi`); `ratios(k)` — три полосы резонатора (harmonic 1·2·3, scale — ступени лада из `scale.pcs`, metal 1·2.76·5.4), `Qof(c)` = (4 + (1−width)·60)·(1 + iceE·8), `structName`, `burning(k)` (грешник или `held` > 0), `sounding`. Действия: `strike(k, vel)` (уровень `lvl` = 1), `setPos`, `hold(k, ±1)` (сколько пальцев держат круг), `pin(k, pos)` — грешник, до `PIN_MAX` = 4, ещё раз — отпустить, `setCirc(k, key, v)` (строки плашки; color — номер шума), `setFx`, `loadFx`, `clear`, `dice` (2–3 грешника, structure из трёх, `rng`), `snapshot`/`restore` (тот же JSON, что был). `tick(dt)` (секунды; склейка отдаёт `dt` хоста, обрезанный до 0.05 с, как было): спад/подъём `lvl` (τ 0.08 вверх, 0.4 + iceE·3 вниз), иней `iceE` (τ 6 с вверх / 3 с вниз; сдвиг > 0.02 — событие `ice`), буря второго круга (пока `burning(1)` и `fx.storm` > 0.01: `stormSemi` = storm·(5.8·sin + 2·sin) — до ±7.8·storm полутонов, событие `tune` для k = 1 не чаще раза в 0.05 с модельного времени; иначе затухает ×0.9 за кадр). События: `strike {k, vel}`, `burn {k}` (тлеть или погаснуть — по `burning(k)`), `tune {k}`, `color {k}`, `ice`, `fx`.
- **`engine.js`** — `createEngine(T, model)` → `{build, on, listen, strikes, live, bus}`. Шумы в буферах один раз (`noiseBufs`: white, pink, brown, crackle, grain + `burst` для удара; DSP на `Math.random`); резонатор круга по требованию `circleNodes(k)` (узлы — в своём массиве `N[k]`, `build` его сбрасывает) — `exc` → 3 bandpass (подъём √Q) → tanh `curve(1 + drive·6)` → lowpass по глубине → `vca` → `bus.inp`; `retune(k)` — частоты, Q и `vca` по модели; удар `strike` (буфер в `exc`, счётчик `strikes`, слушателям — `{strike: k}`), тление `smoulder` (петля шума своего цвета), `recolor`; шина: `pre` → fire (tanh) → `out` ×3 → выход, smoke → lowpass 1400 → `T.hall()`; `applyFx` перенастраивает все круги; `setLive` — через 8 с тишины. `on(e)` — событие модели → узлы (`ice` — `retune` всех девяти).
- **`view.js`** — `geo(T)`: девять эллипсов `rings[k] {cy, rx, ry}` (сверху вниз, шаг `dy`), Коцит `coc`, тьма `dark` (угол — `corner.hit`); `circleAt` (полоса ±dy/2), `posAt` — место на круге → `pos`. Жесты: тап — удар, >160 мс — тлеет (`hold(now)` — до шага модели), вдоль — высота, вертикально сквозь круги — арфа (`t.harp`), двойной тап — грешник, долгое касание круга с грешником — плашка `circleSheet` (pitch, noise, width, drive, level; «~» — LFO строк хоста, id `inf-c<k>`, ключи pos, width, drive, level). Рисование: `wall()` (штриховка мимо тьмы, стенки), надпись `drawInscription` (по уровню), дым, круги (горящие — уголь, пламя `flames` по `lvl`), порывы бури на втором круге, иней по `iceE`, трещины на Коците, грешник `sinner` там, где круг звучит, подписи — пока трогаешь. Только картинка (во view): вращение `rot[k]` (засечки на передней половине эллипса, скорость по `lvl`), угольки `sparks` (удар — 10 из `heard`, горение — по `lvl`, до 160). FX-веер (structure, fire, smoke, ice, storm; LFO — classic), легенда.
- **`index.js`** — склейка: `model.listen(engine.on)`, `engine.listen(view.heard)`, `tick(now, dt)` — `view.hold` → `model.tick(dt)` → `view.tick` (вращение, угольки), `T.registerWorld(5, …)`, `window.t2d.inf` (circ, fx, geo, at(k, pos), strikes, live, ice, storm, sparks, setFx, bus, model).

Тона Шепарда (падение) нет — убран по просьбе автора (выбивался), идея на потом — в ROADMAP. Свои LFO кругов (`circ[k].lfo`) заменены LFO строк хоста (плашка круга). Тесты модели — `tools/models/inferno.test.mjs`; сценарий `shot.py inferno`.
