# V · Inferno

**Inferno (мир V, `inferno.js`):** воронка `geo()` — девять эллипсов `rings[k] {cy, rx, ry}` (сверху вниз, шаг `dy`), Коцит `coc`, тьма `dark` (угол — `corner.hit`); `circleAt` (полоса ±dy/2), `posAt` — место на круге → высота: `semiOf(k, pos)` = (8−k)·60/9 + pos·60/9 полутонов от 55 Гц (с ладом — `T.snapSemi`). Состояние круга `circ[k] {pos, sinner, held, color, width, drive, level, lvl, n}`. Звук: шумы в буферах один раз (`noiseBufs`: white, pink, brown, crackle, grain + `burst` для удара); резонатор круга по требованию `circleNodes(k)` — `exc` → 3 bandpass (`ratios(k)`: harmonic 1·2·3, scale — ступени лада, metal 1·2.76·5.4; Q `Qof` = (4 + (1−width)·60)·(1 + ice·8), подъём √Q) → tanh `curve(1 + drive·6)` → lowpass по глубине → `vca` → `bus.inp`; удар `strike` (буфер в `exc`), тление `smoulder` (петля шума своего цвета; `held` — сколько пальцев, грешник — всегда); шина: `pre` → fire (tanh) → `out` ×3 → выход, smoke → lowpass 1400 → `T.hall`; тона Шепарда (падение) нет — убран по просьбе автора (выбивался), идея на потом — в ROADMAP; `setLive` — через 8 с тишины. Жесты: тап — удар, >160 мс — тлеет, вдоль — высота, вертикально сквозь круги — арфа (`t.harp`), двойной тап — грешник (до 4), долгое касание круга с грешником — плашка `circleSheet` (noise, width, drive, level). Рисование: `wall()` (штриховка мимо тьмы, стенки), надпись `drawInscription` (по уровню), дым, тени падения, круги (горящие — уголь, пламя `flames` по `lvl`), иней по ice, грешник `sinner` там, где круг звучит, подписи — пока трогаешь. FX: structure, fire, smoke, ice — ice растёт постепенно (`iceE`, τ 6 с вверх / 3 с вниз, `Qof` и спад `lvl` берут `iceE`, пересчёт резонаторов при сдвиге > 0.02), трещины на Коците. Вращение `rot[k]` (засечки на передней половине эллипса, скорость по `lvl`), угольки `sparks`/`spark(k, n)` (удар — 10, горение — по `lvl`, до 160). LFO круга `circ[k].lfo {rate, depth, shape, to, ph, v, sh}` (плашка круга; `lfoHz` 0.05–12 Гц, `SHAPES` sine/triangle/square/random, `LFO_TO` pitch — `lfoSemi` ±7·depth в `hzOf`, level — `lvlOf` тремоло; в `tick` — `lfoApply(k)` только частоты полос и vca). Буря второго круга (fx.storm, 0 — выкл, ±6·storm полутонов): пока `burning(1)`, `stormSemi` качает высоту (в `hzOf` для k = 1, `retune(1)` раз в 50 мс), порывы на круге. `t2d.inf` (circ, fx, geo, at(k, pos), strikes, live, ice, storm, sparks). Сценарий `shot.py inferno`.
