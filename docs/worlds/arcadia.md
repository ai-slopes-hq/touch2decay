# XII · Arcadia

**Arcadia (мир XII, `arcadia.js` + `terrain-worklet.js`):** синтез по рельефу (wave terrain). Страна — `genLand(seed)` (зерно → `rng`): горные цепи (гауссианы вдоль изогнутой линии), холмы (гуще к нам), пологие складки `waves`, озёра — неровные котловины, вода до уровня берега (`lake` — маска, `z` в озере ровный), реки — спуск по склону с излучинами (застряла — пруд), русло прорезано; нормировка в −1…1; вершины `peaks`, имена из Аркадии (`MONTES`, `LACUS`, `FLUMINA`). Сетка `GX × GY` = 80 × 160, страна вглубь в `ASP` = 3.2 раза длиннее (расстояния — `dist`, уклон — `gradOf`). Worklet: сетка приходит сообщением `terrain {z, lake, gx, gy, asp}` (новая — перетекает за 0.5 с), высота — Catmull — Rom 4 × 4 (`cub`), за краем — зеркало (`reflect`), над озером — рябь от wind; до `VMAX` = 4 голосов `{f, hx, hy (дом), r, fig, mode, sp, route}`: петля (круг / восьмёрка / узел 2 : 3, по вертикали делится на asp) со звуковой частотой, высота → `sin(1.57·(1 + 3·relief)·z)`, DC-блок, ровная громкость (AGC до ×4), срез ~6 кГц, tanh; центр петли идёт к цели `target` (still, circuit — круг `sp`, wander — две синусоиды, river / summit — туда-обратно по ломаной `route`), скорость — `speed` (fx.pace: 0.01·40^pace Гц); обратно `p {c: [cx, cy, r], g}` ~30/с. Мир: псевдоперспектива как в Natura — `proj(u, v)` (v = −1 у нижней рамки, 1 — горизонт; сила `K` = 2.4, ширина не сходится), земля поднята холмами `lift` → `at`; касание — `pick` (луч от нас вглубь до первой земли выше пальца); нота — `depthOf(v)` (ровно по высоте экрана, 24 полутона от A2, с ладом — ступени), деления по левой рамке. Странник `{slot, u, v, oct, r, fig, mode, sp, lvl, route, trail}`: тап по земле — новый, по флажку — уходит, тянешь флажок — дом, край петли (`rimAt`, `loopPts`) — радиус, держишь — `tSheet` (octave, orbit, figure, path, range, level; «~» random на orbit, range, level). Рисование: `wall()` — бумага с крапом, облака, дальние хребты, борозды, озёра (штриховка по экрану, берег — изолиния маски по мелкой экранной сетке), реки, ряды значков рельефа от горизонта (`mountain` — штриховка и снег, `hill`, `tree` — ель/лиственное в лесах по шуму `forest`, редкая трава), имена без наложений, рамка Таро, подпись ARCADIA; `drawT` — путь пунктиром, привязь, петля поднятая холмами (её горбы — слышимая волна) и её тень, бегущий сканер, флажок, подписи при касании. FX: relief, pace, wind, chorus (две задержки 13/19 мс, плывут 0.27/0.19 Гц, по сторонам), phaser (шесть allpass, LFO 0.11 Гц) — оба отцеплены в нуле, hall. Шина: worklet → pre → [фейзер] → mix → сухо + [хорус] → out; зал — от mix. Кубик — новая страна + 2–3 странника. `t2d.arc` (travellers, land, at, ground, loop(i), centers, gains, hz, newLand, routeOf). Сценарий `shot.py arcadia`.
