# IX · Horologium (Nova)

**Horologium (мир IX, `horologium.js` + `horo-worklet.js`, с v148):** волшебные числа — Rhythmicon. Прежний West Coast (шестерни, LPG; автор: «тембры не Буклы, а обычного FM») заменён целиком — он в истории git до v147.

**Worklet** (`horo`): колесо `P` (обороты), скорость `F` (сглаживание 60 мс; `{t:'set', F}`), спуск руками `{t:'step', d}` — доворот на d за 40 мс. Кольца `r[8]` {n 2…9, on, under, phi, lvl}: ударов за оборот `m` = n (обертон) или 12/n (унтертон), `mOf` — aequalis тянет m к ближайшему полутону. Удар — когда `floor(P·m + phi)` сменился (и `chance`): concursus — совпал с ударом другого кольца или «раз» (окно 6 мс) → ×(1 + 1.2·conc), иначе ×(1 − 0.35·conc). Щелчок → двухполюсный резонатор на `m·max(B, Fe)` (B — 55 Гц × тоника лада; быстрее B — резонатор идёт за потоком), время спада `0.012·50^materia·√(220/f)`, нормировка `1 − exp(−1/(T·rate))` (часто — сумма не растёт); дерево — с шорохом. Выход ×(0.7 + 1.1(1 − mat))/√(1 + Fe/8) (быстро — тише), DC-блок, tanh. Наверх ~30/с `{t:'p', P, F, hits}`.

**Мир:** `rings`, `fx {aequalis, materia, concursus, chance, hall}`, `clock {run, u, bpm}` — u: октав быстрее темпа (`Ft` = bpm/240 — оборот = такт), `Fnow`. **Маятник** `pend {th, ph, spin, held}`: энергия e = (ω/ω0)²/2 + (1 − cos θ), ω0 = 2π·0.8, на темпе `ET` = 1 − cos 0.3; `uOfE` = 0.9·log2(e/ET) (−3…8), `eOfU`. Схватил (`down`: у груза или на круге, если крутится) — F = 0, θ за пальцем; проход через низ (смена знака θ у низа) — `step` 1/Z (Z = 4); отпустил (`release`): поймал у низа (|ω| < 0.3, |θ| < 0.45) — стоп, иначе run и u из энергии, e ≥ 1.95 — `spin`. `tickClock`: u > 0 — к нулю с τ 6 с, u < 0 — к нулю с τ 1.5 с; картинка: размах `acos(1 − e)`, частота качания Z·F/2, крутится — θ растёт, быстро — веер / расплыв. **Жесты:** кольцо (`ringAt`) — тап вкл/выкл, двойной (`DTAP_MS`) — унтертон, вдоль — фаза, держишь — `ringSheet`; ступица (r < r0 − 6) — тап пуск/стоп, держишь — `hubSheet` (темп, `T.tempoFrom(9)`). **Рисование:** `wall()` (обод, 96 делений, цифры I…XII снаружи обода (v149; было слово unitas), «раз», шкала tempus, ось), `drawRings` (метки этого оборота `marksOf` — у нецелых m ползут; вспышка по `ringHit` из worklet; быстро — все горят; число кольца — в просвете между метками внизу слева), `drawHand` (стрелка-солнце, быстро — диск; луч concursus; ступица), `ratioText` (отношение, имя из `NAMES`, rhythmus/tonus и ноты), шкала с limen (20 / среднее m) и бегунком F, `drawPendulum`. Эмблема на карте — три кольца IV, V, VI. `t2d.horo` (rings, fx, clock, pend, geo, F, P, strikes, handSteps, ring(i, a), bob(), hub(), run(on, u), ratio()). Сценарий `shot.py horologium`.
