# XVII · Prisma (DLC vol. I)

**Prisma (мир XVII, `prisma.js`, без worklet):** аддитивный синтез, опыт Ньютона. Тема — `INK 226,226,236`, `BGC #07080d`.

- **Звук:** 16 `OscillatorNode` (синус) → gain → `StereoPanner` → `bus.master` → pre → hall. Гармоника k: `fk = f0·(k+1)^(1 + 0.14·stretch)`, `f0 = 55·2^(semi/12)` (с ладом — `snapSemi(semi + 24) − 24`). Громкости `amps()`: окно по октавам вокруг `center = (rot + 1)·2` (0…4 октавы), ширина `0.25 + 1.6·width`, наклон 1/√(k+1), заслонки `blocked[k]`, `impar` гасит чётные, выше 16 кГц — 0; нормировка по сумме квадратов. `scintilla` — каждые 70 мс множитель `shimmer[k]` случайно приседает. Осцилляторы создаются, когда открыт свет (`lightOn`), и останавливаются через 9 с темноты (`stopOsc`, `setLive`).
- **Сцена `geo()`:** снаружи слева полоса неба с солнцем (`sun`, угол — карта, `mapShot`), ставень `wallX` со шкалой полутонов (−12…24), отверстие `holeY` — высота; призма `px, py, ps`, поворот на картинке `rot·0.35`; стена `screenX`. Лучи `rays()` — веер из призмы, наклон `rot`, раскрытие растёт со `stretch`; яркость луча и пятно на стене — громкость гармоники (`gainsNow`).
- **Жесты:** отверстие — тап: свет вкл/выкл; вверх-вниз — semi; держишь — плашка *foramen* (pitch, width, level). Призма — вбок `rot`, вверх-вниз `stretch` (ось по первому движению); держишь — плашка *prisma* (colour, stretch, width). Тап по лучу (правее призмы) — заслонка.
- **FX:** scintilla, impar, spread (чётные/нечётные гармоники в разные стороны, шире кверху), hall. Кубик — высота, поворот, иногда растяжка, ~20 % заслонок, свет. Корзина — темно и без заслонок.
- `t2d.prisma` (st, blocked, fx, geo, rays, amps, f0, fk, gains, osc). Сценарий `shot.py prisma`.
