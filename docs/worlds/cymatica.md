# II · Cymatica (`cymatica.js` + `plate-worklet.js`)

**Cymatica:** звук — `plate-worklet.js` (AudioWorklet; чистые функции `besselJ`, `MODES`, `modeRatios`, `strikeGains`, `t60s`, `resCoefs`, `pickVoice`, `shapeGrid` на верхнем уровне, процессор `plate` внизу). Сообщения в worklet: `params`, `f0`, `strike`, `bow`; из worklet: `energy` ~30/с и один раз `shapes` (сетка 96×96 форм мод для песка). `cymatica.js`: очередь сообщений до готовности узла, жесты (удар, смычок > 150 мс, двойной тап — закреплённый смычок, кольцо на метке, щипок/колесо — `pinchTo`/`stepScale` → `setF0`: линейно 12 px на полутон, с ладом 18 px на ступень; размер на экране — `shownF0`, плавно за `plate.f0`, τ 80 мс). Эхо — доля темпа `ECHO_DIVS` по лучу `time` (`echoSec`, фидбек `echoFb` растёт с echo, линии до 3 с; `t2d.cym.echo`). Время задержки никогда не плавно меняется (скрежет): `retime` заводит новую пару линий `echoPair`, старая дозванивает до 6 с, не больше 4 пар, не чаще 90 мс (`echoChains`). Ступени луча с подписями — `marks` у сектора (рисует `drawRing`). Тела `TUNINGS` в worklet (8 по лучу structure: string, membrane, plate, bell, bowl, handpan, marimba, kalimba; по умолчанию plate = 2/7), веер FX, отмена. LFO у смычков пока нет. **Смычки выключены** флагом `BOWS_ON = false` в `cymatica.js` (автор: апплет о полиритмах и модах); код и тесты смычков на месте, тесты в `shot.py` включаются по `t2d.cym.bowsOn`. **Секвенсер:** часы — в worklet (`stepSamples`, `setSeq`, `tick`; удар секвенсера пропускается, если живой удар был меньше полшага назад), сообщения `seq` (узор целиком) и `step { r, m, time }`; в `cymatica.js` — **две последовательности своей длины (полиритм)**: `seq.rhythm { len, steps: {vel} }` — удары, `seq.melody { len, steps: {x, y} }` — места на пластине; удар шага бьёт в место текущего шага мелодии, **нота — клетка пластины под местом**, пустое место — пауза (раскладка ханга: `n = degPerOct()` секторов от верха по часовой, 3 кольца-октавы равной площади, база — ступень пластины `nearestIdx(noteList(), fs())`; `noteList` — 0…60 полутонов, 55–1760 Гц). `notesOf` считает ноты, `sendSeq` шлёт в worklet `rhythm {vel}` и `melody {s, x, y}` (место в молчащей клетке — пустым; worklet берёт точку удара из шага мелодии), `sentSeq` — для тестов, `t2d.cym.notes` — ноты мест. Пустое второе кольцо заполняется (`fillMelody` при тапе по удару, `fillRhythm` при пошаговом вводе). Запись игрой: удар — в шаг ритма по сетке, место — в шаг мелодии того же мига (`recordHit`). Кубик: мелодия длины, не делящей ритм. Помощники `euclid`, `nearestStep`, `walkMelody`, `rotateSteps`, `twistOrPinch`, `cellIdx`, `noteAt`, `cellOf`, `cellCenter`, `transposeHits` (`t2d.cym.core`, тесты — `tools/test-seq.mjs`). Вращение — `startTwo`/`moveTwo`/`twistTo` (два пальца) и `f.twist1` (Shift-мышь): каждое кольцо крутится само, пластина — `transposeHits` по местам мелодии. Бусина (`mtick`) двигает место в клетку на ступени (6 px), метка места — тащится. Пошаговый ввод — `cursor` (null, пока не тапнули гнездо мелодии; `drawCursor`). Клетки — `drawCells` (сетка 0.25, подписи при `showNotes`; гейт — `litCells`: клетка горит по уровню голоса из `energy.voices`, `glowOf` −50…−10 дБ; `t2d.cym.lit`). **Песка нет** (убран: на ханге он лишний; worklet ещё шлёт `shapes` — не используется). Радиус пластины — `r ∝ f^−1/4` (мягче физики, чтобы клетки были под палец). Клавиш лада больше нет. Тоника и классы высот лада — `T2D.scaleRoot`, `T2D.scalePCs`. Цель вращения — `twistTarget` по среднему расстоянию пальцев: стол — пластина, дальше — кольца; кольца видно идут за пальцами (`ringTurn`). Выход Cymatica ×2.5 (+8 дБ). **Шанс** — `st.chance` у удара (тянуть удар на кольце к центру/наружу, `rtick` + `chanceEdit`), общий `plate.fx.chance` (луч в веере); worklet решает в `tick` (`hit` в сообщении `step`). **Запись по шагам** — `stepRec {r, m}` (● на стоящих часах, `stepRecToggle`; тап мимо — пауза). **Луна** `drift {on, depth, rate, shape, k}` — кнопка `driftX` (луна на орбите: ширина — depth, место — `drift.k`; под кнопками ▶ ● сетка луна — тихие подписи bpm · per gradus/scribe · grid · luna ±N), держишь — плашка `openDrift` → `T2D.openSheet(spec)` (общая плашка хоста, как FX; строки `DRIFT_SECTORS`), `driftTick` (sine / random по `DRIFT_RATES` от темпа), высота с луной — `effF0()` (её шлём в worklet, по ней `fs()` и размер). **Созвездия** — `stars`/`starPush`/`drawStars`. **Резонатор отзывается** — `answer(semi)` (класс высоты = основной тон пластины: гул и подпись на шаре). Сетка записи `grid` (1/2/4 гнезда, `snapToGrid`), «причесать» — `quantizeRhythm` (зажатая кнопка сетки); кнопки ▶ ● сетка — `astro(g).playX/recX/gridX`. Сценарии: `handpan`, `entry`. Фон — `wavesLayer()` (кеш, пересборка при сдвиге высоты на полутон). Кольца: ноты — бусины на R1 (`rMax + 22`), удары — на R2 (`rMax + 48`), граница зон `RM`; длина кольца (у каждого своя) — заливка по нему, край тянется (`astroHit` → `len`, по углу ±0.3 гнезда); мигание играющего шага — `pulse` (по сообщению `step`), вспышка записи — `born` (в `sendSeq`), накопленный поворот шкалы — `ringOrn`.
