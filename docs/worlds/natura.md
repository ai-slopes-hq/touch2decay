# IV · Natura (`worlds/natura/`)

## Ядро SDK (этап 1, v185, 25.10) — звук и часы в `core/worlds/natura` → `t2d.wasm` (слот 4)

Звук и часы шагов переехали в C++; **модель пока в вебе** (`model.js` без изменений, этап 2 перенесёт и её): веб шлёт ядру состояние целиком — действие `STATE` `[bpm, len, fx×9, 16 × (занято, note, wave, glide, chance, cutoff, res, att, rel)]` при каждом изменении (`stateArgs` в `engine.js`, опрос раз в кадр из `tick` мира и перед событиями, так что правки консолью, плашками и LFO доходят сами), плюс события: `PLAY`, `HEAR i`, `SHAKE v`, `SKIFF q t wave` / `SKIFF_OFF`, `WAVE`, `CROAK note`, `LASER`, `SCARE` (по смене `state.goneAt`). Ядро: `model.cpp` (шаг, голос ноты, `noteHz`/`skiffHz` по ладу хоста, `delaySec`), `wave.hpp` (пять волн), `world.cpp` (пулы: ноты 32 — самый старый уступает, кораблики 4, лягушки 4, лазеры 3; шина hp дерева → хор `sdk::Chorus` (моно) → пред → лента `sdk::TapeEcho` (время плывёт τ 0.15 с, `glideTo`) → ×1.2; посыл в общий зал (hall) `(пред + эхо) · reverb² · 1.3 · 1.2`; шелест листвы; шаги — `sdk::Steps` по часам хоста, свой темп или сетка MIDI-часов, с точностью до сэмпла; шанс — `sdk::Rng` от зерна мира). «Услышано» из ядра — пары `[2, место]` (нота ударила → утки) и `[1, место]` (шаг сыгран → лягушка, стрекозы); зеркало `[бегунок (шагов с начала), играет, голосов, кораблик держится]`, `engine.phase()` додумывает между зеркалами (≤ 1 шага). Прежний движок на узлах Web Audio — эталон `tools/ref/natura-engine.js` (+ `natura-model.js`).

**Волны — настоящие band-limited, не копии `PeriodicWave` браузера** (решение автора А1): sine / triangle — `sdk::Osc`, saw — `sdk::Saw` (BLEP), square — две пилы со сдвигом ½, sharp — таблица `tanh(2.6·tri + 0.35)` на октаву (2048 точек, кубическая интерполяция, без постоянной, пик 1 по ряду из 47 гармоник — как нормирует браузер). Громкость, подобранная автором на слух: saw и square — ×0.848/0.849 (пик браузерной волны 1 ниже идеальной ±1), остальные ×1.
**Фильтры — k-rate, раз в блок** (как `BiquadFilterNode` Chromium; фильтр с поминутно-сэмпловыми коэффициентами для чистой синусоиды давал другую «юбку» атаки).
Новое в SDK: `Chorus` с режимом «моно» (решение В1), `TapeEcho::glideTo` (время «лентой»), `sdk::Glide` в `smooth.hpp` (setTargetAtTime по сэмплам; Portus перешёл на него без изменений звука).
