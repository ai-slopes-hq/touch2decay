# IV · Natura (`natura.js`)

IV · Natura (`natura.js`, **звучит**: нота `playNote` — sine/square/triangle → lowpass с огибающей (cutoff, env) → хор (chorus) → лента-задержка (delay, time — доля темпа `DIVS`) и `hall` (reverb); часы — `schedule` по `ctx.currentTime` (таймер 25 мс, окно 120 мс), `seq {playing, bpm, next, step}`, бегунок на экране — `phase()`; ноты — ступени лада `noteHz` (без лада — ля минор от A2); жесты: тап по воде — кувшинка, по кувшинке — убрать, поперёк — нота, вдоль — шаг, держишь (`tick`, `T.HOLD_MS`) — кольцо кувшинки; запруда (колья поперёк, `drawBridge`) — длина; причал у истока `pierXY` — пуск/стоп и темп; запасной кораблик `skiff` (лежит у `skiffHome`, голос `skiffSound` — волна `lastWave`, высота `skiffHz`: с ладом по ступеням, без — плавно; ярче вниз по течению; след `trail`, отпустил — `back` к берегу); глайд — `pd.glide` (провести по воде `t.path` через кувшинки, `drawGlides`, частота скользит из `prevHz` за 0.8 шага); дерево — `shake` (скорость пальца, затихает τ 1.4 с) → `bus.hp` 20 Гц…10 кГц + шелест `shakeTick`; птицы — `birdList`, тап — `laser()` (меандр 2.4 кГц→70 Гц сквозь lowpass Q 22) и вспархивают (`birdsAt`); фильтр и огибающая — в сцене, не в веере (веер: reverb, delay, time, chorus): туча `cloudAt` вверх-вниз — `cutoff`, горы (полоса у горизонта) вверх — `res` (Q фильтра, кеш земли по `res`), две утки в заводи `pondAt`/`ducksAt`/`duck`/`drawDucks` (мельницу автор забраковал) — левая `att`, правая `rel`, вверх — больше и длиннее (размер = значение), `attSec`/`relSec`/`envAt`; на ноте левая ныряет (по attack), от правой круги (по release) — по последней ноте `noteAt`/`notePd`; кораблик, брошенный в заводь (скорость пальца > 0.35 px/мс, луч попадает в эллипс, или отпущен над ней), — `skiff.fly` → `splash`, `ducksGone` (`GONE`: улетают 0.7 с, вдали до 3 с, возвращаются за 1 с; `flyer`), пока их нет — `envOpen()`: attack 0, release 1; конфетки: лягушка `frog`/`frogPos`/`drawFrog`/`croak` (касание лягушки — касание её кувшинки `t.frog`: тап квакает, потянул — едет; по `playedAt` — когда кувшинка звучала: сидит на самой молчаливой, её заиграла — прыжок), рыба `drawFish` на шаге 0 петли, стрекозы `flies`/`drawFlies` (chorus), утята `ducklings` (rel), отражения в заводи (`globalAlpha`, клип по эллипсу), солнце садится по темпу `sunAt` (и `corner.hit`); пять волн `WAVES` (sine, square, triangle, saw, sharp — `setWave`, sharp — `PeriodicWave` из tanh(2.6·tri + 0.35)), громкости `LVL`; меню волн `menu`/`menuOpts`/`drawMenu`/`pickWave` — только у кораблика на берегу (держишь), тот же палец на цветок или тап потом; **плашка кувшинки** `lilySheet(i)` через `T2D.openSheet` (строки `LILY_ROWS`: wave · cutoff · res · attack · release · chance; общее значение — в скобках; двойной тап по строке — `reset`, хост: `lastFxTap`), старое кольцо (`RING`, `drawLilyRing`) не открывается; свои значения — `pd.lock {cutoff, res, att, rel}`, `pd.chance`, значение шага — `val(pd, k)`; пейзаж (туча, горы, утки) — только общие `fx` (второй палец больше не пишет в кувшинку); шанс — `pd.chance × fx.chance` в `schedule`, луч chance и в веере; кувшинки крупнее (`LILY`), попадание — ближайшая `padAt`; двойной обвод — есть свои значения; пунктир — шанс < 100 %; кубик раскидывает и сцену, и свои значения; камыши больше не cutoff; сценарий `shot.py natura`; карта Таро чёрным по сепии, секвенсер — река `river(G, t)` (квадратичная кривая `G.P`: от гор вниз и вправо; у точки — нормаль `nx, ny`, «поперёк» — `across(r, q)`, обратно — `onRiver`) с кувшинками `pads` (место по течению `slotT` — шаг, поперёк — нота, цветок — голос, `padXY`), лист-лодочка — бегунок, запруда (колья поперёк, `drawBridge`) — длина; древо с тучей на правом берегу (дождь гуще — time, облака вокруг — delay), птицы — chorus, горы `ridge` (res), туча (cutoff), утки (A/R), солнце четвертью слева сверху — тап — карта, надгробие в левом нижнем углу пока без действия; `t2d.nat`).
