# VII · Monochordum

**Monochordum (мир VII, `worlds/monochord/` + `monochord-worklet.js`; раскладка model / engine / view — см. `CLAUDE.md`):** `model.js` — струны `str`, ветер (`state.wind`, `lastWind`), `auto`, fx, `snapR`, `hzOf`, кубик, снимок; автострам — чистые `autoStep(step)` (какие струны, сила, промежуток; chance) и `stepDur(step)` (swing); энергию из worklet пишет `meter`; `engine.js` — шина, дека, хор, зал, worklet, `setLive`, часы автострама (`clock`, `autoSchedule` по `ctx.currentTime`, запас 200 мс, удар → `listen` `{hit}`); `view.js` — `geo`, `yOfR`/`rOfY`, `stringAt`, `earthG`, касания, плашки `stringSheet`/`windSheet`/`earthSheet`, `wall`, `drawHand`/`drawAeolus`/`drawEarth` (поворот Земли `rot` и вспышка `hitAt` — здесь); `index.js` — склейка, `tempo`, `t2d.mono` (+ `model`). Тесты модели — `node --test tools/models/monochord.test.mjs`. Звук — Карплус — Стронг в AudioWorklet (4 струны, `BUF` 4096, дробная длина, однополюсный lowpass — яркость, потеря за проход — t60; сообщения `tune {i, f, bright, decay, level}`, `pluck {i, pos, vel}`, `bow {i, amp}`, `sus {i, on}`, `wind {amt}`; обратно `energy` ~30/с; всё молчит — `process` не считает). Модуль грузится при входе в мир (`start`, как у Cymatica). Шина: струны → сухо + дека (3 bandpass, `body`) → `mix` → выход и `T.hall`. Струна `str[i] {r, sus, bright, decay, level, en, bow}`, `r` — доля звучащей длины 1…1/4, `hzOf(i)` = `F_OPEN[i]`·тоника / r; подставка `yOfR`/`rOfY`, `snapR` — к `MARKS` (пифагоровы лады Фладда) или к ступеням лада. `geo()`: колки `y0`, порожек `y1`, струны `xs`, ящик `box`, облако `hand` (справа над дугами; `corner.hit` — карта). Фон — `wall()` (лады, сферы, дуги `INTERVALS`, розетка, Земля). Жесты: подставка ±20 px — высота; выше подставки тап — щипок, туда-сюда у струны — смычок (скорость); пересёк соседнюю струну — страм `strum(t, f, G)` (касание `kind: 'strum'` или `t.strum`, смычок снят; щипок каждой пересечённой выше её подставки, сила — скорость), страм можно начать мимо струн; смычок включается только после `BOW_WAIT` 150 мс у струны или при развороте пальца (`t.bowing`, `t.dir`) — быстрый уход к соседней струне не скрипит, двойной тап — `sus`, держишь — `stringSheet`. Ветер — часть патча, не FX: `wind` (`setWind`, в снимке, корзина — 0), роза ветров `geo().aeolus` слева над Эмпиреем — `drawAeolus` (крутится с ветром, `roseA`) (вверх — сильнее, тап — 0 / `lastWind`). Симпатический резонанс — в worklet: струны считаются сэмпл за сэмплом вместе, общая подставка `bridge` = Σy, каждая берёт `cpl·(bridge − свой y)` и отдаёт `own = 1 − 3cpl` (устойчиво: сумма строки < 1), `cpl` = 0.0015·sympathy (`couple`). Флажолет — своя короткая петля `s.h` (`harm {i, n, vel}`: длина /n, t60·0.8), энергия `h` и `n` идут с `energy`; на струне узлы `NODES` (тап ±7 px — `harm`), волна с n пучностями. Звёздочка у сферы `MARKS` под подставкой — по энергии. Автострам — Земля внизу (`earthG`, `drawEarth`, `auto {on, bpm, div, pattern, strength, swing}`, `autoSchedule` (будит `T.onTick` — таймер 25 мс и метроном `clock-worklet.js`, иначе в фоне iOS шаги пропадают) → `strumAt`: щипки с `at` — worklet кладёт их в `pend` и играет в свой блок; тап — `setAuto`, держишь — `earthSheet`; `tempo.set`, `T.tempoFrom(7)`; корзина — стоп). Плашка струны: строка `pitch` (r без прилипания, «~» — вибрато); держишь розу — `windSheet` (random LFO — порывы). FX: decay, bright, body, sympathy, chorus (`chorusNodes` — по требованию, две задержки 12/19 мс с LFO, отцеплены от `mix`, пока chorus 0), hall. Шина: `mix` → `post` (сухо + хор) → выход и зал. `t2d.mono` (str, fx, geo, at(i, r), hz, ready, live, setFx, setWind, wind, chorus). Сценарий `shot.py monochord`.

**chance** (v142): FX `fx.chance` — вероятность каждого шага автострама (`autoStep` в модели).

**Ведомый по MIDI** (`host/midi.js`): автострам идёт по сетке MIDI-часов (доли, деления, swing); сам он по Start не запускается (`tempo.armed` — всегда `false`), а включённый — следует за часами и темпом. Тесты — `tools/test-follow.mjs`, `tools/models/monochord.test.mjs`.
