# VII · Monochordum

**Monochordum (мир VII, `worlds/monochord/`; с SDK D1 (v174) — мир SDK: модель, струны, дека, хор и автострам — в ядре `core/worlds/monochord` → `t2d.wasm`, слот 7; раскладка model / engine / view — см. `CLAUDE.md`):** `model.js` — фасад модели ядра (прежний API: струны `str`, ветер (`state.wind`, `lastWind`), `auto`, fx, `snapR`, `hzOf`, кубик, снимок; действия — сразу в state и в ядро, зеркало ~60/с; энергия струн `en`/`eh`/`hn` и шаг `state.step` — из зеркала; `autoStep`/`stepDur`/`swingAt` — тот же алгоритм для тестов, шаги ставит ядро); эталон прежней JS-модели — `tools/ref/monochord-model.js`; `engine.js` — тонкая склейка: сухой выход ядра в канал, `bind`/`sync`, удар автострама из «услышанного» ядра → `listen` `{hit}` (в блоке, где удар звучит); `view.js` — `geo`, `yOfR`/`rOfY`, `stringAt`, `earthG`, касания, плашки `stringSheet`/`windSheet`/`earthSheet`, `wall`, `drawHand`/`drawAeolus`/`drawEarth` (поворот Земли `rot` и вспышка `hitAt` — здесь); `index.js` — склейка, `tempo`, `t2d.mono` (+ `model`). Тесты модели — `node --test tools/models/monochord.test.mjs`. Звук — Карплус — Стронг в ядре (`core/worlds/monochord/sound.cpp` — порт прежнего worklet, на `sdk::KsLoop`; 4 струны, `BUF` 4096, дробная длина, однополюсный lowpass — яркость, потеря за проход — t60; сообщения `tune {i, f, bright, decay, level}`, `pluck {i, pos, vel}`, `bow {i, amp}`, `sus {i, on}`, `wind {amt}`; обратно `energy` ~30/с; всё молчит — `process` не считает). Ядро держит мир всегда (лениво больше не грузится): в тишине струны и шина не считаются (в тишине ядро не тяжелее v173). Шина: струны → сухо + дека (3 bandpass, `body`) → `mix` → выход и посыл в зал ядра (`T.send('hall')`, ×2.2 — прежний `out` после возврата). Струна `str[i] {r, sus, bright, decay, level, en, bow}`, `r` — доля звучащей длины 1…1/4, `hzOf(i)` = `F_OPEN[i]`·тоника / r; подставка `yOfR`/`rOfY`, `snapR` — к `MARKS` (пифагоровы лады Фладда) или к ступеням лада. `geo()`: колки `y0`, порожек `y1`, струны `xs`, ящик `box`, облако `hand` (справа над дугами; `corner.hit` — карта). Фон — `wall()` (лады, сферы, дуги `INTERVALS`, розетка, Земля). Жесты: подставка ±20 px — высота; выше подставки тап — щипок, туда-сюда у струны — смычок (скорость); пересёк соседнюю струну — страм `strum(t, f, G)` (касание `kind: 'strum'` или `t.strum`, смычок снят; щипок каждой пересечённой выше её подставки, сила — скорость), страм можно начать мимо струн; смычок включается только после `BOW_WAIT` 150 мс у струны или при развороте пальца (`t.bowing`, `t.dir`) — быстрый уход к соседней струне не скрипит, двойной тап — `sus`, держишь — `stringSheet`. Ветер — часть патча, не FX: `wind` (`setWind`, в снимке, корзина — 0), роза ветров `geo().aeolus` слева над Эмпиреем — `drawAeolus` (крутится с ветром, `roseA`) (вверх — сильнее, тап — 0 / `lastWind`). Симпатический резонанс — в worklet: струны считаются сэмпл за сэмплом вместе, общая подставка `bridge` = Σy, каждая берёт `cpl·(bridge − свой y)` и отдаёт `own = 1 − 3cpl` (устойчиво: сумма строки < 1), `cpl` = 0.0015·sympathy (`couple`). Флажолет — своя короткая петля `s.h` (`harm {i, n, vel}`: длина /n, t60·0.8), энергия `h` и `n` идут с `energy`; на струне узлы `NODES` (тап ±7 px — `harm`), волна с n пучностями. Звёздочка у сферы `MARKS` под подставкой — по энергии. Автострам — Земля внизу (`earthG`, `drawEarth`, `auto {on, bpm, div, pattern, strength, swing}`; шаги ставит ядро — `sdk::Steps` по часам хоста (свой темп или сетка MIDI), щипки шага — с точностью до сэмпла (раньше — таймер JS на 200 мс вперёд и начало блока worklet); тап — `setAuto`, держишь — `earthSheet`; `tempo.set`, `T.tempoFrom(7)`; корзина — стоп). Плашка струны: строка `pitch` (r без прилипания, «~» — вибрато); держишь розу — `windSheet` (random LFO — порывы). FX: decay, bright, body, sympathy, chorus (`sdk::Chorus`: две стерео-задержки 12/19 мс с LFO 0.31/0.47 Гц и StereoPanner ∓0.7; при chorus 0 вход хора отцеплен, хвост дозвучивает и засыпает), hall. Шина: `mix` → `post` (сухо + хор) → выход и посыл в зал ядра. `t2d.mono` (str, fx, geo, at(i, r), hz, ready, live, setFx, setWind, wind, chorus). Сценарий `shot.py monochord`.

**chance** (v142): FX `fx.chance` — вероятность каждого шага автострама (`autoStep` в модели).

**Ведомый по MIDI:** разбор часов и сетка — в ядре (`core/sdk/transport.hpp`, одна сетка на все миры), автострам идёт по ней в ядре (доли, деления, swing); кого запускать на Start — `host/midi.js` по событиям ядра. `tempo.armed` — всегда `false`: Start заводит автострам, только если его включали руками в этой сессии (или он играет / играл в момент прошлого Stop) — идущий начинает с доли 0, остановленный MIDI Stop возвращается на следующем Start. Тесты — `tools/test-mono-core.mjs` (струны против эталона бит в бит, автострам, сетка), `tools/test-transport.mjs`, `tools/models/monochord.test.mjs` (эталон и ядро), `tools/mono-bus.py` (шина против Web Audio), сценарии `shot.py monochord midi webmidi`.

## SDK D1 (23.10, v174, ветка `native`)

**Сделано:** мир целиком в ядре (модель, струны, дека, хор, посыл, автострам); новые блоки SDK — `KsLoop`, `Chorus`, `panEq` / `PanStereo`, транспорт (`ClockParser`, `Follower`, `Steps`); MIDI-часы для всех миров разбирает ядро. `Math.random` в струнах → `Rng` от зерна. Сверка: сухие струны против прежнего worklet — бит в бит; шина (дека, хор) против прежней Web Audio — RMS ± 0.0004 дБ; снимок — тот же JSON. Спека и план — `docs/superpowers/specs|plans/2026-10-23-sdk-d1*`.

**Решено автором:** D до AUv3; D1 — один Monochordum; разбор MIDI-часов — тоже в ядро. **Отвергнуто:** разведка AUv3 до переноса миров; две копии разбора часов (в JS и в ядре).

**Отличия от прежнего:** шаги автострама точны до сэмпла (было до 2.7 мс разброса); удар Земли вспыхивает в блоке, где звучит; кнопка ещё 50 мс не ждёт — первый шаг сразу. Темп с Web MIDI считается по отметкам времени в секундах контекста (сдвиг «контекст − performance» — наибольший за 5 с), в синтетическом сценарии `webmidi` гуляет ± 0.5 BPM (раньше — ровно 120).

**Осталось:** проверка автора на iPhone (звук, автострам в фоне, ведомый через оболочку).

## Натив (iOS, фаза 3, 30.10)

Код — `ios/app/T2D/Monochord/`: `MonoMirror.swift` (зеркало ядра, 52 числа), `MonoGeo.swift` (геометрия струн, земля, рука, Эол), `MonochordView.swift` (касания, легенда, тик), `MonoDraw.swift` (рисование), `MonoSheets.swift` (плашки струн, земли, ветра и веер FX). Звук — то же ядро слота 7. Значения читаются из зеркала, локальных переопределений нет. Все LFO — строки мира (`obj` −1): FX 0…6, ветер 7, strength 8, swing 9, строка k струны i — `10 + 4·i + k`; у строк земли tempo / rate / pattern LFO нет (код −1). Кубик (`DICE`) — действие ядра. Корзина (CLEAR) снимает только LFO ветра (`lfoOff`). Веер FX назван «aether» (как у всех миров; «chorda mundi» — подзаголовок мира). `tempoFrom` (темп другим мирам) не делаем. Смычок — как `view.js:129-133`: через 120 мс после касания затухает ×0.8 за кадр только струна, чей палец не сдвинулся; сдвинувшийся хоть раз палец смычок держит, даже остановившись, подъём пальца шлёт `BOW 0`. Известное ограничение хоста: LFO строк сопоставляются по `code` без проверки `lfo.keys`, поэтому строкам без LFO дан код −1. Сцены `-shot`: `monochord`, `monochord-sheet`, `monochord-earth-sheet`, `monochord-wind`, `monochord-fan` (веб-пара — `python3 tools/shot.py monochord`). На iPhone не проверено — ждёт iPhone.
