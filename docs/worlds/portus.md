# XIII · Portus

**Portus (мир XIII, `portus.js`):** dub techno на обычных узлах; фильтр, эхо и ревер — предметы сцены, не веер. **Одна дорожка, как в Natura** (автор: «одна дорожка на всех»; было — острова по очереди, по такту на остров, — отвергнуто). Сцена: `P(u, d)` (d = 0 у набережной, 1 — горизонт; `K` = 2.6; `kOf(d)` — 1 у нас … 0 на горизонте). 16 лучей от фонарей `lanternX(i)` (`colU(i)` × `colC(k)` — сходятся к устью); глубина — нота `p` 0…12, ровно по экрану (`dOfP`, `pOfY`); точка острова — `colPt(i, p)`, ближайший луч — `colAt`. Берега — воронка вокруг лучей (`edge(G, side, d)`, мелкие бухточки), скалы `cliffH`; маяк `G.ph` на краю набережной; луна `G.moon` в левом углу вместо солнца (`corner.hit` — всегда нет; тап по луне — `t2d.goMap()`). Кораблики (бумажные, по просьбе автора — не острова) `isles {step, p, oct, lvl, type (−1 — как у маяка), sd}`, по одному на луч (`isleOn`, `place`). Нота: нижняя тоника — `55·2^(r/12)`, при r ≥ 5 — октавой ниже (37…69 Гц), + p, с ладом — `snapSemi(a + 24) − 24`, + октава. Аккорд — `pharos.chord` или свой (`CHORDS`: 5, sus, m7, m9, m11). Часы — `schedule` (25 мс, запас 200 мс, шестнадцатые, swing на нечётных): на шаге j остров `isleOn(j)` → `stab(t, is, vel, gap)`: по две пилы на ноту → два lowpass с огибающей → vca, живёт до следующего удара (`nextGap`). Шина: drive → сухо; эхо пинг-понг (`DT` шестнадцатых, `fbOf()` = 0.15 + 0.84·buoy.d, до 0.985; петля: highpass, lowpass dark, tanh; wow на delayTime); `killEcho` (тап по небу выше тумана) — обратная связь, посыл и выход эха в ноль за ~20 мс, через 350 мс — обратно (`applyAll`), падающая звезда; ревер `T.hall()` (fog²·1.6, хвост 1.2 + size·8 с); море (fx.mare) подключается только при mare > 0. Жесты: море — `place` на луче (занят — переезжает), тянешь остров — луч (если свободен) и нота, тап — тонет; фонарь — остров на луче (глубина `lastP`) или убрать; маяк — пуск, вбок — темп (`T.tempoFrom(13)`); луна — вверх cutoff, вбок resonance; буй — поперёк время (между берегами), вдаль feedback; верх тумана — amount; без часов — `audition` (не чаще 140 мс); держишь — `sheets(kind)` (luna, echo, nebula, pharos: chord, length, swing, level; insula: chord, octave, level). Рисование: `wall()` — звёзды, волны, лучи фонарей, засечки полутонов у левого берега (ступени длиннее, тоника и октава — пунктир), берега (штриховка земли, скалы, урез, прибой, кипарисы), набережная; `drawMoon`, `drawIsle` — бумажный кораблик (корпус-трапеция, парус, сгибы, качается; звучащий — золотом; не шире луча), `drawBuoy` (круги повторов), `drawFog`, `drawPharos` (луч на остров `lastHit`), `drawQuay` (светящийся луч шага, фонари). FX: wow, mare, drive, spread. `t2d.portus` (isles, steps, col(i, p), lantern(i), sky(), kill(), killed, buoyAt, hz, name, fc, fb, play). Сценарий `shot.py portus`.
