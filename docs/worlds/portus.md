# XIII · Portus

**Portus (мир XIII, `portus.js`):** dub techno на обычных узлах; фильтр, эхо и ревер — предметы сцены, не веер. **Одна дорожка на 16 шагов, как в Natura** (автор: «одна дорожка на всех»; были острова по очереди по тактам, потом 16 лучей от фонарей — оба отвергнуты). Сцена: `P(u, d)` (d = 0 у набережной, 1 — горизонт; `K` = 2.6; `kOf(d)`; `dOfF(f)` — d по доле высоты экрана). Фарватер: места `fOf(i)` ровно по экрану, середина `laneC(f)`, полуширина `laneHW(f)`, точка `laneAt(f, a)` (a: −0.5…0.5 поперёк), кораблик — `slotPt(i, p)`, под пальцем — `slotAt` (место и нота, мимо — null), вехи — `markPt(i)` у левого края (`markAt`). Берега — мысы `edge(G, side, d)` (гауссианы), скалы `cliffH`; маяк `G.ph` на правом мысу; луна `G.moon` в левом углу вместо солнца (`corner.hit` — всегда нет; тап — `t2d.goMap()`). Кораблики `isles {step, p, oct, lvl, sd}`, по одному на место (`isleOn`, `place`). **Аккорд один — у маяка** (`pharos.chord`, `CHORDS`: 5, sus, m7, m9, m11; автор: «и у кораблей аккорд, и у маяка — не понимаю»), кораблик — только тоника: `110·2^((p + root, с ладом snapSemi) / 12 + pharos.oct + is.oct)`, октавы −2…+2 (автор: не транспонировать всё, а октава в настройках). Часы — `schedule` (25 мс, запас 200 мс, шестнадцатые, swing на нечётных): на шаге j кораблик `isleOn(j)` → `stab(t, is, vel, gap)`: по две пилы на ноту → два lowpass с огибающей → vca, живёт до следующего удара (`nextGap`). Шина: drive → сухо; эхо пинг-понг (`DT` шестнадцатых, `fbOf()` = 0.15 + 0.84·buoy.d, до 0.985; петля: highpass, lowpass dark, tanh; wow на delayTime); `killEcho` (тап по небу выше тумана) — обратная связь, посыл и выход эха в ноль за ~20 мс, через 350 мс — обратно (`applyAll`), падающая звезда; ревер `T.hall()` (fog²·1.6, хвост 1.2 + size·8 с); море (fx.mare) подключается только при mare > 0. Жесты: фарватер — `place` (место занято — кораблик переплывает на новую ноту), тянешь кораблик — место (если свободно) и нота, тап — тонет; веха — кораблик на месте (нота `lastP`) или убрать; маяк — пуск, вбок — темп (`T.tempoFrom(13)`); луна — вверх cutoff, вбок resonance; буй — поперёк время (между берегами), вдаль feedback; верх тумана — amount; без часов — `audition` (не чаще 140 мс); держишь — `sheets(kind)` (luna, echo, nebula, pharos: chord, octave −2…+2, length, swing, level; navicula: octave (сдвиг от маяка), level). Рисование: `wall()` — звёзды, волны, фарватер (края и квинта пунктиром, черты мест, засечки полутонов у ближнего края), берега (штриховка земли, скалы, урез, прибой, кипарисы), набережная; `drawMoon`, `drawIsle` — бумажный кораблик (корпус-трапеция, парус, сгибы, качается; звучащий — золотом; не шире луча), `drawBuoy` (круги повторов), `drawFog`, `drawPharos` (луч на остров `lastHit`), `drawQuay` — вехи фарватера (фонарь горит — кораблик, бегущий огонёк — шаг, свет поперёк фарватера). FX: wow, mare, drive, spread. `t2d.portus` (isles, steps, col(i, p), lantern(i), sky(), kill(), killed, buoyAt, hz, name, fc, fb, play). Сценарий `shot.py portus`.
