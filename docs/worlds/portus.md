# XIII · Portus

**Portus (мир XIII, `portus.js`):** dub techno на обычных узлах; фильтр, эхо и ревер — предметы сцены, не веер. Сцена — ночная бухта в псевдоперспективе: `P(u, d)` (d = 0 у набережной, 1 — горизонт; `K` = 2.6; ширина бухты к горизонту чуть сходится), берега — `edge(side, d)` (мысы — гауссианы, мелкие бухточки), высота скал `cliffH`; набережная внизу (`qy`), маяк `G.ph` на правом мысу, луна `G.moon` в левом углу (вместо солнца: `corner.hit` — всегда нет, тап по луне — `t2d.goMap()`). Острова `isles {u, d, oct, lvl, sd}` — аккорды: поперёк — тоника (`semiOf`, 12 полутонов от A2, с ладом — ступени), вдаль — тип `typeOf` = полоса d по пятым (`CHORDS`: 5, sus, m7, m9, m11 — голоса стабов), по очереди: `curIsle(step)` — номер такта / `pharos.bars`. Часы — `schedule` (25 мс, запас 200 мс, шаг — шестнадцатая, swing на нечётных), удары — `steps` (16 фонарей, `lanternAt`). Удар `stab`: по две пилы на ноту (±5–8 центов) → два lowpass (24 дБ; первый с резонансом) с огибающей от `fcOf()·2^(env·4.2)` к `fcOf()` → vca (атака 4 мс, спад τ = 0.035 + len²·1.8) → панорама → `stabs`; живёт до следующего удара (`nextGap`) — голоса не копятся; без часов — `audition`. Шина: `stabs` → drive (tanh, fx.drive) → `post` → сухо; эхо — пинг-понг `dL`/`dR` (время `DT[echo.time]` шестнадцатых, скольжением; петля: highpass 240 → lowpass `echo.tone` → tanh → `fbOf()` = 0.15 + 0.84·buoy.d, до 0.985 — «endless»; wow — 0.55 Гц на `delayTime`); ревер — `T.hall()` из сухого и эха (`fog.amt²·1.6`, хвост `1.2 + size·8` с); море (fx.mare) — шум в полосе с накатом, подключается только при mare > 0. Жесты: тап по морю (`inSea`) — остров, тянешь — другой аккорд, тап — тонет; фонарь — удар; маяк — пуск/стоп, вбок — темп (`T.tempoFrom(13)`); луна — вверх cutoff, вбок resonance, тап — карта; буй — поперёк время, вдаль feedback; верх тумана `fogTop` — amount; держишь любой — `sheets(kind)` (luna: cutoff, resonance, envelope, «~» classic; echo: time, feedback, dark, send; nebula: amount, size; pharos: bars per chord, length, swing, level; insula: chord, octave, level). Рисование: `wall()` — звёзды, волны, изобаты (границы аккордов), мысы (штриховка земли, скальная стена, урез, прибой, кипарисы), горизонт, набережная; `drawMoon` (диск в углу, кратеры, спящее лицо, ореол резонанса, лунная дорожка), `drawIsle` (скала, кипарисы, отражение, номер; звучащий — золотом), `drawBuoy` (круги эха по `hits`: каждый повтор — круг, слабее в fb^k), `drawFog` (пелена и рваные штрихи), `drawPharos` (луч к нынешнему острову, вспышка на ударе), `drawQuay` (фонари, бегущий огонёк). FX: wow, mare, drive, spread. `t2d.portus` (isles, steps, luna, echo, buoy, fog, pharos, fx, seq, play, sea(u, d), lantern(i), buoyAt, name, hz, fc, fb). Сценарий `shot.py portus`.
