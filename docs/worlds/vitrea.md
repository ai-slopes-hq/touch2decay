# XVIII · Vitrea — Harmonica vitrea (DLC vol. I)

**Vitrea (мир XVIII, `vitrea.js`, без worklet):** трение по стеклу. Тема — ночь (`INK 214,222,236`, `BGC #0a0e16`), луна `MOON`, вода `WATER`.

- **Звук:** один шум (буфер 2 с, петля) → lowpass 6 кГц → у каждого из 6 бокалов `exc` (gain) → 4 bandpass-моды `MR = 1, 2.32, 4.25, 6.63` (громкости `MG`, верхние × crystal) + двойник основной моды на `f·(1 + 0.005·tremor)` (биения) → `sum` (level) → панорама → pre → hall. Добротность из звона: `Q = π·f·T60/6.9`, `T60 = 0.6 + 6·dec^1.5` с; громкость моды нормируется на ширину полосы (`0.4 / √(1.57·bw/(sr/2))`). Высота: `DRY = 36, 38, 41, 43, 45, 48` полутонов от 55 Гц минус `8·w^1.3` (вода `w` 0…0.85), с ладом — `snapSemi`. Шум останавливается через 9 с тишины. Проверено: у поющего бокала ~98 % энергии в модах.
- **Жесты:** обод (±20 px) — ведёшь: скорость пальца `sp` → `excite(0.15 + 0.85·sp)`, отпустил — гаснет; тап по ободу — звон (`ping`: всплеск 4 мс), двойной тап — `pin` (палец-призрак, excite ≈ 0.5 с покачиванием). В чаше — вверх-вниз: вода; тап — звон; держишь — плашка *poculum* (water, decay, level; «~» на water, level).
- **Картинка:** `en` — оценка громкости бокала (растёт к excite, падает по звону); обод светится лунным цветом, на воде рябь, у `pin` — огонёк бежит по ободу. Луна в левом верхнем углу — карта.
- **FX:** crystal, tremor, spread, hall. Кубик — вода вразброс, один-два бокала поют сами, третий звенит. Корзина — пальцы прочь (вода остаётся).
- `t2d.vitrea` (glasses, fx, geo, freq, ping(k), pin(k), noise). Сценарий `shot.py vitrea`.
