# VI · Paradisus

**Paradisus (мир VI, `worlds/paradisus/`, без worklet; раскладка model / engine / view — как у Firmamentum, см. `CLAUDE.md`):** `model.js` — ангелы `{k, v, pinned, singers, detune, vib, breath, reg, lvl, seed, dr, sung}` (узлов в модели нет), `fx`, `harm(k)`, `hzOf`, `vowelAt` / `formants` (чистые, таблица `FORM`), дрейф гласной `vEff` на времени модели, планеты `orbitT` / `planetAt` и `chime`, Gloria (`grainAcc`, поющий — через `rng`), лимит `PIN_MAX`, действия касаний (`addAngel(k, v, pin)`, `release`, `moveAngel`, `setAngel`, `rose`), кубик, снимок; звучит ли ангел (`a.sung`, раньше `a.n`) — от engine через склейку (`model.voiced`); звук — события `voice`, `angel` (`rebuild` — новый хор), `fx`, `grain`, `grains` (россыпь розы), `chime`; `engine.js` — голоса (`Map` ангел → узлы), `voiceOn/voiceOff`, `retune`, собор `cathedralIR` + `setIR`, `octaver`, `grain`, `setLive`, слышанное `voice` / `grain` / `chime`; `view.js` — `geo`, `sphereAt` / `angleAt` / `vOf` / `anglePos`, `angelNear`, касания, `angelSheet`, стена, роза, `openness`, планеты, `flashes`, `glitter`, FX-веер, легенда, угол; `index.js` — склейка, `t2d.par` (тот же набор плюс `model`). Тесты модели — `tools/models/paradisus.test.mjs`.

Светлая тема (`INK` 94,69,32 на `#f5efe1`, золото `GOLD`). `geo()` — девять эллипсов `sph[k] {rx, ry}` вокруг розы (`k` = 0 внутри — Primum Mobile, 8 снаружи — Luna; гармоника `harm(k)` = 9 − k), центр чуть выше середины, роза `rose`, свет `light` (угол — `corner.hit`). `sphereAt` — ближайшая сфера вдоль луча (≤ 30 px), `angleAt` → гласная `vOf` (0…5 по кругу от верха: a, e, i, o, u). Высота `hzOf` = тоника лада во второй октаве × n × регистр. Голос `voiceOn` (уровни — константы `BWK` ширина формант ×2.2, `FGK`, `BODYK`, `VCAK`, `OUTK`, `DBK` — верхние форманты мягче): N пил (детюн ±(4 + 22·detune) центов) + вибрато (`vibCents` от fx.vibrato × vib) → 4 bandpass формант `formants(v)` (таблица сопрано `FORM`, между гласными — плавно) + тело (источник → lowpass 5f) + шум дыхания в форманты и воздух (highpass 3.5 кГц) → `vca` (медленное «дыхание» громкости) → шина (сухого 0.6, остальное — собор); раньше узкие форманты и собор на +9 дБ давали «горстку перегруженных синусов»; собор — `ConvolverNode` с отзвуком `cathedralIR(ctx, t60)` (шум со спадом, срез верха едет 9 → 1.2 кГц, каналы — разный шум, энергия нормирована по полосе ~2.5 кГц — иначе собор громче сухого на 9 дБ и перегружал мастер; t60 = 2.5 + aether·7, пересчёт `setIR` не чаще 250 мс); шиммер — петля: выход собора → lowpass 7 кГц → `octaver` (октава вверх: две линии задержки, время — точная пила из буфера, окна cos², у осциллятора-пилы склон неровный — давал 1.84 вместо 2) → `fb` (shimmer·0.62) → снова в собор; общий `T.hall` в раю не используется. Офлайн-рендер с собором — +15 % времени. Gloria — зёрна `grain()` (окна синуса на гармониках поющих, по стерео): модель сыплет `grain` ∝ dt·gloria·24, engine играет, view — вспышки `glitter`; подъёма (Шепард) и лестницы Иакова нет — убраны (лестница некрасивая, Шепард выбивался). Жесты: тап — ангел поёт, пока держишь; вдоль — гласная, поперёк — сфера; двойной тап — закрепить (до 4) / отпустить; держишь закреплённого — `angelSheet`; тап по розе — россыпь зёрен (12 через 35 мс, таймеры — в engine). `t2d.par` (angels, fx, geo, at(k, v), glitter, flashes, open, planet, vEff, orbit, live, hz, dice, model). Планеты: `orbitT` (круг за 70/(0.3 + 1.7·orbits) с), `planetAt(k)` = frac(orbitT·harm(k) + 0.13k); прошла над закреплённым поющим ангелом своей сферы — событие `chime` (engine: 6 зёрен через 45 мс, view: `flashes`); `fx.orbits` = 0 — выключено. Роза рисуется каждый кадр (не в `wall`), раскрытие `openness` по хору и gloria. Дрейф гласной у закреплённых — `vEff(a)` (±0.45·vibrato, своя фаза `seed`/`dr`, время модели в секундах; `a.v` — дом, в снимок), перестройка голоса — событие `angel` раз в 0.12 с времени модели. Шаг модели — `dt` кадра хоста (≤ 0.05 с). Сценарий `shot.py paradisus`.
