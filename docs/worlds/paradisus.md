Тесты модели — `tools/models/paradisus.test.mjs`.

Светлая тема (`INK` 94,69,32 на `#f5efe1`, золото `GOLD`). `geo()` — девять эллипсов `sph[k] {rx, ry}` вокруг розы (`k` = 0 внутри — Primum Mobile, 8 снаружи — Luna; гармоника `harm(k)` = 9 − k), центр чуть выше середины, роза `rose`, свет `light` (угол — `corner.hit`). `sphereAt` — ближайшая сфера вдоль луча (≤ 30 px), `angleAt` → гласная `vOf` (0…5 по кругу от верха: a, e, i, o, u). Высота `hzOf` = тоника лада во второй октаве × n × регистр. Голос `voiceOn` (уровни — константы `BWK` ширина формант ×2.2, `FGK`, `BODYK`, `VCAK`, `OUTK`, `DBK` — верхние форманты мягче): N пил (детюн ±(4 + 22·detune) центов) + вибрато (`vibCents` от fx.vibrato × vib) → 4 bandpass формант `formants(v)` (таблица сопрано `FORM`, между гласными — плавно) + тело (источник → lowpass 5f) + шум дыхания в форманты и воздух (highpass 3.5 кГц) → `vca` (медленное «дыхание» громкости) → шина (сухого 0.6, остальное — собор); раньше узкие форманты и собор на +9 дБ давали «горстку перегруженных синусов»; собор — общий ревербер `cathedral` ядра (`T.send('cathedral')`, T60 ~8 с, фиксированный): посыл = (0.35 + aether·0.5)·(0.9 + aether·0.5)·1.1 через highpass 160 Гц; прежние свёртка `cathedralIR`, `octaver` и шиммер-петля убраны (23.10) — **shimmer теперь только лучи розы**, aether — только доля собора, длины отзвука нет. Gloria — зёрна `grain()` (окна синуса на гармониках поющих, по стерео): модель сыплет `grain` ∝ dt·gloria·24, engine играет, view — вспышки `glitter`; подъёма (Шепард) и лестницы Иакова нет — убраны (лестница некрасивая, Шепард выбивался). Жесты: тап — ангел поёт, пока держишь; вдоль — гласная, поперёк — сфера; двойной тап — закрепить (до 4) / отпустить; держишь закреплённого — `angelSheet`; тап по розе — россыпь зёрен (12 через 35 мс, таймеры — в engine). `t2d.par` (angels, fx, geo, at(k, v), glitter, flashes, open, planet, vEff, orbit, live, hz, dice, model). Планеты: `orbitT` (круг за 70/(0.3 + 1.7·orbits) с), `planetAt(k)` = frac(orbitT·harm(k) + 0.13k); прошла над закреплённым поющим ангелом своей сферы — событие `chime` (engine: 6 зёрен через 45 мс, view: `flashes`); `fx.orbits` = 0 — выключено. Роза рисуется каждый кадр (не в `wall`), раскрытие `openness` по хору и gloria.
