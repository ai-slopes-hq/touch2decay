# XIV · Tonitrus

**Tonitrus (мир XIV, `tonitrus.js` + `storm-worklet.js`):** степь в грозу, портретная сцена (`Ws = min(W, 0.62·H)`), клетка карты `[0, 1]` (над Horologium). Выкатывался сначала на превью-ветку `tonitrus` (автор: «сначала на стейджинг»).

**Сцена** (`geo()`): горизонт `hor` на 0.6 высоты; туча `G.cloud {x, y, w, h}` — выше/ниже по `rain.amt`, вбок по `rain.u`; грозовая туча `G.storm {x, near, w, h}` на горизонте (по `storm.u`, размер — по близости `storm.D`); звонница `beamL…beamR`, `beamY`, `foot`, колокола `G.bells[i] {x, y, s}` (большой слева); дерево `G.tree`. Перспектива: `groundY(G, D)` = hor + (bot − hor)·DMIN/D (D в км, `DMIN` 0.08 … `DMAX` 6), обратно `dOfGround`; по небу — `dOfSky` (выше — ближе, логарифмически); верх молнии `boltTop(G, D)` (дальняя — ниже). Значки «~» — `autoPos(G)` {rain, bolt, bells}.

**Молния** (`makeBolt(G, gx, D, path?)`): канал `main` — от `boltTop` до земли, извилистость `jag` (середина отрезка уходит вбок, до 5–6 px); нарисованный пальцем путь сортируется сверху вниз, прореживается и продолжается до земли; 2–5 ветвей; `strokes` — повторные разряды (0 и ещё 1–3 через 45–135 мс). **Гром** — `rumble(b, sr, cx, halfW)`: точки канала в км (вбок, высота до 1.6 км, глубина = D + случайное блуждание), каждый отрезок — N-импульс длиной 2.5 + 4·√r мс, амплитуда ∝ длина·(0.25 + синус угла к лучу зрения)/(0.2 + r)·логнормаль; приход `tOf(r)` = 1.7·r^0.8 с (сжато, не настоящие 3 с/км), дальний раскат растянут (1 + 0.35·D); дальние куски — в тёмный буфер (lowpass 380 Гц ×2), ближние — в яркий (срез 2600/(0.3 + D)); рокот — тёмный шум по огибающей импульсов; ближе 1.5 км — треск (рваный шум с производной); повторные разряды — с весами 1, 0.55, 0.35; нормировка и мягкий `tanh` (чтобы низ было слышно на динамике); ведущая тишина обрезается (`lead`), источник стартует через `lead`. Громкость удара `loud` = 0.35 + 0.65/(1 + 0.6·D). Расчёт — ~30–60 мс в Chromium.

**Вспышка**: на удар (если `cfg.flash`) — по вспышке на каждый разряд, не чаще одной серии в 340 мс (≤ 3/с); яркость 0.16 + 0.3·близость, при `prefers-reduced-motion` — ×0.4; в `draw` — белёсый слой на весь экран, гаснет за ~60 мс, туча подсвечивается.

**Worklet** (`storm-worklet.js`, вход — гром): дождь — подложка (розоватый шум в полосе 450 Гц … 1.8–7.3 кГц по силе) + капли (пуассоновы, до 520/с при rain = 1, не больше 40 сразу): 28% «пузыри» (синус 700–3300 Гц / размер, высота поднимается, 4–16 мс), остальное — «стук» (короткий фильтрованный шум); ветер — розовый шум в плавающей полосе (порывы); колокола — 5 × 8 мод (`RATIO` hum 0.25, prime 0.5, tierce 0.6, quint 0.75, nominal 1, 1.5, 2, 2.66 от ноты; хвост 1.5 + 9·decay с × размер), удар — толчок по модам (`strike {i, vel}`), гром на входе раскачивает моды при `symT` > 0 (вход ∝ (1 − r), долгие моды слушают слабее); обратно 20/с `lv` (энергия колоколов) и `rain`. Сообщения: `params {rainT, size, rainLvl, windT, symT, bellLvl, decay}`, `bells {f[5]}`, `strike`, `damp`. Модуль заводится при входе в мир (`enter: start`) или первом звуке.

**Колокола**: ноты `BELL_IV` [0, 7, 12, 15, 19] от A3 (220 Гц) + тоника лада, с ладом — `snapSemi`; `cfg.pitch` — октава −1/0/+1. Перенастройка при смене лада — в `tick` (ключ частот).

**Сами** (`auto`): `bolt` — гроза ходит по циклу 150 с (`storm.ph`: D от ~0.35 до ~5.7 км, `storm.u` — синус), удары с экспоненциальными паузами `meanGap()` = (16 − 13.5·rate) с × (0.6 + 0.08·D) около тучи; `rain` — сила волнами (два медленных синуса), с грозой — сильнее, когда близко (`applyRain`); `bells` — сочувствие грому (`cfg.symp`) и изредка удар от ветра (если *wind* > 0.05).

**Жесты**: «~» — тап переключает; колокол — удар на касании, ведёшь — следующие; туча — тап вкл/выкл дождя, тянешь — сила и место; небо/земля — тап — удар (на отпускании), ведёшь — свой канал; держишь — плашки `nubes` (rain, drops, level, by itself), `fulmen` (storm by itself, how often, thunder, flash), `campanae` (pitch, decay, thunder rings them, level, by themselves). Подписи: расстояние под пальцем, сила дождя, нота колокола. FX: space (зал), wind, dark (срез всего мира). Угол — без солнца (`corner.hit` — нет), выход стрелкой.

**Рисование**: `wall()` — небо горизонтальными штрихами (вверху гуще), увалы, степь пучками травы (клонятся по ветру), дорога с колеёй, дерево, звонница без колоколов; `drawStorm` — башня из кругов + наковальня, под ней ливень, когда гроза сама; `drawCloud` — косой дождь от основания до земли (`groundY`), кучевая туча `puffs` + `drawPuffs` (объединение кругов: обводки, сверху заливка — остаётся только внешний контур; штриховка гуще к основанию; ровное основание); `drawBolt` — ядро и бледный широкий штрих, ярче в такт разрядам, гаснет за 0.7 с после последнего; `drawBells` — качаются по `lv`, звучащие — светлые; `drawAuto`.

Отладка: `t2d.tonitrus` (rain, auto, storm, cfg, fx, strikes, thunders, lv, rainLv, hz(i), bellAt(i), cloudAt(), autoAt(k), landAt(D, u), skyAt(g, u), rumble(D) → {lead, sec, ms}, strike(x, D)). Сценарий `shot.py tonitrus`.
