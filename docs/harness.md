# Харнес Claude Code

Обвязка Claude Code под цикл touch2decay (26.10). Цель по порядку: экономия токенов, надёжность выкладки; автономность — потом.

## Почему так

Замер по 17 сессиям 20–26.10 (`python3 tools/tokens.py --history`): из ~780M токенов 760M — чтение кеша, то есть повторное чтение длинного контекста на каждом шаге. Медиана контекста главного потока — 200–375k, максимум 966k. Контекст раздувают чтение кода (`cat`, `sed -n`, `grep`, Read `.js` / `.diff` — ~60 % результатов инструментов) и скриншоты (~11 %); вывод тестов мелкий (`node --test` ~170 токенов). Отсюда: короткий главный поток, чтение кода и скриншоты — в субагентах.

## Экономия контекста

- Одна задача — одна сессия. Хук `ctx_nudge` после 150k (и дальше каждые +50k) подсказывает агенту предложить `/handoff` → `/clear`.
- `/handoff` (`.claude/skills/handoff/`) пишет `.claude/handoff.md` (не в git); хук `handoff_load` подкладывает его в следующую сессию один раз и убирает в `handoff.prev.md`.
- Изучать код — через Explore; в главном потоке читать только то, что правишь, Read с `offset` / `limit`, без `cat` целых файлов.
- Скриншоты сценариев — агент `shots` (`.claude/agents/shots.md`): прогоняет `shot.py`, смотрит png сам, возвращает вердикт текстом.
- Учёт — `python3 tools/tokens.py` (текущая сессия), `--line` — ячейка «Токены» для `docs/tokens.md`, `--history` — все сессии.
- Строка статуса (глобальная, `~/.claude/statusline.py`) показывает размер контекста в k.

## Выкладка — что проверяют хуки

`guard.py` на `git commit` / `git push` агента (команды автора через `!` не трогает). Блок — с причиной, агент чинит сам.

- Коммит: `CACHE` в `sw.js` = все `?v=` в `index.html`; `node --check` застейдженных `.js`; тронуто `core/**/*.cpp|hpp` → `t2d.wasm` в том же коммите (правка только нативной стороны — `[no-wasm]` в сообщении); новый файл сайта не в списках `sw.js` — предупреждение.
- Пуш: меняются файлы сайта (всё, кроме `tools/`, `docs/`, `core/`, `ios/`, `mockups/`, `notebooks/`, `.claude/`, `*.md`) → версия больше, чем в `origin/<ветка>`.
- После пуша: `python3 tools/deploy-wait.py` — ждёт статус Vercel и печатает одну строку (`success v189 abc1234 <url>`).
