# SDK звука: правила

Вынесено из `CLAUDE.md` (26.10). Читать перед любой работой со звуком мира.

## SDK звука: что взять, что положить (лукап перед работой со звуком)

Перед любой работой со звуком мира (перенос в C++, баг в DSP, новый блок) — сверка с SDK, до кода:
1. **Что уже есть** — `core/sdk/` (список ниже) и `core/host/`. Решения автора и вопросы — `docs/sdk-inventory.md` §8–9.
2. **Что у мира** — строка мира в матрице `docs/sdk-inventory.md` §6 и его блоки в §2 (колонка «один блок?»).
3. В ответе автору — коротко: **берём** из SDK …, **кладём** в SDK …, **остаётся** в мире ….

**Брать** (не копировать формулу в мир): блок есть в `core/sdk/` — использовать его; близкие константы мира — параметрами блока, звук не меняется (решение 4). Зал — только посыл в общий ревербер хоста (`Out.sL/sR` + `rev()` у мира SDK, `T.send(rev)` на Web Audio), своего `hall()` нет. Лад — `const Scale&` хоста. Случайность — `sdk::Rng` от зерна (`prepare(sr, seed)`), никакого `Math.random`/`rand()`.

**Класть** в SDK: блок помечен в инвентаризации «да» / «да·п», нужен 2+ мирам (или общий для хоста), в `core/sdk/` его нет. Правила блока: header в `core/sdk/`, `namespace sdk`, без аллокаций в `process` (память — внешний буфер или внутри объекта), без DOM / Web Audio / UI; константы — параметры конструктора, умолчание — как у первого мира; тест в `core/tests/sdk_test.cpp`; миры, которые на него переходят, проходят свою сверку 1e-6 без изменений. Потом — строка в список ниже и в `core/README.md`.

**Не класть**: «нет» / «своё» из §6 (пластина Cymatica, bytebeat, окна пульсаров, мост струн…) — в `core/worlds/<мир>/`; паритет-хелперы (`jsRound`, `f32()`) — не в блоки (§7); картинку и раскладку `mirror` — у мира; блоки выключенных миров (III, XVII, XVIII) — отложены (решение 8). Сомнение «блок или мир» — спросить автора вариантами.

**В `core/sdk/` сейчас (25.10):** `Saw` (band-limited пила, остаток BLEP — Brandt, ядро ±16 сэмплов, задержка 16 сэмплов, алиасинг ниже −90 дБ; идеальная, не копия PeriodicWave), `Biquad` (семантика Web Audio, Q в дБ у LP/HP), `DcBlock{R}`, `OnePole` (сглаживание / гейн голоса вверх-вниз), `softclip(x, k)` = tanh, `panLin(p, spread)`, `Delay` + `Allpass` (внешний буфер, линейная интерполяция), `Rng` (mulberry32, бит в бит с эталоном JS), `Reverb` = `Fdn4` (room / hall / cathedral) + `Plate` (Dattorro), `Resonator` (двухполюсный, `ResCoef` по T60 / τ), `Knee` (колено выхода), `StepClock` (часы секвенсера в сэмплах: шаг, MIDI-замок, пропуск), эхо `TapeEcho` (время «лентой» — `glideTo`), пинг-понг `PingPong` (две линии крест-накрест, LP в петле; по желанию HP, насыщение на ноге L→R, wow на времени, скользящее `setSec`, `setFb(·, τ)` — как у Portus), огибающая `AD`, струна `KsLoop`, хор `Chorus` (в том числе «моно» — Natura), фейзер `Phaser`, `panEq` / `PanStereo`, `Param` (таймлайн AudioParam), `Glide` (setTargetAtTime по сэмплам, `smooth.hpp`), `Osc`, `Shaper<N>` (кривая WaveShaper без oversample), `TanhShaper` (нормированный tanh, k, oversample 2× — Inferno), `BpBank<N>` (банк полос BP с плавными целями; закон Q и нормировка гейна — снаружи), `Noise` (white, pink, brown, crackle, grain — на лету от `Rng`), `jsmath.hpp` (`jsHypot`, `jsRound`, `jsClamp`), транспорт (`ClockParser`, `Follower`, `Steps`), `Json` (снимки, не для `process`), интерфейс `World` (`prepare / action / process / rev / mirror / heard / snapshot / restore / sounding`). Хост (`core/host/`): миры по слотам, посыл × фейдер → четыре ревербера, `Scale`. **Ещё нет** (кандидаты из инвентаризации): модальный банк, `Phasor` и чтение таблиц, `WaveTables` (морф 9 таблиц), `DetuneStack`, `EnergyMeter`/`BlockTimer`, `RowLfo`.
