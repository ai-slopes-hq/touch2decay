# Фаза 2a (iOS): отложенное, решения, непроверенное

Выжимка из журнала ревью 2a (28.10.2026; сам журнал не хранится). План: `docs/superpowers/plans/2026-10-28-ios-2a.md`, спека — `docs/superpowers/specs/2026-10-28-ios-2a-design.md`, общий план — `docs/native-ios-plan.md`. Исправленное в волне F1–F11 сюда не входит. Всё ниже — мелочи, не блокирующие 2b, если не сказано иное.

## Не проверено на iPhone

- `ios/app/install.sh` ни разу не запускался на устройстве.
- Аудиосессия: блокировка, звонок / Siri, смена маршрута (наушники; с 28.10 движок пересобирается и по `AVAudioEngineConfigurationChange`). Логика — чистая функция `AudioPlan` в `Audio.swift` с тестами, на железе не гонялась (F1/F2).
- Настоящая задержка касание → звук (на симуляторе `outputLatency` не показательна), загрузка рендера на устройстве (цель ≤ 30 %), 60 fps, вид на экране.
- `core/build-wasi.sh` не собирался (нет wasi-sdk).
- Сверка с веб-эталоном: снимок `-shot` сходен с `.shots/firmamentum.png` от 23.10 (Playwright не стоял); пыль «+» бледнее веба, подписи удерживаемой звезды на снимке не видны.

## Решения и ограничения для следующих фаз

- `t2d_app_init` гонится с render/UI (поля без синхронизации): вызывать только при остановленном `AVAudioEngine`; UI-чтение mirror/heard во время init — допустимый мусор на кадр. Предусловие стоит записать в `core/app/t2d_app.h` (сейчас только в `engine.hpp`).
- Ядро заново инициализируется только при смене частоты; при прерывании и reset медиасервисов перестраивается лишь граф движка (состояние миров сохраняется).
- Мастер: частота LPF ограничена ≤ 0.45·sr (иначе biquad у Найквиста на 44.1 кГц). Малосигнальное усиление в тесте mix_master учитывает `makeup` компрессора (1.234459 на 48 кГц).
- Остаток `full` −0.4 дБ против Chromium: адаптивный релиз компрессора Chromium не смоделирован; принято.
- `Comp::run` (`core/host/host.cpp`): `pow`/`log10` на сэмпл — не оптимизировать до замера на iPhone (симулятор 9–13 %, макс. 16–19 % < 30 %). Правка `core/**` тянет пересборку wasm и веб-тесты.
- Купол Firmamentum: round-trip `toSky` — только для точек внутри купола, вне его `nil`, как в `view.js` (спека старше сетки из брифа). Если на устройстве купол выглядит шире/уже веба — искать здесь.
- Лог dev-сборки: адрес Mac захардкожен (`Log.mac` в `Log.swift`, 192.168.0.2:8766, `ios/shell/logserver.py`); конфигурируемость — позже. На чужой сети — лишние запросы и запрос доступа к локальной сети.
- Тесты `T2DTests` идут без TEST_HOST: Swift-файлы, нужные тестам (Draw, Theme, Stage, Clock…), вручную добавлять в sources `project.yml`; позже — TEST_HOST или общий framework.
- Константы касаний, плотность `min(scale, 2)`, hairline 1 pt — по `host/touch.js` (см. ограничения плана 2a); свечение только кешированным спрайтом, без теней.

## Аудио (app)

- `Audio.swift` (~83, 94–95): молчаливые `try?` у `setActive` / `setCategory` — провал не попадает в лог.
- Нет повтора после провала старта движка; при <2 буферах выход не обнуляется.
- Последовательность Audio stop → init → start не покрыта тестом (тесты — только C API и `AudioPlan`).
- `Audio` получил параметр `seed` (по умолчанию 1) ради `-shot`, вне брифа.

## Приложение / UI

- `Stage`: нет тестов самого `Stage`; сцена `-shot` без автотеста. Неиспользуемый `new:` в `finger(_:new:)`; `draw` берёт `CACurrentMediaTime` отдельно от link.
- `Stage`: draw вне тика link (`setNeedsDisplay` из fire / touchUp) пишет кадр со старым `frameStart` — завышает frame max. `Meter.frame(missed:)` в продакшене всегда 0; frame — только CPU draw, не GPU.
- `StageView`: жёсткий стартовый geo 390×844.
- `FirmamentumView.swift` ~330 строк (касания + состояние + рисование) — вынести `FirmamentumView+Draw.swift`. `wall(_ d:)` (~:72): параметр `d` мёртвый; при провале CGContext `wallKey` уже выставлен — провал кешируется навсегда.
- `Mirror.swift:26`: `Int(b[16])`, `np`/`nd`/`nb` без `max(0, …)` — ловушка на битом буфере. `nfx = 7` захардкожен (дубль `NFX` из `world.hpp`) — нужен комментарий.
- `Clock.swift`: `enum Clock` затеняет протокол `Clock` из stdlib — компилируется, переименование косметическое.
- Skip-reparse зеркала почти не срабатывает при звуке (время в зеркале меняется каждый блок); `Array(mbuf[0..<mlen])` аллоцирует при разборе. Аллокации буферов убраны, остаток — перф-мелочь.
- `Log.swift`: размер файла проверяется только при запуске.
- `Draw.swift`: текст аллоцирует attrs / CFAttributedString / CTLine на вызов — кешировать CTLine для стабильных подписей. `glowAt` ставит `setAlpha(min(1, a))` вместо `ga·a` как `draw.js:40` — инвариант «alpha контекста = 1» задокументировать. `quarterSun` не портирован (миры III/IV, не в 2a). `Draw.scale` — только константа, CTM масштабирует вызывающий.
- `ios/app/Fonts/OFL-IM-Fell.txt`: нет строки копирайта Igino Marini — сверить с upstream (OFL п. 2).
- `SKIP_INSTALL` не задан у `T2DCore` (важно только для archive). Угловой палец после ухода > holdMove остаётся поглощённым (F4); для других миров сверить контракт `World.cancel`.

## Ядро (core)

- `core/bridge/api.cpp` (~:43): комментарий про «ловушку libc++» — дубль из `wasm.cpp`, устарел (проверить; не исправлено).
- `core/host/host.cpp:209`: мёртвый `if (det > 1) det = 1;` в `Comp::run`. Вне `Comp::run`-замера: `saturate` на каждом сэмпле x>1e-4, `pow(10, kneeDb/20)` на вызов (вынести в set), ветка else с `log10`/`pow` при det≥1 в покое.
- `core/app/engine.cpp`: `sr ≤ 0` / `ticks_per_sec ≤ 0` → inf/NaN → UB в `static_cast<uint64_t>` (:61–62, :121–122).
- `engine.cpp`: малый `cap` в heard/mirror молча даёт 0 (heard застревает) — задокументировать минимумы (mirror 1024, heard 256). `dropped` считает и невалидные аргументы, хотя заголовок говорит «не влезло в кольцо»; слот вне диапазона принят и попадает в `lat_n`.
- `engine.cpp`: `Spsc` копирует целый Act (~1 КБ) / Rec (~2 КБ); `head_`/`tail_` в одной кеш-линии; `addMax` — CAS-цикл. Плотность комментариев ниже, чем в `core/sdk/`; `m[16]` без комментария.
- `core/sdk/world.hpp`: фильтр нулевых heard-записей опирается на неписаное правило «heard начинается с ненулевого счётчика/тега» — задокументировать.
- `t2d_master_makeup` — тестовый C API, не в wasm-экспорте. `VOL_GAIN = 1` (= `volGain(VOL_DEF)`) без сеттера.
- `core/tools/mix_cli`: молча игнорирует неизвестные ключи stdin.

## Тесты

- `core/tests/sdk_test.cpp`: `bridgeNative` проверяет звук только в последнем из 40 блоков; `include t2d.h` в середине группы (~:470); `mix_master ceil(-6)` — только верхняя граница; ceil-тест дублирует цикл синуса `masterSine`; нет теста на сброс LPF в `prepare` / `t2d_init`.
- Сцены master-bus (quiet / dice) почти не нагружают компрессор; нет сцены «громко → тихо» (release zones).
- Нет кросс-поточного теста Engine (рекомендован TSan `sdk-test`); нет тестов `n == 0`, малого `cap`, слота вне диапазона; `app_reinit_rate` не проверяет сброс остатка и очереди; `app_spsc_threads` может зависнуть на join при провале.
- `FirmamentumTests` / `StageTests`: `testCornerFingerStaysConsumedAfterMove` проходит и без фикса F4 (нужен spy World) — долг; нет теста повторного использования id другой звездой при удержанном пальце; `testTapAddsStar` не проверяет `a[1]` (u); нет теста угла 44×44 (`inCorner`); тест удержания только через `touchUp`; нет теста `cornerTick` при удержанном пальце и отмены сдвигом.
- `EngineTests`: индекс `len > 17 ? 16 : len - 1` невнятный. `Draw`-тесты: `testGlowSpriteBuiltOnce` тавтологичен (static let); `testScaleCapped` повторяет формулу; `testSunGlyphDraws` — широкая полоса 40…160, вертикальный флип пройдёт; хелпер чернил привязан к RGBA-premultiplied (байт 3); дубль регистрации шрифтов в `setUp`.
- F10 (thermal в `Log.flush`) без теста: нужен реальный `Log` и сеть. В волне исправлений тесты писались вместе с кодом, красная фаза отдельно не наблюдалась.
